Quickstart

Three steps
to your first call.

  1. 01

    Create an account

    Every account gets $0.25 free each month, spent first, so you can try any tool before you pay.

  2. 02

    Create an API key

    On your account page. Keys start with tk_live_ and are shown once.

  3. 03

    Send a POST

    To /toll-preview/api/v1/tools/<tool>, with the key as a Bearer token and the tool's input as JSON.

curl -X POST https://krishnachagti-sudo.github.io/toll-preview/api/v1/tools/business-days \
  -H "Authorization: Bearer tk_live_..." \
  -H "Content-Type: application/json" \
  -d '{"op":"between","region":"US","start":"2026-07-01","end":"2026-07-08"}'
const res = await fetch("https://krishnachagti-sudo.github.io/toll-preview/api/v1/tools/business-days", {
  method: "POST",
  headers: {
    "Authorization": "Bearer tk_live_...",
    "Content-Type": "application/json"
  },
  body: JSON.stringify({ op: "between", region: "US", start: "2026-07-01", end: "2026-07-08" })
});
const data = await res.json();

Reference

Keys, errors and retries,
the same for every tool.

API keys

Keys start with tk_live_. Send yours in the Authorization header. A key is shown once, when you create it, and only a fingerprint is kept, so if you lose a key, revoke it and make a new one.

Make one key per app or agent, so you can limit or revoke each on its own. Keep keys on your server, never in a web page or a public repository.

Every request
Authorization: Bearer tk_live_...
Content-Type: application/json

What a call returns

A successful call answers with result, what it cost in charged, and your balance after the charge. dataVersion names the reference data the answer came from, when a tool uses any.

Amounts are whole numbers of micro-units: one dollar is 1,000,000. The display fields show the same amount as text, exactly. A tool whose price depends on what you ask also says which action was charged, and why.

Quotes

To know the price first, send the same body to the tool's /quote address. It answers with the amount, as a number and as text, and the price in words. It runs, charges and reserves nothing.

Over MCP, the quote_price tool does the same. See MCP for agents.

POST https://krishnachagti-sudo.github.io/toll-preview/api/v1/tools/business-days/quote
{

Errors

Every error has the same shape. fields appears when specific input fields were wrong. Nothing is charged for a call that is refused.

An error
{
  "ok": false,
  "error": {
    "code": "invalid_input",
    "message": "...",
    "fields": {
      "start": "..."
    }
  }
}
Every error code and what it means
Error codes
StatusCodeWhat it means
400invalid_inputThe body is not valid JSON, is too large, or does not match the tool's input. Not charged.
401unauthorizedThe key is missing, wrong or revoked.
402insufficient_balanceYour balance does not cover this call. Add money and try again.
402cap_reachedThe call would pass a monthly limit on the key or the account. Not charged.
404unknown_toolNo tool has that name, or it has been retired.
409in_progressA call with the same Idempotency-Key, or the first paid call for the same job, is still running. Retry in a moment.
422idempotency_mismatchThe Idempotency-Key was already used with different input.
422not_availableThe tool cannot answer this exactly (for example, no published data for that date). Not charged.
429rate_limitedToo many requests. Slow down and retry.
502upstream_failedThe tool failed while running. The charge was refunded.

Idempotency keys

Networks drop answers. To retry safely, send an Idempotency-Key header with a value you choose (1 to 200 characters), unique per logical call.

If a call with that key was already answered for the same tool, the stored answer comes back, marked Idempotent-Replay: true, and nothing more is charged. Reusing a key with different input returns idempotency_mismatch. If the first call failed and was refunded, the key is free to use again.

A retry-safe call
Idempotency-Key: invoice-4471-due-date

Rate limits and spending limits

Each key can make 10 requests a second, with short bursts of up to 20. Past that you get rate_limited; wait briefly and retry.

Every key has a hard monthly spending limit (a new key gets $5 unless you choose another), and you can set one for the whole account. A call that would pass a limit is refused with cap_reached and charges nothing. Limits count from the 1st of each month (UTC).

Too many requests 429
{
  "ok": false,
  "error": {
    "code": "rate_limited",
    "message": "Too many requests. Wait a moment and try again."
  }
}
