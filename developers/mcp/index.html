MCP for AI agents

Give your agent
exact tools.

Toll runs an MCP server over Streamable HTTP. Your agent gets the same tools, the same key and the same prices as the REST API, and the same answer every time.

Connect

One address
and your API key.

MCP server, Streamable HTTP
https://krishnachagti-sudo.github.io/toll-preview/mcp
Send JSON-RPC 2.0 requests with POST, one at a time. Batches are not supported.
  1. 01

    Create an API key

    On your account page. Make one key per agent, so you can limit or revoke each on its own.

  2. 02

    Add the server

    Give your MCP client the address above, with your key as a Bearer token in the Authorization header.

  3. 03

    List, then call

    Listing tools needs no key. Calling one takes your key, and is priced and limited exactly like an API call.

MCP client settings
{
  "mcpServers": {
    "tools": {
      "type": "http",
      "url": "https://krishnachagti-sudo.github.io/toll-preview/mcp",
      "headers": {
        "Authorization": "Bearer YOUR_API_KEY"
      }
    }
  }
}

Most MCP clients take a block like this. Put your real key in place of YOUR_API_KEY, and keep it out of shared files.

Example calls

JSON-RPC over HTTP,
with real answers.

Every answer below is what the server sends back. A refused call (no balance, a limit reached, invalid input) comes back as text with isError set to true, so the agent can read the reason and act on it. A call without a key gets error -32001.
