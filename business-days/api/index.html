Business days API

POST https://krishnachagti-sudo.github.io/toll-preview/api/v1/tools/business-days with {"op":"between","region":"US","start":"2026-07-01","end":"2026-07-08"} returns 4 business days and names the holiday it skipped, Independence Day (observed) on 2026-07-03. Each call costs $0.0005 (₹0.04 on a rupee account).

Business days
4
Per call

Request

FieldValue
opbetween to count, or add to add days to a date
regionUS (federal holidays) or GB-ENG (England and Wales bank holidays)
startA date written like 2026-07-01, from 1971 to 2100. Never counted itself.
endbetween only: the last date, counted. Before the start, the count is negative.
daysadd only: a whole number from -3650 to 3650; negative goes back
curl -X POST 'https://krishnachagti-sudo.github.io/toll-preview/api/v1/tools/business-days' \
  -H "Authorization: Bearer $API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"op":"between","region":"US","start":"2026-07-01","end":"2026-07-08"}'

Response

{
  "ok": true,
  "result": {
    "businessDays": 4,
    "holidaysSkipped": [
      {
        "date": "2026-07-03",
        "name": "Independence Day (observed)"
      }
    ]
  },
  "charged": {
    "amount": 500,
    "currency": "USD",
    "display": "$0.0005"
  },
  "dataVersion": "holiday-rules-2026.10"
}

Amounts are whole micro-units (1,000,000 to the dollar or rupee); the response also carries your balance after the charge. holidaysSkipped lists each weekday holiday inside the range, with the date it was taken off. For add the result is { date, holidaysSkipped }: adding 1 business day to 2026-12-24 in GB-ENG gives 2026-12-29, past Christmas Day and the Boxing Day substitute day.

Invalid input is a 400 invalid_input with the field that was wrong, and is never charged. Retries are safe with an Idempotency-Key header. The docs cover errors, limits and idempotency for every tool.

From an AI agent (MCP)

Agents that speak the Model Context Protocol call the same tool, named business-days, with the same input and price. Add the server with your key:

{
  "mcpServers": {
    "toll": {
      "type": "http",
      "url": "https://krishnachagti-sudo.github.io/toll-preview/mcp",
      "headers": {
        "Authorization": "Bearer YOUR_API_KEY"
      }
    }
  }
}

What it knows

US federal holidays as set by 5 U.S.C. 6103 on their observed days, and England and Wales bank holidays with substitute days and one-off royal days, from 1971 to 2100. Weekends are Saturday and Sunday. It does not know state, company or Scottish holidays.

Sources

  • OPM: Federal holidays
  • 5 U.S.C. 6103: Holidays
  • GOV.UK: UK bank holidays

Steps

  1. Create an account. Sign up; every account gets a small free allowance each month, spent before any money you add.
  2. Make a key. Create an API key on your account page and keep it on your server.
  3. Call the tool. POST a JSON body with op, region and the dates to the business-days endpoint, with the key as a Bearer token.
