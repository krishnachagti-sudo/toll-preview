# California lien waiver forms

California sets out 4 statutory lien waiver forms in Civil Code 8132, 8134, 8136 and 8138: conditional and unconditional, each for a progress or a final payment. The Contractors State License Board says a waiver must follow one of them substantially to be effective.

- Statutory forms: 4
- Notary: Not on the form
- Source read: November 2, 2026

## The forms

California statutory lien waiver forms

| Form | Statute | When to use it |
| --- | --- | --- |
| Conditional waiver and release on progress payment | Cal. Civ. Code 8132 | With a pay application, or in exchange for a check for a progress payment, before the money has cleared. |
| Unconditional waiver and release on progress payment | Cal. Civ. Code 8134 | After a progress payment has cleared. |
| Conditional waiver and release on final payment | Cal. Civ. Code 8136 | For the last payment, before the money has cleared. |
| Unconditional waiver and release on final payment | Cal. Civ. Code 8138 | After the last payment has cleared. |

## What the statute says

- **CSLB, on Civil Code 8132-8138**: "To be effective, the waiver and release forms must follow, substantially, one of the forms set forth in Civil Code sections 8132, 8134, 8136, and 8138."
- **CSLB, on conditional releases**: "In the case of a conditional release, the release is only binding if there is evidence of payment to the claimant."

## Questions

### Does California have a statutory lien waiver form?

Yes: four statutory lien waiver forms in Cal. Civ. Code 8132-8138. The statute's words: "To be effective, the waiver and release forms must follow, substantially, one of the forms set forth in Civil Code sections 8132, 8134, 8136, and 8138."
