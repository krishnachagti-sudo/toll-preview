# Texas lien waiver forms

Texas sets out 4 statutory lien waiver forms in Property Code 53.284: conditional and unconditional, each for a progress or a final payment. A waiver must substantially comply with them, and it must also be notarized when the owner signed the original contract before January 1, 2022 (H.B. 2237, secs. 35 and 37).

- Statutory forms: 4
- Notary: Before 2022 contracts only
- Source read: November 2, 2026

| Form | Statute | When to use it |

## What the statute says

- **Tex. Prop. Code 53.284(a)**: "A waiver and release given by a claimant or potential claimant is unenforceable unless it substantially complies with the applicable form described by Subsections (b)-(e)."
- **Tex. Prop. Code 53.283**: "A person may not require a claimant or potential claimant to execute an unconditional waiver and release for a progress payment or final payment amount unless the claimant or potential claimant received payment in that amount in good and sufficient funds."
- **Tex. Prop. Code 53.284(c)(1) and (e)(1)**: "contain a notice at the top of the document, printed in bold type at least as large as the largest type used in the document, but not smaller than 10-point type"
- **Tex. Prop. Code 53.281(b)**: "in the case of a conditional release, evidence of payment to the claimant exists."

## Which Texas version applies

H.B. 2237 (2021) changed Property Code 53.281(b) so that a waiver needs only to be signed, where before it had to be signed and notarized. Section 37 of the act says the changes apply only to an original contract entered into on or after January 1, 2022, the date the act took effect. The original contract is the owner's contract with the prime contractor, not your subcontract.

The form text in 53.284 itself did not change, so both versions print the same words; for an older contract the generator adds the notary's certificate of acknowledgment from Civil Practice and Remedies Code 121.008.

## Questions

### Does Texas have a statutory lien waiver form?

Yes: four statutory lien waiver forms in Tex. Prop. Code 53.284. The statute's words: "A waiver and release given by a claimant or potential claimant is unenforceable unless it substantially complies with the applicable form described by Subsections (b)-(e)."

### Does a Texas lien waiver need to be notarized?

Only when the original contract was entered into before January 1, 2022. H.B. 2237 removed "and notarized" from Property Code 53.281(b), and its section 37 applies that change only to original contracts entered into on or after January 1, 2022.
