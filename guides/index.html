  3. Store the key as a script property

Use Endwise in Excel with Power Query (POST with a JSON body)

How it works
  1. Create an API key with a low monthly limit
  2. Open a blank query
  3. Paste the M code
  4. Set the data source to Anonymous
  5. Load the result and refresh with care

Yes, with Power Query in 4 parts: Web.Contents sends a POST, a Headers record carries Authorization: Bearer YOUR_API_KEY, Json.FromValue builds the body, and Json.Document reads the answer.
