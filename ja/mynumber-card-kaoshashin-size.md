# マイナンバーカードの顔写真を20KB〜7MBに収める方法

マイナンバーカード総合サイトによると、オンライン申請の顔写真はファイルサイズが20KB〜7MB、形式はjpeg、幅・高さとも480〜6000ピクセルである必要があります（2026年11月5日確認）。7MBを超えるときは、このツールで上限を7000KBにすると収まります。

## オンライン申請の顔写真の条件は？

マイナンバーカード総合サイトの「データの大きさに制限はありますか？」というよくある質問には、次の条件が書かれています。

マイナンバーカード総合サイト：オンライン申請の顔写真の条件

| 項目 | 条件 |
| --- | --- |
| ファイル形式 | jpeg、jpg（heicは不可） |
| ファイルサイズ | 20KB〜7MB |
| ピクセルサイズ | 幅480〜6000ピクセル、高さ480〜6000ピクセル |
| カラーモード | RGBカラー（CMYKカラー等は不可） |
| 撮影時期など | 6か月以内に撮影、正面・無帽・無背景 |

同じページには「画像編集ソフトで加工された画像などは、受け付けできない場合があります」という注意もあります。

## 7MBを超えたらどうする？

スマホの写真はたいてい7MBより小さく、私たちのテストで使った12メガピクセルの写真も2.08MBでした。その場合は圧縮の必要はありません。デジタルカメラなどで7MBを超えたときは、[上限7000KBでツールを開く](https://krishnachagti-sudo.github.io/toll-preview/ja/image-to-size/?kb=7000)と、7MB以下のJPEGにできます。無料で、写真はブラウザの外に出ません。

このツールは、すでに7MB以下のJPEGにはまったく手を加えず、そのまま返します。圧縮するのは、上限を超えているときだけです。

## 注意したい点

- 20KBの下限：ツールは写真を大きくしません。20KB未満になる場合は、撮り直してください。
- ピクセル数：このツールが調整するのはファイルサイズだけです。幅と高さが480〜6000ピクセルに入っているかは、ご自身で確認してください。上限が大きければ、ツールはピクセル数も変えません。
- 加工された画像：公式サイトが「受け付けできない場合がある」としているので、まずは撮影時の設定でサイズを下げられないか試してください。
- 1KBの数え方：ツールは1KBを1,000バイトで数えるので、7000KBは7,000,000バイト以下です。7MBを1,000,000バイト単位と考えても1,048,576バイト単位と考えても、収まります。

## 手順

1. **写真のサイズを確認する.** 写真ファイルのサイズを確認します。7MB（7,000KB）以下で、20KB以上なら、そのまま申請できる可能性があります。
2. **ツールを開く.** 上限を7000KBにして「画像をKB指定で圧縮」を開きます。ブラウザの中で動き、写真はアップロードされません。
3. **写真を選ぶ.** 7MBを超えているJPEGやPNGの写真を選びます。
4. **結果を確認して申請する.** 新しいサイズが20KB以上7MB以下か確認し、ダウンロードして、申請画面で選びます。

## よくある質問

### マイナンバーカードのオンライン申請の顔写真は何KBまで？

マイナンバーカード総合サイトによると、ファイルサイズは20KB〜7MB、形式はjpeg（heicは不可）、ピクセルサイズは幅480〜6000、高さ480〜6000、カラーモードはRGBカラーです（2026年11月5日確認）。

### 7MBを超えた写真はどうすればいいですか？

このツールで上限を7000KBにすると、7MB以下のJPEGにできます。ただし公式サイトは「画像編集ソフトで加工された画像などは、受け付けできない場合がある」とも書いているため、先に撮り直しや設定変更でサイズを下げられないか確認してください。

### 20KB未満の写真は大きくできますか？

いいえ。このツールは写真を大きくしません。20KB未満なら、解像度の高い設定で撮り直してください。

### 写真の縦横の比率や背景は直してくれますか？

いいえ。ファイルサイズを小さくするだけです。写真の条件（正面、無帽、無背景など）は公式の「顔写真のチェックポイント」で確認してください。
