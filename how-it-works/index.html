How it works

Top up once.
Pay per use.

One prepaid balance for every tool. Use a tool on its page, over the REST API or from an AI agent, and each use takes its price from that balance.

Four steps

From top-up
to exact answer.

  1. 01

    Top up once

    Add from $20 or ₹200. There is no subscription. Nothing renews and nothing tops itself up.

  2. 02

    Use any tool

    On its web page, through the REST API, or from an AI agent over MCP. One key and one balance for every tool.

  3. 03

    Pay per use

    Each use takes its price from your balance, often a fraction of a cent. Failed calls are refunded automatically.

  4. 04

    Set a hard limit

    On the account and on each API key. A call past the limit is refused, not billed.

What you pay

A price per use,
in plain words.

Each tool states its price in words, generated from the rules that charge you. Tools that run in your browser are free.

Most uses cost a fraction of a cent. Before you run anything, you can ask for a quote: it says the exact amount and charges nothing. See every price.
