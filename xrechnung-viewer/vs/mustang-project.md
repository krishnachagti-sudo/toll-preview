# Mustang Project oder dieser Viewer

Mustang ist eine quelloffene Java-Bibliothek und Kommandozeile (Apache-2.0, Version 2.26.0 vom 25.08.2026) zum Lesen, Schreiben, Prüfen und Umwandeln von ZUGFeRD 2.5 und XRechnung 3.0.2; dieser Viewer ist ein Werkzeug im Browser und per API zum Öffnen und Prüfen einzelner Dateien.

## Gegenüberstellung

| Merkmal | Mustang Project | Dieser Viewer |
| --- | --- | --- |
| Art | Java-Bibliothek, Kommandozeile; Mustangserver als bezahlte REST-API | Webseite, REST-API und MCP |
| Funktionen | lesen, schreiben, prüfen, CII in UBL umwandeln, PDF/A-1 in PDF/A-3 | lesen, nach Regeln prüfen, Fehlercodes erklären, PDF mit Prüfbericht |
| Lizenz und Preis | Apache-2.0, frei; Mustangserver kostenpflichtig (Preis auf der Seite nicht genannt) | Anzeige kostenlos; Prüfung $0.01, PDF mit Prüfbericht $0.03 je Datei |
| Voraussetzung | Java (JRE 11 für die Kommandozeile) | keine |

## Wann Mustang Project besser ist

Mustang ist besser für Entwickler, die E-Rechnungen in ihre Java-Software einbauen, sie erzeugen oder umwandeln wollen.

## Wann dieser Viewer besser ist

Dieser Viewer ist besser für eine schnelle Prüfung ohne Code und ohne Java, mit Klartext zu jedem Fehlercode.
