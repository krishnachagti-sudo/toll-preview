# PDF24 oder dieser Viewer

PDF24 ist ein kostenloser Generator zum Erstellen von E-Rechnungen (ZUGFeRD-PDF, XRechnung, Peppol, EN 16931) mit Verarbeitung auf Servern in Deutschland; dieser Viewer öffnet und prüft E-Rechnungen, die Sie erhalten oder erstellt haben.

## Gegenüberstellung

| Merkmal | PDF24 E-Rechnung erstellen (laut tools.pdf24.org) | Dieser Viewer |
| --- | --- | --- |
| Aufgabe | E-Rechnungen per Formular erstellen, PDF-Rechnungen per KI auslesen und umwandeln | E-Rechnungen öffnen, nach den offiziellen Regeln prüfen, als PDF ablegen |
| Kosten | kostenlos, durch Werbung finanziert | Anzeige kostenlos; Prüfung $0.01, PDF $0.03 |
| Verarbeitung | auf Servern in Deutschland, Dateien nach einer Stunde gelöscht | Anzeige im Browser; Prüfung im Speicher, nicht gespeichert |
| KI | ja, zum Auslesen von PDF-Rechnungen | nein, jedes Ergebnis kommt aus den veröffentlichten Regeln |

## Wann PDF24 besser ist

Wenn Sie selbst eine E-Rechnung erstellen wollen, ohne Rechnungssoftware zu kaufen. Eine so erstellte Datei können Sie hier anschließend prüfen.

## Wann dieser Viewer besser ist

Wenn Sie eine erhaltene E-Rechnung lesen oder wissen wollen, ob eine Datei die KoSIT- und EN-16931-Regeln erfüllt.
