# Several trucks on one IFTA return

Several trucks go on one IFTA return: one license covers the fleet, and the return adds every truck's miles and gallons for each fuel type into one fleet MPG. The calculator's 2-truck sample fleet logs 2,200 and 860 miles for 3,060 in all on 490 gallons, 6.24 MPG.

- Fleet MPG: 6.24
- Return: $28.16 credit

## One license, one return, two decals a truck

Your base jurisdiction issues one IFTA license for the carrier and two decals for each qualified vehicle (R605). The quarterly return covers the whole fleet: Total Distance is every mile of every qualified vehicle (R266), and the fleet MPG is worked out once for each fuel type.

## Keeping per-truck records

Every trip sheet and fuel receipt carries the unit number, so each truck can be checked on its own: its odometer readings should run trip to trip without gaps. ## Trucks on different fuels

A gasoline truck and a diesel truck in the same fleet are on the same return but in separate fuel sections, each with its own MPG. Vehicles that are not qualified motor vehicles (under 26,001 pounds with two axles, for example) stay off the return.

## Questions

### Do I file one IFTA return per truck?

No. One license covers every qualified vehicle in the fleet, with two decals per vehicle (R605), and one quarterly return covers them all. Total Distance is all miles "by every qualified vehicle in the licensee's fleet" (R266).

### Is the MPG per truck or per fleet?

Per fleet, for each fuel type: all miles of the vehicles on that fuel divided by all their gallons. In the sample, 3,060 miles / 490 gallons = 6.24.

### Do I still need records for each truck?

Yes. Trip sheets and fuel receipts must carry the vehicle unit or identification number (Idaho State Tax Commission), and an auditor checks each truck's odometer chain.
