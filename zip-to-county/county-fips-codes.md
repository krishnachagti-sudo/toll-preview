# County FIPS codes

A county FIPS code is 5 digits, the state's 2 and the county's 3: Harris County, Texas is 48201 (48 is Texas, 201 is Harris). The Census 2020 file lists 3,234 counties and county equivalents; Los Angeles County, CA (06037) has land in the most ZCTAs, 304.

- Counties and equivalents: 3,234
- With ZCTA land: 3,232
- Most ZCTAs: Los Angeles County, CA: 304

## Questions

### What is a county FIPS code?

A 5-digit code: the 2-digit state code and the 3-digit county code. Harris County, Texas is 48201.

### Which county has the most ZIP codes?

Los Angeles County, CA (06037), with land in 304 ZCTAs, then Cook County, IL (178) and Harris County, TX (143), per the Census 2020 ZCTA-county file.

### How many ZIP codes are in Harris County, Texas?

Harris County (48201) has land in 143 ZCTAs in the Census 2020 file; some of them extend into neighboring counties.

### Why does a FIPS code lose its leading zero in Excel?

A spreadsheet reads 01001 as the number 1001. Import the column as text, or rebuild it with =TEXT(A2,"00000").
