# Certificates for kids

The kids' design prints each child's name in large bold letters, up to 54 pt, under "Super Star Award" and "Hooray for", with a star border; 6 names make 6 certificate pages for $0.99, and the proof is free.

## Open the kids' design

[Open the certificate maker](https://krishnachagti-sudo.github.io/toll-preview/bulk-certificate-generator/?design=kids)

Name sizes on the kids' design, US Letter landscape.

| Name | Size | Fit |
| --- | ---: | --- |
| Mia | 54 pt | full size |
| Leo | 54 pt | full size |
| Olivia Brown | 54 pt | full size |
| Mateo Garcia | 54 pt | full size |
| Sophia Lee | 54 pt | full size |
| Benjamin Featherstone-Whitaker | 42.25 pt | made smaller |

First names alone work: a list with one Name column of first names prints just those. For a whole school, sort by class so each teacher's stack comes out together.

> Class lists are used to make the PDF and are not kept. The preview and the free proof are made in your browser; the clean PDF is made on the server, in memory, and the list is discarded with the answer.
