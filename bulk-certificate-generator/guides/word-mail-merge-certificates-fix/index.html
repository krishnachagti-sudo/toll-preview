Word certificate merge: same name on every page

A Word certificate merge that shows the same name on every page usually was printed before it was merged: Microsoft's steps end with Finish & Merge > Edit Individual Documents or Print Documents, which makes one certificate per row, so a list of 30 names gives 30 certificates; printing the template prints only the record in the preview.

Give up on Word when

  • the merge fields keep drifting out of their text boxes,
  • long names overflow and one size for all is too small for the short ones,
  • there are too many rows to check one by one.

Batch the same list here

One certificate per row, each name fitted; the proof is free.

Open these settings in the certificate maker

  • Microsoft Support: Use mail merge to personalize letters (read November 8, 2026)support.microsoft.com

Steps

  1. Finish the merge. Printing the document you designed prints what the preview shows: one record. Use Mailings > Finish & Merge > Edit Individual Documents (to check) or Print Documents.
  2. Check the preview record by record. Mailings > Preview Results, then Next. If Next does not change the name, the name on the page is typed text, not a merge field: delete it and use Insert Merge Field.
  3. Check the list. The first row of the sheet must be the headings; select the right sheet when Word asks, and look at Edit Recipient List for blank or hidden rows.
  4. Keep the connection. Save the merge document; when you open it again, choose Yes to keep the connection to the list.
