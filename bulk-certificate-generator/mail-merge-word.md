# Mail merge certificates in Word

In Word, a certificate mail merge takes 6 steps (Start Mail Merge \> Letters, Select Recipients, Insert Merge Field, Preview Results, Finish & Merge, Save); here it takes 2 (open the list, download), and each name is sized to fit: "Ana Ruiz" at 50 pt, "Maximiliana Featherstonehaugh-Worthington" at 33.25 pt.

## Where Word merges go wrong

- Printing the main document instead of finishing the merge prints one certificate. Use Finish & Merge.
- Preview Results shows one record at a time; use Next to check the long names, or Edit Individual Documents to see them all.
- The font size of the merge field is the same for every row, so the longest name decides it for everyone, or overflows its line.
- Each row is one certificate: two awards for one student need two rows.

## Steps

1. **Start the merge.** Open your certificate design in Word, then Mailings \> Start Mail Merge \> Letters.
2. **Select the list.** Mailings \> Select Recipients \> Use an Existing List, and pick the Excel workbook and its sheet.
3. **Insert the name field.** Click where the name goes, then Mailings \> Insert Merge Field and pick the name column. Add Award or other fields the same way.
4. **Preview.** Mailings \> Preview Results, then Next and Previous to check each record.
5. **Finish.** Finish & Merge \> Edit Individual Documents to check every certificate, or Print Documents to print them.
6. **Save.** Save the merge document; it stays connected to the list for next time.

## Questions

### How do I mail merge certificates in Word?

Mailings \> Start Mail Merge \> Letters; Select Recipients \> Use an Existing List; Insert Merge Field for the name; Preview Results; Finish & Merge \> Edit Individual Documents or Print Documents (Microsoft's steps for letters, which certificates follow).

### Why does a long name not fit in my Word certificate?

A merge field takes the font size of the template, so every name prints at the same size. Here each name gets its own size: "Ana Ruiz" prints at 50 pt and "Maximiliana Featherstonehaugh-Worthington" at 33.25 pt on the same design.
