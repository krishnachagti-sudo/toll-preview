What it reads

It is read the way a crawler reads it: the status and format, the sitemaps.org schema, the 50,000 URL and 50MB limits, every lastmod date, the host and folder rules, image and news tags, and robots.txt against every listed URL. Then a sample of the listed URLs is requested live to see which redirect, return an error, say noindex or name another URL as canonical.

One sitemap (an index and up to 10 of its files) with up to 10 URLs checked live is free on this page. Bigger checks need an account: $0.0005 per check, and $0.0001 per check after 20,000 in a month, where a check is one sitemap file read or one URL requested live. Pasting XML is free.

Free, in your browser

Not online yet? Paste the XML.

Paste a sitemap or index (or a text sitemap, one URL per line). It is checked in your browser by the same rules, with nothing sent anywhere. Add the address it will live at to check the host and folder rules too. Free.

The rules

What it checks, file, entries and URLs.

The sitemaps.org protocol and Google's sitemap docs, with problems named as the Search Console Sitemaps report names them.

What it does not cover

Google's own crawl schedule, how a server answers Googlebot rather than us, and tags added by JavaScript.

Read the full list
  • A check shows what each server answered at that moment, to one request from our server in the United States. Servers can answer Googlebot, other countries or signed-in visitors differently, and some block automated requests.
  • Search Console is the record of what Google fetched and parsed. This check cannot see Google's crawl schedule, crawl demand or manual actions, so a clean result here does not make "Couldn't fetch" go away by itself.
  • The lastmod sanity flags (future dates, one date on nearly every URL, dates later than the file) are our own heuristics, not Google's rules.
  • noindex and canonical are read from the HTML the server sends (the first 256 kB) and from the X-Robots-Tag and Link headers; tags added by JavaScript are not seen.
  • Private, local, link-local (cloud metadata) and reserved addresses are never fetched, on any hop; only ports 80, 443, 8080 and 8443 are used. Check only sites you own or work on.

The file

Answers 200 with well-formed XML, at most 50,000 URLs and 50MB uncompressed.

Read the full rules

That the address answers 200 with XML, not a login or an HTML page; gzip; UTF-8; well-formed XML with line numbers (a bare & is the usual culprit); the sitemaps.org namespace and tags; at most 50,000 URLs and 50MB (52,428,800 bytes) uncompressed; and for an index, at most 50,000 sitemaps, no index inside an index.

The entries

Absolute URLs on the sitemap's own host and folder, and real lastmod dates.

Read the full rules

Absolute, escaped URLs under 2,048 characters on the sitemap's own protocol and host (www included), inside its folder; duplicates; lastmod in W3C Datetime (a time needs a time zone); changefreq and priority values; image and news tags. Sanity flags for lastmod (our heuristic): future dates, and one date on nearly every URL.

The URLs

robots.txt against every URL; redirects, errors, noindex and canonical on the ones checked live.

Read the full rules

robots.txt run against every listed URL, and the sitemap itself, as Googlebot reads it. For the URLs checked live: redirects, 404s and other errors, noindex in a robots meta tag or an X-Robots-Tag header, and a rel=canonical that names a different URL.
