# Guides

Practical guides to getting exact answers from your AI assistant, your code editor, your own agent or the tools directly. Every tool they use runs free 5 times a day without an account.

- [How to use Endwise with Claude (Claude Code and apps)](https://krishnachagti-sudo.github.io/toll-preview/guides/use-with-claude/): Connect to Claude Code with one command, see what the Claude apps allow today, try a first prompt, and keep spend under control.
- [Does Endwise work with ChatGPT? What works today](https://krishnachagti-sudo.github.io/toll-preview/guides/use-with-chatgpt/): What works today when you want ChatGPT to call exact tools: the MCP connector limits, a custom GPT Action with an API key, and the OpenAI API from code.
- [How to add Endwise to Cursor and VS Code (MCP)](https://krishnachagti-sudo.github.io/toll-preview/guides/use-in-cursor-and-vs-code/): Exact mcp.json files for Cursor and VS Code with a Bearer key, how to keep keys out of git, and how to check it works.
- [Give your own AI agent exact tools: 3 ways](https://krishnachagti-sudo.github.io/toll-preview/guides/build-an-agent/): For developers: three ways to give an agent exact tools (Anthropic MCP connector, OpenAI remote MCP, REST function calling), with samples, per-agent keys, quotes and error handling.
- [Why AI assistants get dates and numbers wrong](https://krishnachagti-sudo.github.io/toll-preview/guides/why-ai-gets-numbers-wrong/): Why language models miss on dates, holidays, rates and tax figures, shown with worked cases, and how to give an assistant a tool that gets them exactly.
- [How to check a number an AI gives you](https://krishnachagti-sudo.github.io/toll-preview/guides/check-numbers-from-ai/): A short procedure for checking a date, rate or tax figure from an AI assistant, with what to test for each kind of number.
- [Pay per use or a subscription: which costs less](https://krishnachagti-sudo.github.io/toll-preview/guides/pay-per-use-or-subscription/): The break-even formula for pay per use against a subscription, worked with Endwise prices: when per use wins and when a pass wins.
