# Guides

Practical guides to getting exact answers from your AI assistant, your code editor, your spreadsheet, your automations, your own agent or the tools directly. Every tool they use runs free 5 times a day without an account.

- [How to use Endwise with Claude (Claude apps and Claude Code)](https://krishnachagti-sudo.github.io/toll-preview/guides/use-with-claude/): Add Endwise as a custom connector, sign in and approve it with a monthly limit, try a first prompt, and keep spend under control.
- [How to use Endwise with ChatGPT](https://krishnachagti-sudo.github.io/toll-preview/guides/use-with-chatgpt/): Add Endwise to ChatGPT as a custom MCP server, sign in and approve it with a monthly limit, and call the same tools from the OpenAI API.
- [How to add Endwise to Cursor and VS Code (MCP)](https://krishnachagti-sudo.github.io/toll-preview/guides/use-in-cursor-and-vs-code/): Exact mcp.json files for Cursor and VS Code with a Bearer key, how to keep keys out of git, and how to check it works.
- [Give your own AI agent exact tools: 3 ways](https://krishnachagti-sudo.github.io/toll-preview/guides/build-an-agent/): For developers: three ways to give an agent exact tools (Anthropic MCP connector, OpenAI remote MCP, REST function calling), with samples, per-agent keys, quotes and error handling.
- [Use Endwise in Google Sheets: custom functions with Apps Script](https://krishnachagti-sudo.github.io/toll-preview/guides/google-sheets/): Apps Script code for Sheets: custom functions, a menu command that writes values, the API key kept in script properties, and no double charges on recalculation.
- [Use Endwise in Excel with Power Query (POST with a JSON body)](https://krishnachagti-sudo.github.io/toll-preview/guides/excel/): Power Query M code for Excel: a POST with a Bearer header and Json.FromValue body, a reusable function for table rows, and how to avoid paying again on refresh.
- [Use Endwise in Zapier, Make and n8n (one HTTP step)](https://krishnachagti-sudo.github.io/toll-preview/guides/zapier-make-n8n/): One HTTP step in Zapier (Webhooks), Make (HTTP) and n8n (HTTP Request): URL, Authorization header, JSON body, result mapping and retry safety.
- [Why AI assistants get dates and numbers wrong](https://krishnachagti-sudo.github.io/toll-preview/guides/why-ai-gets-numbers-wrong/): Why language models miss on dates, holidays, rates and tax figures, shown with worked cases, and how to give an assistant a tool that gets them exactly.
- [How to check a number an AI gives you](https://krishnachagti-sudo.github.io/toll-preview/guides/check-numbers-from-ai/): A short procedure for checking a date, rate or tax figure from an AI assistant, with what to test for each kind of number.
- [Pay per use or a subscription: which costs less](https://krishnachagti-sudo.github.io/toll-preview/guides/pay-per-use-or-subscription/): The break-even formula for pay per use against a subscription, worked with Endwise prices: when per use wins and when a pass wins.
- [A spreadsheet or Endwise: which to use](https://krishnachagti-sudo.github.io/toll-preview/guides/spreadsheet-or-endwise/): An honest comparison of a spreadsheet and Endwise for business days, exchange rates, mileage, per diem and 1099 thresholds, including when the spreadsheet wins.
