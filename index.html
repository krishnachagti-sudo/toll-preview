Connect your agent

Three steps. Same tools and same prices as the API.

Endwise runs an MCP server over Streamable HTTP. Apps that support MCP sign-in connect with just the address. Other clients use an API key.

Building your own agent? The same tools are on the REST API: POST /toll-preview/api/v1/tools/<tool>, with the OpenAPI document.

The full MCP guide

  1. 01

    Add the address

    In the Claude apps, add it as a custom connector. In ChatGPT, add it as a custom MCP server.

    /toll-preview/mcp
  2. 02

    Sign in with OAuth, or use a key

    Sign-in opens a Endwise page where you approve the app and set its monthly limit. Other clients send an API key as a Bearer token.

  3. 03

    List, then call

    Listing tools needs nothing. Each call is priced and limited exactly like an API call, and a call that fails is refunded.

FAQ

Questions, answered plainly

More detail is in the docs.

Is there a subscription?

No. You can top up from $10 and each call takes its price from that balance. Firms can buy a plan for a year instead. Nothing renews unless you opt in, and nothing tops itself up.

Can I try it without an account?

Yes. You get 5 free runs a day without an account. With an account you also get $0.25 free each month, spent before your own money.

Can a bug in my code drain my balance?

Set a hard monthly limit on your account and on each API key. A call past the limit is refused, not billed.

What happens if a call fails?

It is refunded automatically.

What if the ECB did not publish a rate on my date?

You get the last fixing before that date, and the answer tells you which day it came from. For example, USD to EUR on Saturday 24 Oct 2026 returns 0.893416 from the Friday 23 Oct 2026 fixing. A day with no rate costs nothing.

Do you use AI to get the answers?

No. Every answer comes from a fixed method and a named source, so the same input always gives the same answer.

Do you track me?

There are no ad or analytics trackers. IP addresses are not stored. Visitor counting uses a daily hash that is deleted the next day. The privacy page lists everything we keep.

Need a tool we don't have?

Tell us the job. One sentence is enough. Add an email if you would like to hear back.
