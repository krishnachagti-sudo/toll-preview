Overview

Press kit

Endwise is a product of Conyso Holdings: small tools that each do one job, give the same answer every time, and are paid for per use, with no AI in the answers. You can use them in 3 ways: on the web, over a REST API, or through MCP. This page has the description, the logo, the colors and how to write the name.

What is Endwise?

Endwise gives exact answers for specific jobs, such as a sourced rate, date or tax figure, for you and for your AI.

Each tool answers one question exactly and shows how it got there: the holidays it skipped, the date of the rate it used. Each follows a fixed method over a named official source, so the same input always gives the same answer. There is no AI model in any answer.

Who makes it?

Endwise is built and run by Conyso Holdings. More about the company is on the about page.

How does it work?

  • No AI in the answers. A fixed method over a named official source gives the same answer for the same input.
  • Pay per use. You add money to one balance and each use is taken from it. There is no subscription. Every tool runs 5 times a day on its page without an account.
  • Three ways in. Use the tool on its web page, call it over a REST API with an API key, or connect an AI assistant over MCP (Model Context Protocol, a standard way for assistants to call tools).
