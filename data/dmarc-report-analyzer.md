# DMARC report analyzer: CSV downloads

1 table from the DMARC report analyzer can be downloaded here as CSV, each with the same rows as its page, a data date and a named official source.

## Which files can you download?

Data date 2026-11-08.

- [DMARC aggregate report example (RFC 9990 and RFC 7489), parsed](https://krishnachagti-sudo.github.io/toll-preview/dmarc-report-analyzer/dmarc-report-example/) ([CSV](https://krishnachagti-sudo.github.io/toll-preview/dmarc-report-analyzer/dmarc-report-example.csv))

## What is in the files?

Each file is the table from the page next to it, as a CSV with a header row, in UTF-8, with CRLF line ends. [All data downloads](https://krishnachagti-sudo.github.io/toll-preview/data/) says more about the format and how you may reuse the files.

## Questions

### What format are the downloads?

Plain CSV: a header row, then one row per line of the table, with commas between fields. Fields that contain a comma, a quote or a line break are quoted, and line ends are CRLF.
