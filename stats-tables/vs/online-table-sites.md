# Free online table sites and computed values

Free table pages answer the common lookups (t = 2.228 for 10 df, two-sided 0.05), but most print fixed rows: Math is Fun's t table jumps from df 30 to 40, so df 45 (t = 2.0141) is not on it; computed values cover any df.

## What we read

- Math is Fun's Student's t table: df 1 to 30, then 40 to 100 by tens, 1000 and 10000, mostly 3 decimals, ten one-tail and two-tail columns; no formula, download or API is offered on the page.
- Statology's t distribution table is an image of the table, so its values cannot be copied as text; no method or API is shown.
- MetricGate describes itself as AI-powered statistical analysis with R. Its pricing page lists Basic at $0/month (10 runs a month), Plus $15, Pro $39 and Premium $99 a month, and an MCP connector that lets AI apps run its calculators.
- SQC Online says all its calculators are now free, for acceptance sampling, control charts and capability, and that the offer may change.

## When these sites are better

For a student who wants one value from a familiar page, a free table is quick and fine. MetricGate is better if you want an AI assistant and R running analyses on your own datasets. SQC Online covers acceptance-sampling standards that these pages do not.

## What computed values add

- Every df and alpha, not only printed rows, to about ten significant digits, with the method stated.
- Each value is tested against the NIST/SEMATECH e-Handbook table it would come from.
- The same answers over REST and MCP at $0.0005 a call (free on this site's pages), with no subscription.
