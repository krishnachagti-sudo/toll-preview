# Minitab and these statistical tables

Minitab Solution Center Core costs $2,394.00 per user per year on Minitab's own page, and its help tabulates d3 only for n = 2 to 25; these tables compute d2 and d3 for any n to 100 (d3 = 0.6052 at n = 100), free on the web.

## What Minitab is

- Minitab's buy page (read November 8, 2026) lists Minitab Solution Center as a single named user annual subscription: Core $2,394.00, Analytics $2,593.50 and Copilot $2,793.00 per year, with modules such as Measurement System Analysis at $528 a year.
- Its help page on unbiasing constants lists d2, d3 and d4 for N = 2 to 25, d2 alone for N = 26 to 50, and approximations for larger N, citing Harter (1960) and Wheeler and Chambers (1992).

## When Minitab is better

For full SPC work: running real control charts on your data with run rules, capability studies with graphs, measurement system analysis and hypothesis tests, all in one place with reports. These tables do not draw charts, store your data or run studies.

## What these tables do differently

- Every constant for every n from 2 to 100 from its definition, including d3 past n = 25 (d3 = 0.6927 at n = 30), with the formula and method shown.
- Critical values and p-values for z, t, chi-square and F at any degrees of freedom, to about ten significant digits.
- Control limits, Cp/Cpk/Pp/Ppk, sigma level and OC curves from your numbers, in the browser for free, or over a REST API or MCP for $0.0005 a call.
