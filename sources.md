# Sources and how we check the answers

Every answer comes from a named official source and a stated data date, with no AI in between. The data behind the tools was read between 2026-10-30 and 2026-11-08; each tool's sources, editions and checks are linked below.

## How does every answer get made?

- The tools are deterministic: the same input gives the same answer, every time. Nothing in an answer is generated or estimated by a model.
- The data is read from an official source by a person, stored with its edition and the day it was read, and changes only when the data is updated.
- An answer names the data date or the source it used, and each tool reports a data version.
- A date, year or place the data does not cover is refused with the reason, not guessed.

[The data updates page](https://krishnachagti-sudo.github.io/toll-preview/updates/) lists each change to the data and rules, with its date.

## Where does each tool's data come from?

Data was read between 2026-10-30 and 2026-11-08, as dated in each tool's table.

Each tool's methodology page lists every source it reads, with the edition and the day it was read, next to the method that uses it, and says how fresh the data is. The table below links straight to it.

## How do we check the answers?

Each tool's test suite compares its answers with the sources above. Only what a test asserts is listed, on the tool's methodology page under how it is tested; the last column of the table links each list. Where a tool has no official worked example to compare with, the list says what is checked instead.

## Questions

### Where does the data behind an answer come from?

From a named official source: a government agency, a central bank or a standards body. This page lists each source with its edition and the day it was read.

### How do I know an answer is current?

Each tool has a data version that names the data it used, and an answer that depends on a source names it. The data updates page lists when data went in or a rule changed.

### Is there any AI in the answers?

No. The same input gives the same answer, worked out by fixed rules from the data above.

### What if a source is not available for a date or a year?

The tool refuses and says why, and the call costs nothing. It does not guess.
