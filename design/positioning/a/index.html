Why AI guesses

A model writes the likely answer.
Some jobs have only one right one.

01

It predicts text. It does not run the rule.

A deadline or a business-day count needs every weekend and holiday checked in turn. A model can write a tidy answer without doing that check.

02

Its knowledge stops at a cutoff.

A rate, threshold or deadline that changed after that date may not be in the model at all, and the model will not always tell you so.

03

It may not show its working.

A single number with no rule, no date and no named source gives you nothing to check, and a wrong guess here costs money.

  • 1099-NEC lineFor 2026 payments the line is $2,000; for 2025 payments it was $600, from the IRS instructions. A model whose knowledge predates the change would give $600 for a 2026 payment.
  • IRS mileage rateA business trip on June 30, 2026 is 72.5 cents a mile, and 76 cents from July 1. One rate for the whole year is wrong for half of it.
  • IFTA due dateThe third quarter 2026 IFTA return is due November 2, 2026, not October 31, because the statutory date falls on a weekend.

Connect your agent

Three steps. Same tools and same prices as the API.

Endwise runs an MCP server over Streamable HTTP. Apps that support MCP sign-in connect with just the address. Other clients use an API key.

Building your own agent? The same tools are on the REST API: POST /api/v1/tools/<tool>, with the OpenAPI document.

The full MCP guide

  1. 01

    Add the address

    In the Claude apps, add it as a custom connector. In ChatGPT, add it as a custom MCP server.

    https://krishnachagti-sudo.github.io/toll-preview/mcp
  2. 02

    Sign in with OAuth, or use a key

    Sign-in opens an Endwise page where you approve the app and set its monthly limit. Other clients send an API key as a Bearer token.

  3. 03

    List, then call

    Listing tools needs nothing. Each call is priced and limited exactly like an API call, and a call that fails is refunded.
