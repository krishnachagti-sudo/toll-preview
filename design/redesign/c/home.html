06Questions
Is there a subscription?

No. You top up from $10 and each call takes its price from that balance. Nothing renews, and nothing tops itself up.

Can I try it without an account?

Yes. You get 5 free runs a day without an account. With an account you also get $0.25 free each month, spent before your own money.

Can a bug in my code drain my balance?

Set a hard monthly limit on your account and on each API key. A call past the limit is refused, not billed.

What happens if a call fails?

It is refunded automatically.

What if the ECB did not publish a rate on my date?

You get the last fixing before that date, and the answer tells you which day it came from. A day with no rate costs nothing.

Do you use AI to get the answers?

No. Every answer comes from a fixed method and a named source, so the same input always gives the same answer.

Do you track me?

There are no ad or analytics trackers. IP addresses are not stored. Visitor counting uses a daily hash that is deleted the next day.

Need a tool we don't have?

Tell us the job. One sentence is enough. Add an email if you would like to hear back.
