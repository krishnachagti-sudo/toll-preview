How it is measured

What a check is,
and what it cannot see.

A check runs a tool's first worked example through the same validation, pricing rules and run as an API call, with no account behind it. No balance is touched and no charge or refund is written. It passes when the run finishes without an error within 30 seconds. It does not compare the answer with the example's.

The checks run inside the server. If the whole server is down, nothing is recorded, so this page cannot say so while it happens; those hours show later as fewer checks or a day with no data. There is no outside monitor behind this page.

This is a record of what was measured, not a promise. There is no uptime guarantee. Checks are kept for 90 days.

The server started once in the last 90 days (deploys and restarts), most recently at 2026-11-09 13:25 UTC.

The same record as JSON, with every day's counts, needs no key: GET /toll-preview/api/v1/status.
