ECB exchange rate API for any date

POST /api/v1/tools/fx-on-date with base USD, quote EUR and date 2026-10-24 returns rate 0.893416 and fixingDate 2026-10-23, the ECB reference rate and the fixing it came from, for $0.001.

Try the same call in the browser

The tool page runs the same code as the API and shows a ready-to-copy request in curl, JavaScript, Python and MCP.

A weekend or holiday uses the last fixing before it.

Open these dates in the full tool

The request

Send a POST with a JSON body to /api/v1/tools/fx-on-date on this site, with your key as a Bearer token in the Authorization header. The docs cover keys, errors, idempotency and rate limits.

FieldTypeExampleMeaning
basestringUSDThree-letter code of the currency you convert from.
quotestringEURThree-letter code of the currency you convert to.
datestring2026-10-24The day, written YYYY-MM-DD, from 1999-01-04.
sourcestringecbOptional. ecb (the default) for the ECB reference rate; treasury, irs or hmrc for the US Treasury reporting rate, the IRS yearly average or the HMRC monthly rate, which answer with the publication and period used instead of fixingDate.

The answer

The result sits inside the usual envelope with what the call cost, your balance and the data version (the latest ECB fixing the server holds).

FieldExampleMeaning
base, quoteUSD, EURThe pair you asked for.
requestedDate2026-10-24The date you asked for.
fixingDate2026-10-23The ECB fixing used: the same day, or the last one up to 7 days before it.
rate0.893416Units of quote per one base, rounded half away from zero to 6 decimals.
inverse1.1193Units of base per one quote, from the unrounded rate.

For AI agents over MCP

The same tool is available to AI agents through the MCP endpoint at /mcp on this site. Its MCP name is fx-on-date and its input is the same fields; calls are priced and limited like API calls. Connection details are in the docs.

StatusCodeWhenCharged
400invalid_inputA code that is not three capital letters, an unknown currency, or a date that is not real.No

How these rates are made

The European Central Bank publishes how many units of each currency one euro buys, usually at around 16:00 CET on every TARGET working day. A rate between two other currencies is worked out from the same day's fixing: units of the second per euro divided by units of the first per euro, rounded half away from zero to 6 decimal places. The inverse comes from the unrounded rate.

A weekend or TARGET holiday has no fixing, so a date like that uses the last fixing before it, up to 7 days back, and the tool names the day it used. Averages here are the mean of the daily rates, each as the tool reports it, rounded to 6 decimal places.

These are ECB reference rates. The ECB publishes them for information only and discourages their use for transactions. They are not the rate a bank, card or money transfer service charges.

Questions

What does a call return on a weekend date?

The last ECB fixing before it, and fixingDate says which day that was. For USD to EUR on 2026-10-24 (a Saturday) the answer is 0.893416 from the fixing of 2026-10-23.

Am I charged when there is no rate?

No. A date with no fixing in the 7 days before it, a date before 4 January 1999, or a working day the ECB has not published yet returns not_available and costs nothing.
