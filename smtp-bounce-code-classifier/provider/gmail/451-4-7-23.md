# Gmail 451 4.7.23

451 4.7.23 is a policy rejection: Gmail's published text "doesn't have a PTR record, or the PTR record's forward DNS entry" means: your sending IP lacks a matching PTR record, so Gmail rate limits it; publish matching reverse and forward DNS for the sending IP.

- Verdict: policy
