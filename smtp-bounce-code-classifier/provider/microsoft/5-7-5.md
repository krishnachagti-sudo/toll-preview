# Microsoft 5.7.5

5.7.5 is a policy rejection: Microsoft's published text "Remote certificate failed MTA-STS validation" means: the destination server's certificate failed the domain's MTA-STS check; the recipient domain must fix its certificate; do not suppress.

- Verdict: policy
