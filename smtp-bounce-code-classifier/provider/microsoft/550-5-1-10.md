# Microsoft 550 5.1.10

550 5.1.10 is a hard bounce: Microsoft's published text "Recipient not found" means: Microsoft's SMTP address lookup did not find the recipient; suppress the address.

- Verdict: hard

## What to do

- **hard:** Suppress the address.

IANA registers X.1.10 as "Recipient address has null MX". IANA defines X.1.10 as "Recipient address has null MX", which on its own would be hard; Microsoft uses 5.1.10 for something else ("recipient not found"), so the text decides.

> Verdicts follow the RFCs, the IANA registry and each provider's published texts as read on November 8, 2026; receivers change their texts without notice. Suppression is your decision: a verdict is a rule-based recommendation, not proof that an address is valid or invalid.
