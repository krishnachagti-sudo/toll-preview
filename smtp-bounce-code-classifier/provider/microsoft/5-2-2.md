# Microsoft 5.2.2

5.2.2 is a policy rejection: Microsoft's published text "Submission quota exceeded" means: the sender passed Microsoft's recipient or message rate limit; wait for the limit to reset; check for compromise.

- Verdict: policy

## What to do

- **policy:** Wait for the limit to reset; check for compromise.

IANA registers X.2.2 as "Mailbox full". IANA defines X.2.2 as "Mailbox full", which on its own would be soft; Microsoft uses 5.2.2 for something else ("submission quota exceeded"), so the text decides.
