# Microsoft 5.1.8

5.1.8 is a block: Microsoft's published text "bad outbound sender" means: the sending account was blocked for sending spam (often a compromised account); secure the account and ask for it to be unblocked; do not suppress recipients.

- Verdict: block

## What to do

- **block:** Secure the account and ask for it to be unblocked; do not suppress recipients.

IANA registers X.1.8 as "Bad sender's system address". IANA defines X.1.8 as "Bad sender's system address", which on its own would be policy; Microsoft uses 5.1.8 for something else ("bad outbound sender"), so the text decides.
