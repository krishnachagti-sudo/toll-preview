# Microsoft 5.7.501

5.7.501 is a block: Microsoft's published text "spam abuse detected" means: the sending account was banned for spam; resolve the account issue with support; do not suppress recipients.

- Verdict: block

- **block:** Resolve the account issue with support; do not suppress recipients.
