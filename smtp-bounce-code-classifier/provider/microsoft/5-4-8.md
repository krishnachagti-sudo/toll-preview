# Microsoft 5.4.8

5.4.8 is a policy rejection: Microsoft's published text "failed MTA-STS validation" means: the destination MX host is not listed in the domain's MTA-STS policy; the recipient domain must fix its MTA-STS policy; do not suppress.

- Verdict: policy
