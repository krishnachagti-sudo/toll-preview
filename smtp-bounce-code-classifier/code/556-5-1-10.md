# 556 5.1.10: what it means and what to do

556 5.1.10 is a hard bounce: IANA defines X.1.10 as "Recipient address has null MX"; suppress the address now. Microsoft publishes 1 text with it.

- Verdict on its own: hard
- Published texts: 1

## The codes, part by part

| Part | Value | Meaning | Source |
| --- | --- | --- | --- |
| Reply code | `556` | The domain does not accept mail (reported by a relay without connecting, for example after finding a null MX) | RFC 7504 |
| Class | `5.X.X` | Permanent Failure | RFC 3463 |
| Subject | `X.1.X` | Addressing Status | RFC 3463 |
| Detail | `X.1.10` | Recipient address has null MX | RFC 7505, RFC 7504 |

**IANA X.1.10:** This status code is returned when the associated address is marked as invalid using a null MX.

IANA lists the reply codes used with it as: undefined.

## What to do

**Hard bounce.** Suppress the address now; it does not exist or will never accept mail.

## Questions

### What does 556 5.1.10 mean?

The reply code 556 means "The domain does not accept mail (reported by a relay without connecting, for example after finding a null MX)" (RFC 7504). The enhanced code 5.1.10 is IANA X.1.10, "Recipient address has null MX", in class 5 (Permanent Failure).

### Is 556 5.1.10 a hard or soft bounce?

It is classed hard: Suppress the address at once.
