# 550 5.2.1: what it means and what to do

550 5.2.1 is a hard bounce: IANA defines X.2.1 as "Mailbox disabled, not accepting messages"; suppress the address now. Gmail publishes 2 texts with it, classed hard, soft: classify the full reply.

- Verdict on its own: hard
- Published texts: 2

## The codes, part by part

| Part | Value | Meaning | Source |
| --- | --- | --- | --- |
| Reply code | `550` | Requested action not taken: mailbox unavailable (e.g., mailbox not found, no access, or command rejected for policy reasons) | RFC 5321 |
| Class | `5.X.X` | Permanent Failure | RFC 3463 |
| Subject | `X.2.X` | Mailbox Status | RFC 3463 |
| Detail | `X.2.1` | Mailbox disabled, not accepting messages | RFC 3463 |

**IANA X.2.1:** The mailbox exists, but is not accepting messages. This may be a permanent error if the mailbox will never be re-enabled or a transient error if the mailbox is only temporarily disabled.

IANA lists the reply codes used with it as: undefined.

## What to do

**Hard bounce.** Suppress the address now; it does not exist or will never accept mail.

## Questions

### What does 550 5.2.1 mean?

The reply code 550 means "Requested action not taken: mailbox unavailable (e.g., mailbox not found, no access, or command rejected for policy reasons)" (RFC 5321). The enhanced code 5.2.1 is IANA X.2.1, "Mailbox disabled, not accepting messages", in class 5 (Permanent Failure).

### Is 550 5.2.1 a hard or soft bounce?

It depends on the text: on its own the code is classed hard, but the texts published with it are classed hard, soft. Classify the full reply.
