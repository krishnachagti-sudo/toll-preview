# 503 5.5.1: what it means and what to do

503 5.5.1 is a policy rejection: IANA defines X.5.1 as "Invalid command"; do not suppress the address; fix the sending setup. Gmail publishes 1 text with it.

- Verdict on its own: policy
- Published texts: 1

## The codes, part by part

| Part | Value | Meaning | Source |
| --- | --- | --- | --- |
| Reply code | `503` | Bad sequence of commands | RFC 5321 |
| Class | `5.X.X` | Permanent Failure | RFC 3463 |
| Subject | `X.5.X` | Mail Delivery Protocol Status | RFC 3463 |
| Detail | `X.5.1` | Invalid command | RFC 3463 |

**IANA X.5.1:** A mail transaction protocol command was issued which was either out of sequence or unsupported. This is useful only as a permanent error.

IANA lists the reply codes used with it as: undefined.

## What to do

**Policy.** Do not suppress the address: a rule your sending setup breaks (authentication, TLS, format, size or relay) refused it. Fix the setup, then resend.

## Questions

### What does 503 5.5.1 mean?

The reply code 503 means "Bad sequence of commands" (RFC 5321). The enhanced code 5.5.1 is IANA X.5.1, "Invalid command", in class 5 (Permanent Failure).

### Is 503 5.5.1 a hard or soft bounce?

It is classed policy: Keep the address. Fix the sending setup (authentication, TLS, size, format or relay), then resend.
