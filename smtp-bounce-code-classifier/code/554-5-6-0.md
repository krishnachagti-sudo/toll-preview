# 554 5.6.0: what it means and what to do

554 5.6.0 is a policy rejection: IANA defines X.6.0 as "Other or undefined media error"; do not suppress the address; fix the sending setup. Gmail publishes 1 text with it.

- Verdict on its own: policy
- Published texts: 1

## The codes, part by part

| Part | Value | Meaning | Source |
| --- | --- | --- | --- |
| Reply code | `554` | Transaction failed (or, at connection opening, "No SMTP service here") | RFC 5321 |
| Class | `5.X.X` | Permanent Failure | RFC 3463 |
| Subject | `X.6.X` | Message Content or Media Status | RFC 3463 |
| Detail | `X.6.0` | Other or undefined media error | RFC 3463 |

**IANA X.6.0:** Something about the content of a message caused it to be considered undeliverable and the problem cannot be well expressed with any of the other provided detail codes.

IANA lists the reply codes used with it as: undefined.

## What to do

**Policy.** Do not suppress the address: a rule your sending setup breaks (authentication, TLS, format, size or relay) refused it. Fix the setup, then resend.

## Questions

### What does 554 5.6.0 mean?

The reply code 554 means "Transaction failed (or, at connection opening, "No SMTP service here")" (RFC 5321). The enhanced code 5.6.0 is IANA X.6.0, "Other or undefined media error", in class 5 (Permanent Failure).

### Is 554 5.6.0 a hard or soft bounce?

It is classed policy: Keep the address. Fix the sending setup (authentication, TLS, size, format or relay), then resend.
