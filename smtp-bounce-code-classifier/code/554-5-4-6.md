# 554 5.4.6: what it means and what to do

554 5.4.6 is a policy rejection: IANA defines X.4.6 as "Routing loop detected"; do not suppress the address; fix the sending setup. Gmail and Microsoft publish 2 texts with it.

- Verdict on its own: policy
- Published texts: 2

## The codes, part by part

| Part | Value | Meaning | Source |
| --- | --- | --- | --- |
| Reply code | `554` | Transaction failed (or, at connection opening, "No SMTP service here") | RFC 5321 |
| Class | `5.X.X` | Permanent Failure | RFC 3463 |
| Subject | `X.4.X` | Network and Routing Status | RFC 3463 |
| Detail | `X.4.6` | Routing loop detected | RFC 3463 |

**IANA X.4.6:** A routing loop caused the message to be forwarded too many times, either because of incorrect routing tables or a user- forwarding loop. This is useful only as a persistent transient error.

IANA lists the reply codes used with it as: undefined.

## What to do

**Policy.** Do not suppress the address: a rule your sending setup breaks (authentication, TLS, format, size or relay) refused it. Fix the setup, then resend.

## What Gmail and Microsoft say with 5.4.6

Gmail and Microsoft publish 2 texts with this code. The tool matches the phrase, so the same code can get different verdicts:

| Provider | Code | Published text | Verdict | Meaning |
| --- | --- | --- | --- | --- |
| Gmail | `554 5.4.6` | `Message exceeded 50 hops` | policy | The message passed through more than 50 hops: probably a mail loop. |
| Microsoft | `5.4.6` | `Routing loop detected` | policy | A configuration error caused a mail loop. |

> IANA says X.4.6 (routing loop) is useful only as a persistent transient error, yet this reply uses class 5.

## Questions

### What does 554 5.4.6 mean?

The reply code 554 means "Transaction failed (or, at connection opening, "No SMTP service here")" (RFC 5321). The enhanced code 5.4.6 is IANA X.4.6, "Routing loop detected", in class 5 (Permanent Failure).

### Is 554 5.4.6 a hard or soft bounce?

It is classed policy: Keep the address. Fix the sending setup (authentication, TLS, size, format or relay), then resend.
