What to do

Hard bounce. Suppress the address now; it does not exist or will never accept mail.

Questions

What does 550 5.1.0 mean?

The reply code 550 means "Requested action not taken: mailbox unavailable (e.g., mailbox not found, no access, or command rejected for policy reasons)" (RFC 5321). The enhanced code 5.1.0 is IANA X.1.0, "Other address status", in class 5 (Permanent Failure).

Is 550 5.1.0 a hard or soft bounce?

It is classed hard: Suppress the address at once.
