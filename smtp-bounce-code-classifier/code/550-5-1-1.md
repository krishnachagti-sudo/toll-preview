# 550 5.1.1: what it means and what to do

550 5.1.1 is a hard bounce: IANA defines X.1.1 as "Bad destination mailbox address"; suppress the address now. Gmail and Microsoft publish 2 texts with it.

- Verdict on its own: hard
- Published texts: 2

## The codes, part by part

| Part | Value | Meaning | Source |
| --- | --- | --- | --- |
| Reply code | `550` | Requested action not taken: mailbox unavailable (e.g., mailbox not found, no access, or command rejected for policy reasons) | RFC 5321 |
| Class | `5.X.X` | Permanent Failure | RFC 3463 |
| Subject | `X.1.X` | Addressing Status | RFC 3463 |
| Detail | `X.1.1` | Bad destination mailbox address | RFC 3463 |

**IANA X.1.1:** The mailbox specified in the address does not exist. For Internet mail names, this means the address portion to the left of the "@" sign is invalid. This code is only useful for permanent failures.

IANA lists the reply codes used with it as: undefined.

## What to do

**Hard bounce.** Suppress the address now; it does not exist or will never accept mail.

## Questions

### What does 550 5.1.1 mean?

The reply code 550 means "Requested action not taken: mailbox unavailable (e.g., mailbox not found, no access, or command rejected for policy reasons)" (RFC 5321). The enhanced code 5.1.1 is IANA X.1.1, "Bad destination mailbox address", in class 5 (Permanent Failure).

### Is 550 5.1.1 a hard or soft bounce?

It is classed hard: Suppress the address at once.
