# 553 5.1.2: what it means and what to do

553 5.1.2 is a hard bounce: IANA defines X.1.2 as "Bad destination system address"; suppress the address now. Gmail publishes 1 text with it.

- Verdict on its own: hard
- Published texts: 1

## The codes, part by part

| Part | Value | Meaning | Source |
| --- | --- | --- | --- |
| Reply code | `553` | Requested action not taken: mailbox name not allowed (e.g., mailbox syntax incorrect) | RFC 5321 |
| Class | `5.X.X` | Permanent Failure | RFC 3463 |
| Subject | `X.1.X` | Addressing Status | RFC 3463 |
| Detail | `X.1.2` | Bad destination system address | RFC 3463 |

**IANA X.1.2:** The destination system specified in the address does not exist or is incapable of accepting mail. For Internet mail names, this means the address portion to the right of the "@" is invalid for mail. This code is only useful for permanent failures.

IANA lists the reply codes used with it as: undefined.

## What to do

**Hard bounce.** Suppress the address now; it does not exist or will never accept mail.

## Questions

### What does 553 5.1.2 mean?

The reply code 553 means "Requested action not taken: mailbox name not allowed (e.g., mailbox syntax incorrect)" (RFC 5321). The enhanced code 5.1.2 is IANA X.1.2, "Bad destination system address", in class 5 (Permanent Failure).

### Is 553 5.1.2 a hard or soft bounce?

It is classed hard: Suppress the address at once.
