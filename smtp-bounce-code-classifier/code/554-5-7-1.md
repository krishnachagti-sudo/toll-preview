# 554 5.7.1: what it means and what to do

554 5.7.1 is a block: IANA defines X.7.1 as "Delivery not authorized, message refused"; do not suppress the address; fix the sender's reputation, content or volume. Microsoft publishes 3 texts with it, classed policy: classify the full reply.

- Verdict on its own: block
- Published texts: 3

## The codes, part by part

| Part | Value | Meaning | Source |
| --- | --- | --- | --- |
| Reply code | `554` | Transaction failed (or, at connection opening, "No SMTP service here") | RFC 5321 |
| Class | `5.X.X` | Permanent Failure | RFC 3463 |
| Subject | `X.7.X` | Security or Policy Status | RFC 3463 |
| Detail | `X.7.1` | Delivery not authorized, message refused | RFC 3463 |

**IANA X.7.1:** The sender is not authorized to send to the destination. This can be the result of per-host or per-recipient filtering. This memo does not discuss the merits of any such filtering, but provides a mechanism to report such. This is useful only as a permanent error.

IANA lists the reply codes used with it as: undefined.

## What to do

**Block.** Do not suppress the address: the receiver refused the sender (reputation, content or volume). Fix that, then resend.

## Questions

### What does 554 5.7.1 mean?

The reply code 554 means "Transaction failed (or, at connection opening, "No SMTP service here")" (RFC 5321). The enhanced code 5.7.1 is IANA X.7.1, "Delivery not authorized, message refused", in class 5 (Permanent Failure).

### Is 554 5.7.1 a hard or soft bounce?

It is classed block: Keep the address. Fix what the receiver objects to in the sender (reputation, content, volume), then resend.
