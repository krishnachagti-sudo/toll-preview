# 550 5.4.4: what it means and what to do

550 5.4.4 is a hard bounce: IANA defines X.4.4 as "Unable to route"; suppress the address now.

- Verdict on its own: hard

## The codes, part by part

| Part | Value | Meaning | Source |
| --- | --- | --- | --- |
| Reply code | `550` | Requested action not taken: mailbox unavailable (e.g., mailbox not found, no access, or command rejected for policy reasons) | RFC 5321 |
| Class | `5.X.X` | Permanent Failure | RFC 3463 |
| Subject | `X.4.X` | Network and Routing Status | RFC 3463 |
| Detail | `X.4.4` | Unable to route | RFC 3463 |

**IANA X.4.4:** The mail system was unable to determine the next hop for the message because the necessary routing information was unavailable from the directory server. This is useful for both permanent and persistent transient errors. A DNS lookup returning only an SOA (Start of Administration) record for a domain name is one example of the unable to route error.

IANA lists the reply codes used with it as: undefined.

## What to do

**Hard bounce.** Suppress the address now; it does not exist or will never accept mail.

- [IANA: SMTP Enhanced Status Codes registry (updated December 6, 2024), read November 8, 2026](https://www.iana.org/assignments/smtp-enhanced-status-codes/smtp-enhanced-status-codes.xml)
- [RFC 3463: Enhanced Mail System Status Codes, read November 8, 2026](https://www.rfc-editor.org/rfc/rfc3463.txt)
- [RFC 5321: Simple Mail Transfer Protocol, read November 8, 2026](https://www.rfc-editor.org/rfc/rfc5321.txt)

> Verdicts follow the RFCs, the IANA registry and each provider's published texts as read on November 8, 2026; receivers change their texts without notice. Suppression is your decision: a verdict is a rule-based recommendation, not proof that an address is valid or invalid.

## Questions

### What does 550 5.4.4 mean?

The reply code 550 means "Requested action not taken: mailbox unavailable (e.g., mailbox not found, no access, or command rejected for policy reasons)" (RFC 5321). The enhanced code 5.4.4 is IANA X.4.4, "Unable to route", in class 5 (Permanent Failure).

### Is 550 5.4.4 a hard or soft bounce?

It is classed hard: Suppress the address at once.
