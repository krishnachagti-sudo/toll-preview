# 421 4.4.5: what it means and what to do

421 4.4.5 is a soft bounce: IANA defines X.4.5 as "Mail system congestion"; retry with backoff and suppress only after repeated failures. Gmail publishes 1 text with it.

- Verdict on its own: soft
- Published texts: 1

## The codes, part by part

| Part | Value | Meaning | Source |
| --- | --- | --- | --- |
| Reply code | `421` | \<domain\> Service not available, closing transmission channel | RFC 5321 |
| Class | `4.X.X` | Persistent Transient Failure | RFC 3463 |
| Subject | `X.4.X` | Network and Routing Status | RFC 3463 |
| Detail | `X.4.5` | Mail system congestion | RFC 3463 |

**IANA X.4.5:** The mail system was unable to deliver the message because the mail system was congested. This is useful only as a persistent transient error.

IANA lists the reply codes used with it as: undefined.

## What to do

**Soft bounce.** Retry with backoff; suppress the address only if it keeps failing over several days.

## Questions

### What does 421 4.4.5 mean?

The reply code 421 means "\<domain\> Service not available, closing transmission channel" (RFC 5321). The enhanced code 4.4.5 is IANA X.4.5, "Mail system congestion", in class 4 (Persistent Transient Failure).

### Is 421 4.4.5 a hard or soft bounce?

It is classed soft: Retry with backoff; suppress only after repeated failures over several days.
