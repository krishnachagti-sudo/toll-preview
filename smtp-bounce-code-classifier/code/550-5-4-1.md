# 550 5.4.1: what it means and what to do

550 5.4.1 is a soft bounce: IANA defines X.4.1 as "No answer from host"; retry with backoff and suppress only after repeated failures. Microsoft publishes 1 text with it, classed hard: classify the full reply.

- Verdict on its own: soft
- Published texts: 1

## The codes, part by part

| Part | Value | Meaning | Source |
| --- | --- | --- | --- |
| Reply code | `550` | Requested action not taken: mailbox unavailable (e.g., mailbox not found, no access, or command rejected for policy reasons) | RFC 5321 |
| Class | `5.X.X` | Permanent Failure | RFC 3463 |
| Subject | `X.4.X` | Network and Routing Status | RFC 3463 |
| Detail | `X.4.1` | No answer from host | RFC 3463 |

**IANA X.4.1:** The outbound connection attempt was not answered, because either the remote system was busy, or was unable to take a call. This is useful only as a persistent transient error.

IANA lists the reply codes used with it as: undefined.

## What to do

**Soft bounce.** Retry with backoff; suppress the address only if it keeps failing over several days.

## Questions

### What does 550 5.4.1 mean?

The reply code 550 means "Requested action not taken: mailbox unavailable (e.g., mailbox not found, no access, or command rejected for policy reasons)" (RFC 5321). The enhanced code 5.4.1 is IANA X.4.1, "No answer from host", in class 5 (Permanent Failure).

### Is 550 5.4.1 a hard or soft bounce?

It is classed soft: Retry with backoff; suppress only after repeated failures over several days.
