# 550 5.7.0: what it means and what to do

550 5.7.0 is a block: IANA defines X.7.0 as "Other or undefined security status"; do not suppress the address; fix the sender's reputation, content or volume. Gmail publishes 3 texts with it, classed policy, block: classify the full reply.

- Verdict on its own: block
- Published texts: 3

## The codes, part by part

| Part | Value | Meaning | Source |
| --- | --- | --- | --- |
| Reply code | `550` | Requested action not taken: mailbox unavailable (e.g., mailbox not found, no access, or command rejected for policy reasons) | RFC 5321 |
| Class | `5.X.X` | Permanent Failure | RFC 3463 |
| Subject | `X.7.X` | Security or Policy Status | RFC 3463 |
| Detail | `X.7.0` | Other or undefined security status | RFC 3463 |

**IANA X.7.0:** Something related to security caused the message to be returned, and the problem cannot be well expressed with any of the other provided detail codes. This status code may also be used when the condition cannot be further described because of security policies in force.

IANA lists the reply codes used with it as: undefined.

## What to do

**Block.** Do not suppress the address: the receiver refused the sender (reputation, content or volume). Fix that, then resend.

## Questions

### What does 550 5.7.0 mean?

The reply code 550 means "Requested action not taken: mailbox unavailable (e.g., mailbox not found, no access, or command rejected for policy reasons)" (RFC 5321). The enhanced code 5.7.0 is IANA X.7.0, "Other or undefined security status", in class 5 (Permanent Failure).

### Is 550 5.7.0 a hard or soft bounce?

It depends on the text: on its own the code is classed block, but the texts published with it are classed policy, block. Classify the full reply.
