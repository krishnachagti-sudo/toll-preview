# 550 5.1.0: what it means and what to do

550 5.1.0 is a hard bounce: IANA defines X.1.0 as "Other address status"; suppress the address now. Microsoft publishes 1 text with it.

- Verdict on its own: hard
- Published texts: 1

## The codes, part by part

| Part | Value | Meaning | Source |
| --- | --- | --- | --- |
| Reply code | `550` | Requested action not taken: mailbox unavailable (e.g., mailbox not found, no access, or command rejected for policy reasons) | RFC 5321 |
| Class | `5.X.X` | Permanent Failure | RFC 3463 |
| Subject | `X.1.X` | Addressing Status | RFC 3463 |
| Detail | `X.1.0` | Other address status | RFC 3463 |

**IANA X.1.0:** Something about the address specified in the message caused this DSN.

IANA lists the reply codes used with it as: undefined.

## What to do

**Hard bounce.** Suppress the address now; it does not exist or will never accept mail.

## Questions

### What does 550 5.1.0 mean?

The reply code 550 means "Requested action not taken: mailbox unavailable (e.g., mailbox not found, no access, or command rejected for policy reasons)" (RFC 5321). The enhanced code 5.1.0 is IANA X.1.0, "Other address status", in class 5 (Permanent Failure).

### Is 550 5.1.0 a hard or soft bounce?

It is classed hard: Suppress the address at once.
