# 451 4.3.0: what it means and what to do

451 4.3.0 is a soft bounce: IANA defines X.3.0 as "Other or undefined mail system status"; retry with backoff and suppress only after repeated failures. Gmail publishes 2 texts with it, classed soft, policy: classify the full reply.

- Verdict on its own: soft
- Published texts: 2

## The codes, part by part

| Part | Value | Meaning | Source |
| --- | --- | --- | --- |
| Reply code | `451` | Requested action aborted: local error in processing | RFC 5321 |
| Class | `4.X.X` | Persistent Transient Failure | RFC 3463 |
| Subject | `X.3.X` | Mail System Status | RFC 3463 |
| Detail | `X.3.0` | Other or undefined mail system status | RFC 3463 |

**IANA X.3.0:** The destination system exists and normally accepts mail, but something about the system has caused the generation of this DSN.

IANA lists the reply codes used with it as: undefined.

## What to do

**Soft bounce.** Retry with backoff; suppress the address only if it keeps failing over several days.

## Questions

### What does 451 4.3.0 mean?

The reply code 451 means "Requested action aborted: local error in processing" (RFC 5321). The enhanced code 4.3.0 is IANA X.3.0, "Other or undefined mail system status", in class 4 (Persistent Transient Failure).

### Is 451 4.3.0 a hard or soft bounce?

It depends on the text: on its own the code is classed soft, but the texts published with it are classed soft, policy. Classify the full reply.
