# 450 4.2.1: what it means and what to do

450 4.2.1 is a soft bounce: IANA defines X.2.1 as "Mailbox disabled, not accepting messages"; retry with backoff and suppress only after repeated failures. Gmail publishes 2 texts with it, classed soft, policy: classify the full reply.

- Verdict on its own: soft
- Published texts: 2

## The codes, part by part

| Part | Value | Meaning | Source |
| --- | --- | --- | --- |
| Reply code | `450` | Requested mail action not taken: mailbox unavailable (e.g., mailbox busy or temporarily blocked for policy reasons) | RFC 5321 |
| Class | `4.X.X` | Persistent Transient Failure | RFC 3463 |
| Subject | `X.2.X` | Mailbox Status | RFC 3463 |
| Detail | `X.2.1` | Mailbox disabled, not accepting messages | RFC 3463 |

**IANA X.2.1:** The mailbox exists, but is not accepting messages. This may be a permanent error if the mailbox will never be re-enabled or a transient error if the mailbox is only temporarily disabled.

IANA lists the reply codes used with it as: undefined.

## What to do

**Soft bounce.** Retry with backoff; suppress the address only if it keeps failing over several days.

## Questions

### What does 450 4.2.1 mean?

The reply code 450 means "Requested mail action not taken: mailbox unavailable (e.g., mailbox busy or temporarily blocked for policy reasons)" (RFC 5321). The enhanced code 4.2.1 is IANA X.2.1, "Mailbox disabled, not accepting messages", in class 4 (Persistent Transient Failure).

### Is 450 4.2.1 a hard or soft bounce?

It depends on the text: on its own the code is classed soft, but the texts published with it are classed soft, policy. Classify the full reply.
