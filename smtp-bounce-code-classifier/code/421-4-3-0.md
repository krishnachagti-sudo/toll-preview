# 421 4.3.0: what it means and what to do

421 4.3.0 is a soft bounce: IANA defines X.3.0 as "Other or undefined mail system status"; retry with backoff and suppress only after repeated failures. Gmail publishes 1 text with it.

- Verdict on its own: soft
- Published texts: 1

## The codes, part by part

| Part | Value | Meaning | Source |
| --- | --- | --- | --- |
| Reply code | `421` | \<domain\> Service not available, closing transmission channel | RFC 5321 |
| Class | `4.X.X` | Persistent Transient Failure | RFC 3463 |
| Subject | `X.3.X` | Mail System Status | RFC 3463 |
| Detail | `X.3.0` | Other or undefined mail system status | RFC 3463 |

**IANA X.3.0:** The destination system exists and normally accepts mail, but something about the system has caused the generation of this DSN.

IANA lists the reply codes used with it as: undefined.

## What to do

**Soft bounce.** Retry with backoff; suppress the address only if it keeps failing over several days.

## Questions

### What does 421 4.3.0 mean?

The reply code 421 means "\<domain\> Service not available, closing transmission channel" (RFC 5321). The enhanced code 4.3.0 is IANA X.3.0, "Other or undefined mail system status", in class 4 (Persistent Transient Failure).

### Is 421 4.3.0 a hard or soft bounce?

It is classed soft: Retry with backoff; suppress only after repeated failures over several days.
