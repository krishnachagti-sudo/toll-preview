# 553 5.1.3: what it means and what to do

553 5.1.3 is a hard bounce: IANA defines X.1.3 as "Bad destination mailbox address syntax"; suppress the address now. Gmail publishes 1 text with it.

- Verdict on its own: hard
- Published texts: 1

## The codes, part by part

| Part | Value | Meaning | Source |
| --- | --- | --- | --- |
| Reply code | `553` | Requested action not taken: mailbox name not allowed (e.g., mailbox syntax incorrect) | RFC 5321 |
| Class | `5.X.X` | Permanent Failure | RFC 3463 |
| Subject | `X.1.X` | Addressing Status | RFC 3463 |
| Detail | `X.1.3` | Bad destination mailbox address syntax | RFC 3463 |

**IANA X.1.3:** The destination address was syntactically invalid. This can apply to any field in the address. This code is only useful for permanent failures.

IANA lists the reply codes used with it as: undefined.

## What to do

**Hard bounce.** Suppress the address now; it does not exist or will never accept mail.

## Questions

### What does 553 5.1.3 mean?

The reply code 553 means "Requested action not taken: mailbox name not allowed (e.g., mailbox syntax incorrect)" (RFC 5321). The enhanced code 5.1.3 is IANA X.1.3, "Bad destination mailbox address syntax", in class 5 (Permanent Failure).

### Is 553 5.1.3 a hard or soft bounce?

It is classed hard: Suppress the address at once.
