# Mastercard 4834: Point-of-Interaction Error

## What it means

Stripe files Mastercard 4834 under Duplicate. Its sub-reasons include being debited more than once, an amount that differs, late presentment and currency conversion errors.

Sub-reasons Stripe lists under 4834: Transaction Amount Differs; Cardholder Debited More than Once for the Same Goods or Services; ATM Disputes; Charges for Loss, Theft, or Damages; Late Presentment; POI Currency Conversion (Dynamic Currency Conversion); Merchant Credit Correcting Error Resulting in Cardholder Currency Exchange Loss; Improper Merchant Surcharge (Intra-European and Inter-European transactions only); Unreasonable Amount - Intra-European Economic Area (EEA) Transactions Only.

## Evidence Stripe lists for this code

- Transaction logs showing only one charge settled
- If a duplicate happened, proof it was voided, reversed or refunded
- Receipts showing each charge was for a different transaction, date or service
- Proof that one item was an authorization hold that dropped off, not a second charge

## Watch for

- Stripe lists nine 4834 sub-reasons; the evidence depends on which one the issuer used.
