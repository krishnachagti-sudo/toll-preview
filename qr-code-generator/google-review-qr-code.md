# A QR code for Google reviews

It takes 3 steps on a computer: open your Business Profile, select Read Reviews and then Get more reviews, and copy the link or save Google's QR code. A static code for a short link such as https://example.com/review is a 25 x 25 module symbol.

## Why make your own code from the link?

Google's saved image is fine for screens. For print, a vector (SVG or PDF) file at the size you need, with a print check, avoids a blurry code. Sizes are on [how big to print a QR code](https://krishnachagti-sudo.github.io/toll-preview/qr-code-generator/qr-code-print-size/).

> The link in the example is a placeholder, not a real profile. Use the link Google shows you; a longer link makes a denser code.

## Steps

1. **Open your Business Profile on a computer.** Google says reviews QR codes can only be generated in a computer browser, not on mobile devices.
2. **Select Read Reviews, then Get more reviews.** Google shows a link and a QR code to share.
3. **Copy the link or save the code.** Select Copy for the link, or right-click the QR code and select Save image as.
4. **Print it.** Use Google's image, or paste the link into a static code generator for a print file at the size you need.

## Questions

### Does Google make the review QR code for me?

Yes, from a computer browser: in your Business Profile select Read Reviews, then Get more reviews. Google says this is not available on mobile devices.

### Will a review QR code expire?

A static code that holds Google's link has no expiry of its own; it works while Google's link does.
