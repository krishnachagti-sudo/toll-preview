How it works

Static, dynamic, and what can expire.

A static code holds your link or details itself. A dynamic one holds a vendor's short link, which works only while the vendor forwards it.

What it does not cover

Dynamic (editable) codes, codes in PDF proofs, EPS files, calendar events and payment codes.

Read the notes and sources
  • The encoder follows ISO/IEC 18004 (QR Code Model 2): numeric, alphanumeric and byte modes, versions 1 to 40 (21 x 21 to 177 x 177 modules), error correction L, M, Q and H, and the eight mask patterns chosen by the standard's penalty rules. Its output is tested against an independent open-source encoder at every version and level.
  • DENSO WAVE, the QR Code's inventor, asks for a four-module quiet zone on every side and recommends 4 or more printer dots a module; the print checks use both. Most-used level: M, about 15% restorable.
  • Content formats: WiFi, SMS, phone, location and email as phone camera apps read them (ZXing "Barcode Contents"); contact cards as vCard 3.0 (RFC 2426); email links per RFC 6068. SMS codes have no official standard.
  • The checker follows HTTP redirects only (at most 10), from our server, and lists a vendor only when its domain is on our checked list; it cannot see your account or promise what a vendor will do. We are not affiliated with any vendor named.
  • Not covered: dynamic (editable) codes, reading codes from PDF proofs, EPS files, calendar events and payment codes. QR Code is registered trademark of DENSO WAVE INCORPORATED.
  • Sources, read November 2, 2026: DENSO WAVE: quiet zone, DENSO WAVE: module size, DENSO WAVE: versions, DENSO WAVE: error correction, DENSO WAVE FAQ, ZXing Barcode Contents, RFC 2426, RFC 6068, Avery 5160, Avery 22816. Vendor pages are listed with each checker result.

Static

The modules spell out your link or details. Nothing in between can lapse.

Read the full rules

The code's modules spell out your link, WiFi login or contact card. A phone reads it straight from the print. No service sits in between, so nothing can lapse; a static link still fails if the website behind it goes away.

Dynamic

A vendor's short link forwards each scan, only while the vendor keeps it on.

Read the full rules

The code spells out a short link on a vendor's domain, and the vendor forwards each scan to your page. You can change the page later, but the printed code works only while the vendor forwards it. Vendors' own pages describe what happens when a plan ends; the checker above quotes them with the date read.

Proof on every file

Each file shows the text it holds and is read back before you get it.

Read the full rules

Each download shows the exact text it holds, its version (size), error correction level and mask, and the file is read back by an independent decoder before you get it. If a logo hides too much, the page says so instead of handing over a code that may not scan.
