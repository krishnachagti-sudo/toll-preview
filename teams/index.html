Connect your agent

Three steps,
then it calls the tools itself.

  1. 01

    Add the server

    Give your MCP client the address. In the Claude apps, add it as a custom connector; in ChatGPT, add it as a custom MCP server and choose OAuth.

  2. 02

    Sign in, or use a key

    Apps that support MCP sign-in (OAuth) open a Endwise page where you approve the app and set its monthly limit. For other clients, create an API key and send it as a Bearer token.

  3. 03

    List, then call

    Listing tools needs nothing. Calling one is priced and limited exactly like an API call, and connected apps show on your account page, where you can disconnect one at any time.

Trust

What we keep,
and the paperwork you need.

Inputs are not stored. The one exception is a safe API retry, and tools that take your files or records keep no answer at all. The data-handling sheet lists everything kept and for how long, with the security answers we can give.

For vendor setup: a W-8BEN-E on request, invoices with your company's name and PO number, and our data processing terms if you ask. Ask us.
