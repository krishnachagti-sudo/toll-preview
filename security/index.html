Security

How we keep it safe

Endwise keeps as little as it can, and makes the rest hard to misuse. This page says what is done today.

Last updated [To be filled in: the date these pages were last updated]

We keep very little

  • What you send to a tool is not stored. The one exception, for safe API retries, is a hash of the input and the answer, described on the privacy page.
  • Your IP address is never written to the database.
  • There are no ad or analytics trackers on any page.

Passwords, keys and sessions

  • Passwords are stored only as a slow, salted hash.
  • An API key is shown once. We keep only a hash and its first 12 characters, so a database copy cannot be used to make calls.
  • The sign-in cookie cannot be read by scripts on the page, is only sent to this site, and is stored as a hash.
  • Sign-in attempts are slowed after repeated failures.

Your balance

  • Every key has a hard monthly spending limit, and you can set one for the whole account. A call past a limit is refused, not billed.
  • Every charge and refund is written to a ledger in one transaction, so a balance can never be charged twice for the same call.
  • Card and bank details go to the payment provider, never to us.

In transit

The site and API are served only over HTTPS. Pages cannot be framed by other sites.

Report a vulnerability

Write to [To be filled in: the security email] with the details and steps to reproduce. Please give us a reasonable time to fix it before telling anyone else, and do not access other people's data, run denial-of-service tests or use automated scanners against the live service. We will reply, keep you updated, and thank you publicly if you would like.
