# Conference badges from a registration list

For a conference of 240 with 24 spare badges, 264 badges in all, Avery 5392 inserts (3 x 4 in, 6 per sheet) take 44 sheets; each badge carries the first name large, then the full name, company, title and pronouns, with the ticket type at the foot, and the batch costs $2.64.

## What goes where

| Line | From the column | Largest size on 5392 |
| --- | --- | --- |
| Event name (top) | The event name you type | 11 pt |
| First name | First name | 54 pt |
| Full name | First and last name | 16 pt |
| Company | Company or Organization | 13 pt |
| Title and pronouns | Job title, Pronouns | 11 pt |
| Ticket type (foot) | Ticket type, Badge type or Track | 10 pt |

Spare badges print with the event name only, for people who register on the day; the blanks left on the last sheet can take a walk-in badge later. A reprint of the same event within 30 days (a corrected list, a late registration) is free if it has no more badges, and pays only the difference if it has more.

The check-in list comes with the badges: every guest in print order with the sheet and label of their badge, so the door team finds a badge at once.
