How big the names print

With the big-first-name style, a first name prints at up to 50.5 pt on this badge. "Christopher" prints at 39.75 pt (made smaller to fit); each badge is fitted on its own, so short names stay at the largest size.

  • Al: 50.5 pt
  • Ana: 50.5 pt
  • Grace: 50.5 pt
  • Michael: 50.5 pt
  • Christopher: 39.75 pt (made smaller to fit)
  • Maximiliana: 39.75 pt (made smaller to fit)
  • Bartholomew: 35.5 pt (made smaller to fit)

Questions

What size is Avery 5147?

2-1/3 in x 3-3/8 in (print or write name badge labels), 2 per sheet, as Avery's template page gives it.

How many name tags are on an Avery 5147 sheet?

2: 1 across and 2 down.

Which Avery products use the 5147 template?

Avery lists 5152.

How many sheets of Avery 5147 for 100 guests?

50 (100 / 2, rounded up).
