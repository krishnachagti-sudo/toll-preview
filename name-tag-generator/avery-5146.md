# Avery 5146 name badges from a guest list

Avery 5146 print or write name badge labels are 2-5/16 in x 3-3/8 in, 2 per sheet (1 across, 2 down) on a 4 x 6 in sheet; 100 names need 50 sheets.

- Badge size: 2-5/16 in x 3-3/8 in
- Per sheet: 2 (1 x 2)
- Sheet: 4 x 6 in
- 100 guests: 50 sheets

## Where each badge goes

Measured from Avery's blank PDF template U-0236-01 for 5146, from the top-left corner of the sheet. Labels are counted left to right, then down.

| Label | From the left edge (in) | From the top edge (in) | Width (in) | Height (in) |
| --- | ---: | ---: | ---: | ---: |
| 1 | 0.313 | 0.5 | 3.375 | 2.344 |
| 2 | 0.313 | 3.156 | 3.375 | 2.344 |

The template's outline for each badge is 3.375 in x 2.344 in (Avery sells it as 2-5/16 in x 3-3/8 in). rows are 0.313 in apart. Text is kept 0.12 in inside every edge, so a sheet that feeds slightly off still shows the whole name.

## How big the names print

With the big-first-name style, a first name prints at up to 50.5 pt on this badge. "Christopher" prints at 39.75 pt (made smaller to fit); each badge is fitted on its own, so short names stay at the largest size.
