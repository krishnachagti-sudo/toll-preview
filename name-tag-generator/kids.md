# Name tags for kids and classrooms

With the first-name-only style on Avery 5395, a child's first name prints as large as 70.5 pt ("Olivia" at 70.5 pt, against 50.25 pt with the adult style), and no last name, school or title is printed.

## Open with the kids style

Largest first-name size on Avery 5395 with the first-name-only style.

| Name | Size |
| --- | ---: |
| Mia | 70.5 pt |
| Leo | 70.5 pt |
| Olivia | 70.5 pt |
| Alexander | 46.5 pt |

Only the first name column is printed in this style (and pronouns if the list has them and they are switched on). The event or class name can go at the top, or be switched off.
