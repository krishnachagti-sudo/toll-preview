Name tag font size

Fitted to its own badge, a first name prints at up to 50.25 pt on Avery 5395 ("Ana" at 50.25 pt) and is made smaller only when it is long ("Christopher" at 39.75 pt), measured with Helvetica Bold's character widths inside a 0.12 in margin.

The largest size is set by the badge's height (so the full name, organization and title still fit below), and a name is made smaller only when its width needs it. Word or a template applies one size to every badge, so the size has to suit the longest name on the list.

Badge sizes: 5395 and 5895 are 2-1/3 in x 3-3/8 in, 5392 is 3 in x 4 in, 5390 is 2-1/4 in x 3-1/2 in.
