## The numbers on other boxes

Avery sells the same badge under several numbers (different pack sizes, printer types or holders). Its template page lists the numbers that use the same template:

- 5395: 25395, 42395, 45395, 48395, 8395, 85395, 88395, Presta 94366
- 5895: 5095
- 5390: 5383, 74461, 74549
- 5392: 35392, 5384, 5393, 74459, 74536, 74540, 74541, 78617, 78619, 8780, 8781
- 5146: 41006, 41008, 5143, 5144, 5151
- 5147: 5152

Two products with the same size are not always at the same positions: 5395 and 5895 are both 2-1/3 x 3-3/8 in, 8 per sheet, but the 5895 template starts each row 2 points (about 0.03 in) lower. Pick the number on your box.

## Questions

### What size are Avery name badge inserts?

3 in x 4 in (5392 and the numbers that share its template, 6 per sheet) or 2-1/4 in x 3-1/2 in (5390, 8 per sheet).

### Which Avery template is a 2.25 x 3.5 name badge?

Avery 5390 (2-1/4 in x 3-1/2 in, 8 per sheet).

### What size is a 3x4 name badge from Avery?

Avery 5392 is 3 in x 4 in, 6 per sheet; Avery lists 35392, 5384, 5393, 74459, 74536, 74540, 74541, 78617, 78619, 8780, 8781 as using the same template.

### Are Avery 5395 and 8395 the same size?

Yes: Avery's 5395 template page lists 8395 as compatible, so both are 2-1/3 in x 3-3/8 in, 8 per sheet, at the same positions. Check the pack for the printer type it is made for.

### Which Avery badge is the largest?

5392: 3 in x 4 in.
