## Planning for walk-ins

Two ways to have badges ready: add spare badges to the batch (they print with the event name only, for a marker), or leave the last sheet's blanks and print each walk-in as they arrive.

## Steps

1. **Keep the part-used sheet.** After the batch, the last sheet has blank labels (150 guests on Avery 5395 leave 2). Take it to the door with the printer.
2. **Type the walk-in.** First and last name, and the organization if you print one. Use the same event name as the batch.
3. **Choose the label.** Pick the first blank label on the sheet; labels count left to right, then down.
4. **Print at 100%.** Feed the sheet the same way as before and print the one-badge PDF at Actual size.
