# How to print name tags from Excel

To print name tags from Excel, open the .xlsx in the badge maker, pick the Avery number on your box and print the PDF at 100%: 150 guests on Avery 5395 is 19 sheets with 2 labels left for walk-ins, and each name is fitted to its own badge.

## Open your Excel list

[Open the badge maker](https://krishnachagti-sudo.github.io/toll-preview/name-tag-generator/?product=5395)

## What the sheet needs

| Column heading (any of these) | Prints as |
| --- | --- |
| First Name, First, Given name, Preferred name, Badge name | The big name |
| Last Name, Surname, Family name | With the first name on the line below |
| Name, Full name, Attendee name, Guest name | Split into first and last ("Ruiz, Ana" is read as Ana Ruiz) |
| Company, Organization, Employer, School, Affiliation | The organization line |
| Job title, Title, Role, Position | The title line |
| Pronouns | After the title, in brackets |
| Ticket type, Badge type, Group, Table, Track | In capitals at the foot |

Names typed in ALL CAPS or all lower case are put in title case (BEN OKAFOR becomes Ben Okafor, o'neil becomes O'Neil); names in mixed case are left exactly as typed. Turn this off under More options.

## Steps

1. **Check the columns.** One guest a row, with a heading row: First name and Last name (or one Name column), and if you want them Company, Job title, Pronouns and Ticket type. Other columns are ignored.
2. **Open the file here.** Open the .xlsx in the badge maker (the first worksheet is read) or save it as CSV and open that. It stays in your browser for the preview.
3. **Pick the Avery number on the box.** Choose the template, or type the number printed on the pack; numbers Avery lists as compatible (such as 8395 for 5395) open the right template.
4. **Check the preview.** It shows every sheet, which names were made smaller to fit, repeated guests and rows with no name.
5. **Print the test page on plain paper.** Print it at 100% (Actual size), lay it on a label sheet and hold both to a window.
6. **Download and print the badges.** Print the PDF at 100%. $0.01 a badge, at least $0.99 an event; a reprint for the same event within 30 days is free.

## Questions

### How do I print name tags from Excel?

Open the Excel file in a name tag generator, pick the Avery number, check the preview and print the PDF at 100%. In Word it is Mailings \> Start Mail Merge \> Labels, the Avery number, Use an Existing List, insert the fields, Update Labels, preview and print (Avery's steps).

### How many sheets for 150 name tags?

On Avery 5395 (8 per sheet), 19 sheets, with 2 labels blank on the last one.

### Do I need Word to print name tags from Excel?

No. The badge maker reads the .xlsx directly and gives a PDF laid out for the Avery sheet.
