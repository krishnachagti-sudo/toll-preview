# Word mail merge vs a name tag generator

Word's label mail merge takes six steps (Avery's count) and uses one font size for every badge; this tool reads the same Excel file, sizes each name to its badge and lists anything cut before you print, for $0.01 a badge with a $0.99 minimum.

## Side by side

Word mail merge: from its own pages, read November 8, 2026. This tool: from its own prices and rules.

|  | Word mail merge | This tool |
| --- | --- | --- |
| Price | Included with Word | $0.01 a badge, at least $0.99 an event; reprints and walk-ins for the event free for 30 days |
| Steps | Six: Labels, product number, existing list, fields, Update Labels, print | Open the list, pick the number, print |
| Long names | One size for the whole merge; a second merge for long names | Each name sized to fit its own badge |
| Same name on every label | Happens when Next Record is missing | Not possible: one badge per guest |
| Formatting | Anything Word can do | Fixed layouts: big first name, full name, or first name only |

## When Word mail merge is the better choice

- You already have a Word badge design you like.
- You need fonts, colors or a logo on the badge.
- You merge labels often and know the steps.

## When this tool is

- The event is tomorrow and the merge is fighting you.
- Some names are long and some short.
- You need walk-ins and a check-in list from the same list.
