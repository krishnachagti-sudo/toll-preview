The rules

Why it lines up, badge by badge.

Sizes, counts per sheet and compatible numbers are as printed on each template's avery.com page.

What it does not cover

Avery numbers not listed below, letters outside the standard font, and printing scaled to fit.

Read the full notes
  • Compatible with Avery products; not made or endorsed by Avery. Avery is a trademark of its owner.
  • Sizes, counts per sheet and compatible numbers are as printed on each template's avery.com page; label positions are measured from the blank PDF template on that page. Read November 8, 2026: the sources load with the page.
  • Names print in the standard Helvetica font, so letters such as é, ñ, ø and š print as written. Letters outside that font (for example Ł, Cyrillic or Chinese) are flagged on the badge they are on.
  • Guest lists are used to make the badges and are not kept. The preview is worked out in your browser.

Avery's own positions

Badges sit where Avery's own blank template puts each label, measured to a hundredth of a point.

Read the full rule

Every avery.com template page offers a blank PDF template. The outline of each label on that PDF was measured to a hundredth of a point, and badges are placed exactly there, from the top-left corner of the sheet. Labels are counted left to right, then down. Numbers Avery lists as compatible (8395 for 5395, 74459 for 5392) use the same positions.

Each name fitted on its own

Each first name is as large as its badge allows; only a long name is made smaller.

Read the full rule

A mail merge sets one font size for every badge, so a long name runs off or the merge has to be done twice. Here the first name is set as large as the badge allows, measured with the font's own character widths, and only a long name is made smaller. A name that still will not fit wraps onto two lines, and anything cut is listed before you pay.

Print at 100%

Print at Actual size (100%), never Fit to page, and print the free test page first.

Read the full rule

Print the PDF at Actual size (100%), never Fit to page: fitting shrinks the sheet a few percent and every row drifts. The PDF asks the print dialog for no scaling. Print the free test page on plain paper first, lay it on a label sheet and hold both to a window. Each test label has a 1-inch bar to measure with a ruler.
