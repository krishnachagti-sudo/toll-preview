# Thryft Ship APV adjustments vs this checker

Thryft Ship's APV page uses the same July 12, 2026 rule (sides rounded up, divided by 139) and works the same example: a 21.06 x 15.55 x 9.61 in box at 8 lb is billed at 26 lb, which this checker also gives. Thryft Ship files disputes for its own labels; the checker works for a label from any platform.

|  | Thryft Ship | This checker |
| --- | --- | --- |
| Labels covered | Labels bought on Thryft Ship | Any USPS label (eBay, Etsy, Click-N-Ship, PC Postage) |
| Files the dispute | Yes: upload the adjustment and Thryft Ship submits it to USPS | No: you file on USPS's webform |
| Explains the 139 rule and the $3 fee | Yes | Yes, with the DMM section for each service |
| Prices the adjustment | Not on the page read | Yes, at Notice 123 commercial prices |
| Cost | The adjustment is passed on with its standard payment processing fee | Check free; packet $0.49 |

## When Thryft Ship is better

If you bought the label on Thryft Ship, its own filing is less work: it knows the label data and reports the outcome back to you. The checker is for labels from other platforms, or to see the numbers before you file.

## The shared example

1. Measure: 21.06 x 15.55 x 9.61 in.
2. Round up each side to the whole inch: 22 x 16 x 10 in.
3. Multiply: 3,520 cubic inches.
4. Over 1,728 cubic inches, so divide by 139 and round up: 26 lb.
