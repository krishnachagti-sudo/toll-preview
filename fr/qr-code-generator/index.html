Codes statiques, sans inscription

Générateur de QR code

Un code statique contient lui-même votre lien ou vos coordonnées : rien d’intermédiaire ne peut donc le désactiver. Cette page le crée dans votre navigateur, montre le texte exact qu’il contient et relit le fichier avant que vous le téléchargiez.

Créer un code sur cette page est gratuit et ne demande aucun compte ; rien de ce que vous saisissez ne quitte votre appareil. Vérifier un code imprimé est aussi gratuit ici. Les codes issus d’un tableur coûtent $0.002 pièce.

Apparence et taille d’impression

Un logo masque des modules : le code s’appuie alors sur la correction d’erreurs, choisissez Q ou H. Le fichier est relu pour s’assurer qu’il se décode encore.

Gratuit, dans votre navigateur. Sans compte, sans traçage, sans expiration.

Chargement.

Un code que j’ai déjà imprimé va-t-il cesser de fonctionner ?

Beaucoup de générateurs créent des codes dynamiques : le code contient un lien court sur le domaine du prestataire, qui ne transmet les scans vers votre page que tant que le prestataire le garde actif. Donnez une image du code, ou ce qu’il contient, et cet outil suit le lien comme le ferait un téléphone.

Une capture d’écran ou un scan se lit le mieux. Une photo prise au téléphone est lue avec le lecteur de codes intégré à votre navigateur, s’il en a un.

Gratuit sur cette page. Sans compte, cela compte comme l’une de vos exécutions gratuites du jour. Le lien est visité depuis notre serveur, qui n’ouvre jamais d’adresses privées ou locales.

Un lot de codes à partir d’un tableur

Un code par ligne, en fichiers PNG ou SVG dans un ZIP avec un manifeste, et une planche d’étiquettes à imprimer. Les lignes sont d’abord vérifiées ici ; vous ne payez que les codes créés, et chaque fichier est relu par rapport à sa ligne.

Les colonnes lues

Une ligne d’en-tête, puis un code par ligne. Nommez la colonne du contenu d’après son champ : url, text, ssid et password (Wi-Fi), firstName, lastName, phone, email (carte de contact), to et subject (e-mail), phone et message (SMS), latitude et longitude (lieu). Une colonne type peut fixer le type de chaque ligne. Jusqu’à trois colonnes d’étiquette (label, label2, label3) s’impriment à côté du code sur la planche. Les cellules texte d’Excel gardent leurs zéros initiaux, et les longs numéros de série sont écrits en entier.

La correction d’erreurs et les couleurs ci-dessus s’appliquent aussi ici. {row} dans un nom de fichier est la ligne du tableur ; {N’importe quel en-tête} est cette colonne.

Statique, dynamique et ce qui peut expirer

Statique

Les modules du code écrivent votre lien, votre accès Wi-Fi ou votre carte de contact. Un téléphone le lit directement sur l’impression. Aucun service ne s’interpose, donc rien ne peut expirer ; un lien statique cesse tout de même de fonctionner si le site web derrière disparaît.

Dynamique

Le code écrit un lien court sur le domaine d’un prestataire, et le prestataire transmet chaque scan vers votre page. Vous pouvez changer la page plus tard, mais le code imprimé ne fonctionne que tant que le prestataire le transmet. Les pages des prestataires décrivent ce qui se passe à la fin d’un abonnement ; la vérification ci-dessus les cite avec la date de lecture.

Une preuve pour chaque fichier

Chaque téléchargement montre le texte exact qu’il contient, sa version (taille), son niveau de correction d’erreurs et son masque, et un décodeur indépendant relit le fichier avant que vous le receviez. Si un logo masque trop de choses, la page vous le dit au lieu de vous remettre un code qui ne se scanne peut-être pas.

  • L’encodeur suit la norme ISO/IEC 18004 (QR Code Model 2) : modes numérique, alphanumérique et octets, versions 1 à 40 (de 21 x 21 à 177 x 177 modules), correction d’erreurs L, M, Q et H, et les huit motifs de masque choisis selon les règles de pénalité de la norme. Sa sortie est testée contre un encodeur open source indépendant à chaque version et chaque niveau.
  • DENSO WAVE, l’inventeur du QR code, demande une zone de silence de quatre modules de chaque côté et recommande 4 points d’imprimante ou plus par module ; les contrôles d’impression utilisent les deux. Niveau le plus utilisé : M, environ 15 % restituables.
  • Formats de contenu : Wi-Fi, SMS, téléphone, lieu et e-mail tels que les lisent les applications d’appareil photo (ZXing « Barcode Contents ») ; cartes de contact en vCard 3.0 (RFC 2426) ; liens e-mail selon la RFC 6068. Les codes SMS n’ont pas de norme officielle.
  • La vérification ne suit que les redirections HTTP (10 au plus), depuis notre serveur, et ne nomme un prestataire que si son domaine figure sur notre liste vérifiée ; elle ne voit pas votre compte et ne peut rien promettre sur ce que fera un prestataire. Nous ne sommes affiliés à aucun des prestataires nommés.
  • Non couvert : les codes dynamiques (modifiables), la lecture de codes sur des épreuves PDF, les fichiers EPS, les événements de calendrier et les codes de paiement. QR Code is registered trademark of DENSO WAVE INCORPORATED.
  • Sources, lues le 2 novembre 2026 (pages en anglais) : DENSO WAVE : zone de silence, DENSO WAVE : taille du module, DENSO WAVE : versions, DENSO WAVE : correction d’erreurs, DENSO WAVE FAQ, ZXing Barcode Contents, RFC 2426, RFC 6068, Avery 5160, Avery 22816. Les pages des prestataires sont indiquées avec chaque résultat de vérification.

Tarifs

  • Créer un code sur cette page et vérifier un code imprimé sur cette page : gratuit.
  • Par API ou MCP : créer un code $0.002, lire un code depuis un PNG $0.002, vérification d’expiration $0.005.
  • Codes issus d’un tableur : $0.002 par code créé, 10 au minimum par commande ; au-delà de 5 000 codes dans un mois civil, le prix par code baisse.

Les lignes qui ne peuvent pas devenir un code ne sont jamais facturées.
