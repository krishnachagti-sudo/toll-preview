Un QR code peut-il expirer ? Codes statiques et dynamiques

Un QR code statique contient lui-même votre lien ou vos coordonnées et n’expire jamais ; un QR code dynamique ne contient qu’un lien court sur le domaine d’un prestataire et ne fonctionne que tant que ce prestataire le transmet. Le tableau ci-dessous recense 7 prestataires dont nous avons vérifié les domaines de redirection le 2 novembre 2026.

Un QR code gratuit expire-t-il ?

Un code statique, non : ses modules écrivent directement votre lien, votre accès Wi-Fi ou votre carte de contact, et le téléphone les lit sur l’impression. Un code dynamique écrit un lien court sur le domaine du prestataire. Le prestataire transmet chaque scan vers votre page, et il peut le limiter, le couper ou le lier à un abonnement.

DENSO WAVE, l’inventeur du QR code, indique dans sa FAQ (en anglais) qu’aucune demande ni aucun contrat de licence n’est nécessaire pour utiliser le QR code tant que l’on respecte les normes JIS ou ISO, et qu’il n’y a pas de frais. Seul peut expirer ce qu’un service intermédiaire maintient.

Comment savoir si mon QR code imprimé est dynamique ?

  • Scannez le code avec une application photo qui affiche l’adresse avant d’ouvrir la page.
  • Si le domaine est le vôtre ou celui de votre entreprise, le code est statique. Si c’est un lien court comme les domaines du tableau ci-dessous, il est dynamique.
  • Ou donnez l’image du code à la vérification d’expiration : elle suit le lien comme un téléphone et dit s’il passe par un prestataire, et lequel.

La vérification est gratuite sur la page de l’outil et ne demande pas de compte.

Chaque domaine a été résolu le 2 novembre 2026 et chaque résumé vient de la page du prestataire à la date indiquée. Les citations exactes, en anglais, figurent sur la page en anglais. Les règles changent ; ce n’est pas une prévision de ce que fera un prestataire d’un code donné.

Peut-on transformer un code dynamique en code statique ?

Non, car les modules imprimés contiennent le lien du prestataire. Mais vous pouvez créer un nouveau code statique pour la page où mène aujourd’hui l’ancien code, puis réimprimer. Il ne dépend alors plus d’aucun prestataire.

Un lien statique a quand même besoin de son site web

Un code statique contenant https://example.com/menu le dit pour toujours. Si la page du menu change d’adresse ou si le domaine expire, le code ne mène plus nulle part. Faites pointer les codes imprimés vers une page d’un domaine qui vous appartient.

À lire

  • Un code statique stocke directement votre contenu et n’expire pas, mais il ne fonctionne que tant que sa destination (site web, formulaire, réseau) existe.
  • Scannez chaque code en test à sa taille d’impression définitive avant un tirage.
  • Vérification d’expiration : elle indique ce que le code contient et où il redirige aujourd’hui, plus la règle publiée du prestataire à la date indiquée ; elle ne voit pas votre compte et ne peut rien promettre sur ce que fera un prestataire. Les règles sont résumées d’après les pages du prestataire à la date indiquée et peuvent changer ; nous ne sommes affiliés à aucun des prestataires nommés.
  • Codes Wi-Fi : la prise en charge varie selon les téléphones, surtout pour les champs entreprise (WPA2-EAP) ; testez avec les téléphones de vos invités.

Questions

Les QR codes gratuits expirent-ils ?

Un code statique ne peut pas expirer : ce qu’il dit est dans le code lui-même. Un code dynamique gratuit le peut, car il passe par la redirection du prestataire, et certains prestataires limitent ou coupent les codes gratuits ou périmés. Le tableau de cette page cite ce que dit chacun.

Comment savoir si mon QR code imprimé est dynamique ?

Scannez-le et regardez l’adresse avant que la page s’ouvre. Si c’est un lien court sur le domaine d’un prestataire de QR codes et non sur votre propre site, il est dynamique. La vérification de la page de l’outil suit le lien et nomme le prestataire.

Peut-on transformer un code dynamique en code statique ?

Non. Les modules imprimés contiennent le lien du prestataire. Vous pouvez créer un nouveau code statique pour la page où il mène, puis réimprimer.
