# Media titles and the 75-character rule

Media is the one exception Amazon's July 2026 announcement names: "titles in all categories except for media will need to be 75 characters or less"; it sets no other number for media, so the 100-character book title in the worked file passes as media and would be 25 over as anything else.

## The rule, in Amazon's words

"Starting July 27, 2026, titles in all categories except for media will need to be 75 characters or less including spaces."

## What the post does not say

- Which categories count as media. Mark media rows yourself (a media column with yes, or the media box).
- A length for media titles. The January 2025 rule said 200 "for most product categories".
- That the character and repeat rules skip media. The January 2025 post states both for titles without a category exception, so the checker applies them to media rows too.

## Questions

### Is there a character limit for media titles?

Amazon's July 2026 post sets none for media. Its January 2025 post set 200 characters "for most product categories" without naming media either way.
