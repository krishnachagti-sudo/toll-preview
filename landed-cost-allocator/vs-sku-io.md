# SKU.io vs this allocator

SKU.io starts at $1,000 a month for inventory, orders, purchasing and FIFO landed cost across channels; costing four shipments a month here is $6.00, so the choice turns on whether you need the whole system or only the landed cost.

## SKU.io, from its own page

- Price: Starting at $1,000 per month, personalized (pricing page, read November 8, 2026).
- FIFO landed cost.
- Inventory, orders, purchasing and forecasting across Shopify, Amazon, Walmart and eBay.
- Unlimited API access.

## This allocator

- Price: $1.50 per shipment of up to 50 lines, free for 3 lines or fewer, re-runs for the same shipment free for a year, at most $14.90 a month.
- Bases: value, weight, CBM, units, per line, as given per SKU, or a mix, chosen per invoice.
- Every invoice split to the cent and added back exactly; Shopify's two-decimal drift shown.
- Late invoices: units on hand re-costed, sold units' share as a COGS variance.
- Your own Shopify export returned with only Cost per item filled; a CSV per SKU and a spreadsheet with formulas.
- No app install and no write access to your store: you import the file yourself.

## When SKU.io is the better choice

When you sell on several channels and want inventory, orders, purchasing, forecasting and landed cost in one system with FIFO layers.
