KB or KiB: 1,000 or 1,024 bytes?

A kilobyte (kB) is 1,000 bytes, the SI meaning, while a kibibyte (KiB) is 1,024 bytes; some software writes KB for 1,024. When a form says 50 KB without saying which, stay under 50,000 bytes and the file fits both.

Two units with one name

In the International System of Units, kilo means 1,000 and mega 1,000,000. In December 1998 the International Electrotechnical Commission approved names for the binary multiples: a kibibyte (KiB) is 1,024 bytes and a mebibyte (MiB) is 1,048,576, as NIST explains.

Software has long written KB and MB for the binary amounts as well. Apple says storage makers count in the decimal system, and that some apps and systems, such as iOS 10 and earlier and OS X Leopard and earlier, report sizes in the binary system, where 1 GB is 1,073,741,824 bytes (Apple Support). So the same file can show as a slightly different number of KB in two places.

What Image to size does

The tool reads 1 KB as 1,000 bytes, so a result under your limit is under it in both readings. The gap is about 2.4% at KB sizes and 4.9% at MB sizes, too small to change how a photo looks. Open Image to size.

Questions

How many bytes is 1 MB?

In SI units 1 MB is 1,000,000 bytes. The binary unit, 1 MiB, is 1,048,576 bytes. Some software writes MB for the binary amount.

Which reading should I use for an upload limit?

The smaller one, 1,000 bytes to the KB. A file under 50,000 bytes is under 50 KB whichever way the form counts.
