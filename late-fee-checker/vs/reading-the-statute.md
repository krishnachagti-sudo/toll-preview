# Read the statute, or use the checker?

The statute is the law; the checker quotes it word for word and does the arithmetic. 23 jurisdictions were read on November 8, 2026; for California, Colorado, Nevada, New Jersey, New Mexico, Tennessee and Texas the text came from a published copy because the official site could not be read, and each page says so.

- Read the statute yourself when your state is not covered, when you need the newest text, or when a definition elsewhere in the code matters (Tennessee's holidays, where an act applies).
- Use the checker for the figure on your rent, the first fee day counted the statute's way, and the conditions in one place, with the sentence each answer rests on.
