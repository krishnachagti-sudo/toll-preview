## Steps

1. **Age each clearing account.** Export each one for the month and run the preview: aging totals and the tie-out.
2. **Confirm last month's deposits.** Load the bank statement; every deposit should have one set. Record the deposits that do.
3. **Follow up anything over 30 days.** Use the month's 30-day cut-off date; everything on or before it goes on the follow-up list.
4. **Log the closing balance.** Write the balance and the over-30 total in the review log.
5. **Send one list of questions.** One message to the client with every open question.
