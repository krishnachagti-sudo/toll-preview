# The For review tab: match, add, exclude

In QuickBooks Online's For review tab, Match links a bank line to an entry you already made, adding (Categorize) creates a new entry, and Exclude keeps the line out of the books; in this worked month, 2 lines should be matched, 1 excluded, and the other 4 have no twin and are added as usual.

## The three actions

What each does, in Intuit's words where it has them

| Action | Use it when | Effect on the books |
| --- | --- | --- |
| Match | Choose this option if you already entered a record for the transaction in QuickBooks. | No new entry: the bank line is linked to the existing one |
| Add (Categorize) | Choose this option if you don't have an existing record. This creates a brand-new record in QuickBooks. | A new entry in the register |
| Exclude | The line is a duplicate, or not for these books | None: the line moves to the Excluded tab |

## How matches are suggested

Intuit says QuickBooks suggests matches in "90 days before to 20 days after the transaction date", and "Find other match" searches when the suggestion is wrong. If the record is already reconciled: "You already reconciled the record. In this case, exclude the transaction so it doesn't create a duplicate."

## Excluded lines

They stay in the Excluded tab and can go back: "Select the Excluded tab, select the checkbox, then select Undo." And: "Once a downloaded transaction is added or excluded, QuickBooks stops the bank from downloading it again."
