How to cite Endwise

To cite a figure, give the page title, Endwise, the page address, the date the page shows after "Data as of", and the official source the page names. For example, the page "US federal holidays 2026: dates and observed days" shows data as of October 30, 2026.

What should a citation include?

  • The page title and the site name.
  • The page address. Content pages have stable addresses: once a page is public it stays public (the site keeps a release ledger of public pages).
  • The data date. Every page shows Data as of and a date, or Worked out for and a date on pages that depend on the day.
  • The official source the page names, such as the agency or the law.
  • The day you accessed the page.

How do I cite US federal holidays 2026: dates and observed days?

This example uses a real table page, US federal holidays 2026: dates and observed days, whose data date is October 30, 2026. In APA style:

Endwise. (2026, October 30). US federal holidays 2026: dates and observed days. https://krishnachagti-sudo.github.io/toll-preview/business-days/us-federal-holidays-2026/

In MLA style:

"US federal holidays 2026: dates and observed days." Endwise, 30 Oct. 2026, https://krishnachagti-sudo.github.io/toll-preview/business-days/us-federal-holidays-2026/.

If your style asks for an access date, add the day you read the page. Put the title in italics where your style asks for it.

To cite the rule behind the figure, cite the official source as well. The page names these: OPM: Federal holidays and OPM: Federal holidays, "in lieu of" days.

The same page as Markdown: https://krishnachagti-sudo.github.io/toll-preview/business-days/us-federal-holidays-2026.md. As CSV: https://krishnachagti-sudo.github.io/toll-preview/business-days/us-federal-holidays-2026.csv.

How do I cite a tool answer, not a table?

A tool's answer names the data it used and the official source. Cite the tool page, give the inputs you used and the day you ran it, and cite the official source the answer names. The same inputs give the same answer for as long as the data and the rules stay the same; the data updates page lists when they change.

Where do the sources come from?

Every tool and table page names its official sources. The sources page lists them with the edition and the day each was read.

Steps

  1. Copy the page address. Use the address of the page the figure is on. Every content page has its own address and a Markdown copy at the same address ending in .md.
  2. Note the data date. Every content page shows "Data as of" and a date, or "Worked out for" and a date on pages that depend on the day. Use that date.
  3. Name the official source. Each page names the official sources its figures come from, in its Sources block. Cite the official source for the underlying rule or rate as well.
  4. Add the date you read it. Add the day you accessed the page. Citation styles that need an access date ask for it.

Questions

Should I cite Endwise or the official source?

Both when you can. Endwise worked out or collected the figure, and the official source is where the rule or rate comes from. Each page names the official source so you can cite it directly.

Which date goes in the citation?

The date after "Data as of" on the page is the day its data last changed. Pages that depend on the day show "Worked out for" and the day instead. Add the day you accessed the page too.

Will the page address keep working?

Once a content page is public it stays public: the site records it in a release ledger and keeps it. The data on it can still change, which is why the page shows its data date.

Is there a plain-text copy I can quote from?

Yes. Each content page has a Markdown copy at the same address with .md at the end, and each table page has a CSV copy ending in .csv.
