# Keeping a deposit when the client cancels

On an $8,000 project with a $4,000.00 deposit, if the client cancels after 30% of the work ($2,400.00 of it) is done, $1,600.00 of the deposit is not yet earned: what happens to it is what your contract says, subject to local law.

## The arithmetic

|  | Amount |
| --- | ---: |
| Project price | $8,000.00 |
| Deposit paid (50%) | $4,000.00 |
| Work done when the client cancels (30%) | $2,400.00 |
| Deposit not yet earned by work | $1,600.00 |

## Clause wording

- "The deposit secures the start date and pays for work done. If the client cancels, the deposit is kept up to the value of the work done at that date, and any rest is refunded within 14 days."
- "The deposit is non-refundable once work has started, because it pays for time reserved that cannot be resold." (State what it pays for: a bare "non-refundable" label may not hold everywhere.)
- "If the client cancels, work done is invoiced at the agreed rates, less the deposit; a deposit above the work done is refunded."

## If you agree a settlement

Returning part of the deposit for work not started is a common way to end things cleanly. Put the amount, the date and that it settles the contract in writing, signed by both.

## Home improvement

In California, CSLB says payments cannot exceed the value of the work performed, the down payment excepted, and caps that down payment; Maryland and Maine cap home-improvement deposits at one-third. See [stage payments for contractors](https://krishnachagti-sudo.github.io/toll-preview/payment-schedule/guides/stage-payments-contractors/).
