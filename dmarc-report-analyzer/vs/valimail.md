# Valimail Monitor and this analyzer

Valimail's Monitor plan is free and applies "precision sender intelligence" to pre-configured sending services, with API access listed as an add-on on Starter and Premium and included on Enterprise (paid plans by quote); this analyzer needs no account or rua change for one report, and its API is per report with no plan (Valimail's pricing page read November 8, 2026).

## Try a report here

[Open this sample in the analyzer](https://krishnachagti-sudo.github.io/toll-preview/dmarc-report-analyzer/?sample=google)

## What Valimail Monitor offers

- Free (Monitor): account and domain dashboards, precision sender intelligence for pre-configured sending services.
- Starter, Premium and Enterprise: "Contact Us for Pricing".
- API access: not on Free, an add-on on Starter and Premium, included on Enterprise.
- Subdomain management and reporting from the Premium plan.

## What this analyzer does

- Reads one report, or up to 50 at once, the moment you have it: .xml, .gz, .zip or the .eml, RFC 9990 or RFC 7489. You do not change your rua= address.
- Names the service behind each IP from published provider data, says why it failed and how it is usually fixed, with the evidence.
- One report on the page is free; over the API, MCP or several files at once it is $0.01 a report file for the first 1,000 a month, then $0.002; no subscription.
- Keeps nothing: there is no history or dashboard, by design.

## When Valimail Monitor is better

- You want reports collected continuously with dashboards at no cost, and are happy to point rua at Valimail.
- You want a managed path to enforcement for a larger company.
