About

Exact tools
for specific jobs.

Toll is made by a small team at Conyso. Each tool does one job, gives the same answer every time, and is paid for per use.

What we make

Small tools,
exact answers.

Each tool answers one question exactly, and shows how it got there: the holidays it skipped, the date of the rate it used, the day an order is handed over. The live tools are 1099 threshold tracker, Business days, Delivery date and holiday order-by calculator, Exchange rate on a date, Image to size, Mileage reimbursement and IRS mileage log, Tax set-aside per payment and Trucker per diem worksheet.

There is no AI model in any answer. Each tool follows a fixed method over a named official source, so the same input always gives the same answer, on the web, over the REST API and over MCP.

  • AnswersSame input, same answer

    A fixed method and a named source, with no AI in the loop.

  • PayingPer use, from one balance

    Top up from $20 / ₹200. No subscription, and every amount shown to the fraction of a cent.

  • PrivacyNo ad or analytics trackers

    IP addresses are not stored. What we keep.
