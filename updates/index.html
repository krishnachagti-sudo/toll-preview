What changed in the data and rules, and when?

Newest first. Each line is a change to the data or the rules a tool uses: a rate added, a rule corrected, a new official source. The date is the day the change went into the site. Lines about downloaded data, such as exchange rates, are written by the server when it notices the data a tool holds has changed. Changes to how the site looks or to its code are not listed.

What data does each tool hold right now?

The data each tool holds has not been recorded yet on this copy of the site. Each tool's answer names the data it used.

Where can I see the sources and the checks behind the data?

The sources page lists, for every tool, the official documents the data comes from, the edition or date of each and the day it was read, and what the tool's tests compare the answers with.

Questions

How do I know the data a tool used is current?

Each answer names the data it used, and each source has a date it was last read. This log lists when data went in or a rule changed. The sources page shows the edition and read date for every source.

Where do the dates in this log come from?

From the history of the site's data files. The date is the day the change went into the site. The source named in each entry is the official document or page the data was read from.

Does a change to the data change an old answer?

The same input gives the same answer for as long as the data and the rules behind it stay the same. When a rule is corrected, the tool gives the corrected answer from then on, and the correction is listed here.
