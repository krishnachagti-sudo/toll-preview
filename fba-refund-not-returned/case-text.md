# Case text for a refund that never came back

A customer return claim names the order, the refund date, what the returns and reimbursements reports show and the window; in the sample, 4 orders are inside it on November 8, 2026, the most urgent 112-0000004-0000004, which closes November 12, 2026.

## A customer return claim

```
Subject: FBA customer return claim, order 112-0000004-0000004

Hello,

I am filing a customer return claim under the FBA inventory reimbursement policy (Customer return claims) for order 112-0000004-0000004, SKU LAMP-01.

- Customer refunded on July 15, 2026 (116 days ago), 1 unit, $34.50.
- FBA Customer Returns report: no unit received as of November 8, 2026.
- Reimbursements report: no reimbursement for this order.
- This is inside the claim window: September 13, 2026 to November 12, 2026.

Please reimburse the 1 unit not returned, valued as the policy states (the refund amount minus applicable fees).

Thank you.
```

## A valuation dispute

```
Subject: Reimbursement valuation, order 112-0000006-0000006

Hello,

For order 112-0000006-0000006, SKU MUG-BLUE, the customer was refunded $24.99 for 1 unit on August 1, 2026, and reimbursement 9000000006 of October 1, 2026 paid $8.12 for 1 unit.

The policy values a customer return claim at the refund amount minus applicable fees. Please show which fees make up the $16.87 difference, or correct the reimbursement. This is within 60 days of the reimbursement (by November 30, 2026).

Thank you.
```

## Before you send it

- Check the Eligible for claim tab of the Inventory Defect and Reimbursement portal: Amazon may already list the order, with its own form.
- One order per claim: the claim tool on Amazon's page asks for one order ID.
- Never before the window opens: Amazon's policy warns against submitting premature requests, or submitting a large number of requests in a short time.
- Amazon won't reimburse you for any refund that you issue directly to a customer.
