Website checks

Bulk redirect chain checker

Paste the URLs you moved, or your redirect map with the old and new URL on each line. Every URL is followed hop by hop. You see each status code, where it loops, which redirects are temporary 302s instead of 301s, any plain-HTTP hop, Google's 10-hop limit, the final status, and whether each old URL lands where you meant it to.

Up to 10 URLs at a time are free on this page. Longer lists need an account: $0.0003 per URL, and $0.0001 per URL after 20,000 in a month. A URL listed twice is charged once, and URLs not reached in a run are not charged.

One per line. For a redirect map, put the expected new URL (or just its path, like /new-page) after a comma or tab.

What the report says

Permanent or temporary

Google treats 301 and 308 as permanent redirects and 302, 303 and 307 as temporary; an instant meta refresh counts as permanent and a delayed one as temporary. Google uses a permanent redirect as a strong signal to index the target and a temporary one as a weak signal.

Chains, loops and limits

One hop is the aim. Two or more is a chain, with the URL to point straight at; five or more is long. Google's crawlers follow up to 10 hops by default; past that the report says so. A URL that comes back to one it already visited is a loop, with the hop where it starts.

Plain HTTP and the expected target

Any http:// URL after the first hop, a jump from https to http, or a chain that ends on http is flagged. With a redirect map, each old URL is matched against its new URL: in one hop, through a chain, off only by a trailing slash, sent to the homepage, or somewhere else.

Already ran curl? Paste its output

Paste what curl -sIL https://your-url printed and the URL you gave it. The same rules judge it, with nothing sent anywhere. Free.

Please read

  • A check shows what each server answered at that moment, to one request from our server in the United States with the user agent shown. Servers can answer differently for other user agents, countries, cookies or logins, and some block automated requests.
  • JavaScript redirects are not followed: only HTTP redirects (301, 302, 303, 307, 308), the Refresh header and meta refresh tags in the first 64 kB of a page.
  • What Google does with redirects is quoted from Google Search Central with the date it was read. Nothing here promises a ranking effect.
  • Private, local, link-local (cloud metadata) and reserved addresses are never fetched, on any hop; only ports 80, 443, 8080 and 8443 are used.
  • Check only sites you own or are working on. Each host gets at most two requests at a time.
