HTTP to HTTPS redirect checker

Every variant should reach the canonical URL in one permanent hop. In the worked example below, a site that sends http to https and then adds www takes 2 hops from http://example.com/, and one variant uses a 302; pointing each variant straight at https://www.example.com/ with a 301 cuts every one to a single hop.

Check your four variants

One per line in the full tool: http and https, with and without www.

Open this in the full tool

Before: two rules in a row

TypedHopsChainVerdict
http://example.com/2301 http://example.com/ > 301 https://example.com/ > 200 https://www.example.com/Chain (2 or more hops)
http://www.example.com/1302 http://www.example.com/ > 200 https://www.example.com/Temporary redirect (302, 303, 307 or delayed refresh)
https://example.com/1301 https://example.com/ > 200 https://www.example.com/OK
https://www.example.com/0200 https://www.example.com/OK

After: one hop each

TypedHopsWhat the hop changesVerdict
http://example.com/1http to https, adds wwwOK
http://www.example.com/1http to httpsOK
https://example.com/1adds wwwOK
https://www.example.com/0no redirectOK

Worked example on example.com addresses, judged by the checker's own rules. With HSTS, a browser that has visited before skips the http hop itself, so a first visit can still show it; the checker always sends the http request.
