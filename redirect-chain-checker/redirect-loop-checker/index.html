Redirect checks

Redirect loop checker

A redirect loop is a chain that comes back to a URL it already visited; the checker stops there, names the hop where the loop starts and the two rules that alternate. Of the 5 common patterns below, 4 loop within two URLs.

The usual loops and what the checker says

PatternHopsLoop starts at hopWhat the report says
http and https fight301 https://example.com/a > 301 http://example.com/a1The loop alternates between http and https of the same URL: one rule sends visitors to https and another sends them back. Look for an https-to-http rule at the origin, a proxy or a CMS setting.
www and bare host fight301 https://example.com/ > 301 https://www.example.com/1The loop alternates between the www and bare host: two rules disagree on which one is canonical.
Trailing slash added and removed301 https://example.com/shop > 301 https://example.com/shop/1The loop adds and removes a trailing slash: two rules disagree on the slash.
Three-step cycle302 https://example.com/a > 302 https://example.com/b > 302 https://example.com/c1Redirect loop
Redirects to itself behind Cloudflare301 https://example.com/1This URL redirects to itself behind Cloudflare: Cloudflare documents this loop when the origin redirects HTTP to HTTPS while the SSL/TLS encryption mode is Flexible. Its fix: remove the origin's HTTPS redirect or set the mode to Full or higher.

The browser shows ERR_TOO_MANY_REDIRECTS (Chrome) or "The page isn't redirecting properly" (Firefox) and gives up. It does not say which rule is wrong; the hop list does.

Cloudflare's documented loops

  • Flexible encryption mode, while the origin redirects all HTTP requests to HTTPS: Cloudflare reaches the origin over HTTP, the origin sends it to HTTPS, and the visitor sees the same URL again. Fix: remove the origin's HTTPS redirects or set the encryption mode to Full or higher.
  • Always Use HTTPS on, while the origin redirects HTTPS to HTTP. Fix: remove the origin's HTTP redirect or turn the setting off.
  • Redirect rules or Page Rules that conflict with each other.
  • Cloudflare: ERR_TOO_MANY_REDIRECTS (updated September 1, 2026, read November 7, 2026)
  • Google Search Central: HTTP status codes, network and DNS errors (updated February 4, 2026, read November 7, 2026)

Questions

How do I fix ERR_TOO_MANY_REDIRECTS on Cloudflare?

Cloudflare: with the Flexible encryption mode, redirect loops occur if the origin redirects all HTTP requests to HTTPS; the fix is to remove the origin's HTTPS redirects or set the SSL/TLS encryption mode to Full or higher.
