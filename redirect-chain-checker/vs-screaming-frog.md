# Endwise vs Screaming Frog for redirects

Screaming Frog SEO Spider is a crawler you download for Windows, macOS and Linux: free up to 500 URLs, then £199 per licence, per year. The Endwise checker needs no install and no licence: 10 URLs free on the page, then $0.0003 a URL.

## Side by side

Screaming Frog facts from its pricing page, read November 8, 2026.

|  | Screaming Frog SEO Spider | Endwise redirect checker |
| --- | --- | --- |
| What it is | A website crawler you download and run | A redirect checker on the web, over an API and MCP |
| Free use | Up to 500 URLs a crawl | Up to 10 URLs a check on the page |
| Paid | £199 per licence, per year | $0.0003 a URL ($0.0001 past 20,000 in a month), from a prepaid balance |
| Runs on | Windows, macOS and Linux | Any browser; any language that can send HTTP |
| Redirect map with expected targets | Not stated on its pricing page | Yes: old,new lines, each row marked on target or not |

## When Screaming Frog is the better choice

- You run a full site audit, not only redirects: it crawls the whole site and finds broken links, errors and redirects in one pass.
- You already own a licence and run it for every migration.
- You check large sites every week, where a yearly licence can cost less than paying per URL.

## When Endwise is the better choice

- You need to check one map after one launch and do not want a yearly licence.
- You cannot install software on your work machine.
- A script, an agent or a no-code tool needs to call the check: it is an API and an MCP tool.
- You want each old URL judged against its intended target: see the [redirect map template](https://krishnachagti-sudo.github.io/toll-preview/redirect-chain-checker/redirect-map-template/).

## Questions

### Is Screaming Frog free?

Its pricing page lists a free version with a crawl limit of 500 URLs, and a paid licence at £199 per licence, per year (read November 8, 2026).

### Do I need to install anything for Endwise?

No. It runs on the web page, over a REST API and over MCP.
