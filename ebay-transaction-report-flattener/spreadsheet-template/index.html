The template, filled

The columns

  • One column per fee column in your report, named as eBay named it (here: Final value fee - fixed, Final value fee - variable, International fee).
  • other_deductions_on_sale_row: Gross minus Net on the sale row that the fee columns do not explain (zero when they add up).
  • shipping_labels, ad_and_other_fees, refunds, claims_and_disputes, adjustments: eBay's rows with the same order number.
  • labels_outside_ebay and your_cost: what you add. kept and profit are worked out.

Sources

  • eBay Help (US): Reconciling your eBay sales transactions (read November 8, 2026)ebay.com
  • eBay Help (US): Earnings report (read November 8, 2026)ebay.com

Not tax or accounting advice: this is arithmetic on eBay's own transaction report. The sample reports are made up; their headings are the names eBay's help uses for these details, and your own report's headings may differ (the tool shows how it found each column).
