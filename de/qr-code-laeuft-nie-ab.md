# Läuft ein QR-Code ab? Statische und dynamische Codes im Vergleich

Ein statischer QR-Code enthält Ihren Link oder Ihre Angaben selbst und läuft nie ab; ein dynamischer enthält nur einen Kurzlink auf der Domain eines Anbieters und funktioniert nur, solange dieser Anbieter weiterleitet. Die Tabelle unten nennt 7 Anbieter, deren Weiterleitungs-Domains wir am 2. November 2026 geprüft haben.

## Läuft ein kostenloser QR-Code ab?

Ein statischer Code nicht: Seine Module schreiben Ihren Link, Ihre WLAN-Zugangsdaten oder Ihre Kontaktkarte direkt aus, und ein Handy liest sie vom Druck. Ein dynamischer Code schreibt stattdessen einen Kurzlink auf der Domain des Anbieters. Der Anbieter leitet jeden Scan auf Ihre Seite weiter, und das kann er einstellen, begrenzen oder an einen Tarif knüpfen.

DENSO WAVE, der Erfinder des QR-Codes, schreibt auf seiner FAQ-Seite (auf Englisch), dass für die Nutzung des QR-Codes weder ein Antrag noch ein Lizenzvertrag nötig ist, solange man die Normen JIS oder ISO einhält, und dass keine Gebühr anfällt. Ablaufen kann also nur etwas, das ein Dienst dazwischen betreibt.

## Woran erkenne ich, ob mein gedruckter QR-Code dynamisch ist?

- Scannen Sie den Code mit einer Kamera-App, die die Adresse anzeigt, bevor sie die Seite öffnet.
- Gehört die Domain Ihnen oder Ihrer Firma, ist der Code statisch. Ist es ein kurzer Link wie die Domains in der Tabelle unten, ist er dynamisch.
- Oder geben Sie das Bild des Codes in die Ablauf-Prüfung ein: Sie folgt dem Link wie ein Handy und sagt, ob und über welchen Anbieter er läuft.

Die Ablauf-Prüfung ist auf der [Werkzeugseite](https://krishnachagti-sudo.github.io/toll-preview/de/qr-code-generator/) kostenlos und braucht kein Konto.

## Kann ich einen dynamischen Code in einen statischen umwandeln?

Nein, denn die gedruckten Module enthalten den Link des Anbieters. Sie können aber für die Seite, zu der der alte Code heute führt, einen neuen statischen Code erstellen und neu drucken. Danach hängt er nicht mehr von einem Anbieter ab.

## Ein statischer Link braucht trotzdem seine Website

Ein statischer Code mit https://example.com/menu sagt das für immer. Zieht die Speisekarte um oder läuft die Domain aus, führt der Code ins Leere. Verweisen Sie gedruckte Codes auf eine Seite unter einer Domain, die Ihnen gehört.

## Fragen

### Laufen kostenlose QR-Codes ab?

Ein statischer Code kann nicht ablaufen: Was er sagt, steckt im Code selbst. Ein kostenloser dynamischer Code kann ablaufen, weil er über die Weiterleitung des Anbieters läuft; manche Anbieter begrenzen oder schalten kostenlose oder abgelaufene Codes ab. Die Tabelle auf dieser Seite nennt, was jeder Anbieter dazu schreibt.

### Woran erkenne ich, ob mein gedruckter QR-Code dynamisch ist?

Scannen Sie ihn und sehen Sie sich die Adresse an, bevor die Seite sich öffnet. Ist es ein Kurzlink auf der Domain eines QR-Anbieters statt Ihrer eigenen Website, ist er dynamisch. Die Prüfung auf der Werkzeugseite folgt dem Link und nennt den Anbieter.

### Kann ich einen dynamischen Code in einen statischen umwandeln?

Nein. Die gedruckten Module enthalten den Link des Anbieters. Sie können einen neuen statischen Code für die Seite erstellen, zu der er führt, und neu drucken.
