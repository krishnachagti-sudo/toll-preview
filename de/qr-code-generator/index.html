Aussehen und Druckgröße

Funktioniert ein bereits gedruckter Code bald nicht mehr?

Viele Generatoren erstellen dynamische Codes: Der Code enthält einen Kurzlink auf der Domain des Anbieters, der Scans nur so lange auf Ihre Seite weiterleitet, wie der Anbieter ihn eingeschaltet lässt. Geben Sie ein Bild des Codes oder seinen Inhalt an, dann folgt diese Prüfung dem Link so, wie es ein Handy täte.

Ein Screenshot oder Scan liest sich am besten. Ein Handyfoto wird mit dem eingebauten Code-Leser Ihres Browsers gelesen, wenn er einen hat.

Auf dieser Seite kostenlos. Ohne Konto zählt es als einer Ihrer kostenlosen Läufe pro Tag. Der Link wird von unserem Server aus aufgerufen, der nie private oder lokale Adressen öffnet.

Hier erscheint das Ergebnis.

Viele Codes aus einer Tabelle

Ein Code pro Zeile, als PNG- oder SVG-Dateien in einer ZIP-Datei mit Manifest, dazu ein Etikettenbogen zum Drucken. Die Zeilen werden zuerst hier geprüft; Sie zahlen nur für die erstellten Codes, und jede Datei wird gegen ihre Zeile zurückgelesen.

Welche Spalten gelesen werden

Eine Kopfzeile, dann ein Code pro Zeile. Nennen Sie die Inhaltsspalte nach ihrem Feldnamen: url, text, ssid und password (WLAN), firstName, lastName, phone, email (Kontaktkarte), to und subject (E-Mail), phone und message (SMS), latitude und longitude (Standort). Eine Spalte type kann die Art jeder Zeile festlegen. Bis zu drei Beschriftungsspalten (label, label2, label3) werden auf dem Bogen neben dem Code gedruckt. Excel-Textzellen behalten führende Nullen, und lange Seriennummern werden vollständig ausgeschrieben.

Fehlerkorrektur und Farben von oben gelten auch hier. {row} im Dateinamen ist die Tabellenzeile; {Beliebige Überschrift} ist diese Spalte.

Wird geprüft, sobald eine Tabelle geöffnet ist.

Braucht ein angemeldetes Konto mit Guthaben; das kostenlose Guthaben von $0.25 im Monat zählt mit.

Hinweise und Quellen lesen
  • Der Encoder folgt ISO/IEC 18004 (QR Code Model 2): numerischer, alphanumerischer und Byte-Modus, Versionen 1 bis 40 (21 x 21 bis 177 x 177 Module), Fehlerkorrektur L, M, Q und H sowie die acht Maskenmuster, die nach den Strafregeln der Norm gewählt werden. Seine Ausgabe wird in jeder Version und Stufe gegen einen unabhängigen Open-Source-Encoder getestet.
  • DENSO WAVE, der Erfinder des QR-Codes, verlangt auf allen Seiten eine Ruhezone von vier Modulen und empfiehlt 4 oder mehr Druckerpunkte pro Modul; die Druckprüfungen verwenden beides. Am häufigsten gewählte Stufe: M, etwa 15 % wiederherstellbar.
  • Inhaltsformate: WLAN, SMS, Telefon, Standort und E-Mail so, wie Kamera-Apps sie lesen (ZXing "Barcode Contents"); Kontaktkarten als vCard 3.0 (RFC 2426); E-Mail-Links nach RFC 6068. Für SMS-Codes gibt es keinen offiziellen Standard.
  • Die Prüfung folgt nur HTTP-Weiterleitungen (höchstens 10), von unserem Server aus, und nennt einen Anbieter nur, wenn seine Domain auf unserer geprüften Liste steht; sie kann Ihr Konto nicht sehen und nichts darüber versprechen, was ein Anbieter tun wird. Wir sind mit keinem genannten Anbieter verbunden.

Statisch

Die Module des Codes enthalten Ihren Link, Ihre WLAN-Zugangsdaten oder Ihre Kontaktkarte als Text.

Vollständige Regeln lesen

Die Module des Codes enthalten Ihren Link, Ihre WLAN-Zugangsdaten oder Ihre Kontaktkarte als Text. Ein Handy liest ihn direkt vom Druck. Es sitzt kein Dienst dazwischen, deshalb kann nichts auslaufen; ein statischer Link funktioniert allerdings nicht mehr, wenn die Website dahinter verschwindet.

Dynamisch

Der Code enthält einen Kurzlink auf der Domain eines Anbieters, und der Anbieter leitet jeden Scan auf Ihre Seite weiter.

Vollständige Regeln lesen

Der Code enthält einen Kurzlink auf der Domain eines Anbieters, und der Anbieter leitet jeden Scan auf Ihre Seite weiter. Sie können die Seite später ändern, aber der gedruckte Code funktioniert nur, solange der Anbieter weiterleitet. Was bei Vertragsende passiert, steht auf den Seiten der Anbieter; die Prüfung oben zitiert sie mit dem Datum, an dem sie gelesen wurden.

Nachweis bei jeder Datei

Jeder Download zeigt den genauen Text, den er enthält, dazu Version (Größe), Fehlerkorrekturstufe und Maske, und die Datei wird von einem unabhängigen Decoder zurückgelesen, bevor Sie sie bekommen.

Vollständige Regeln lesen

Jeder Download zeigt den genauen Text, den er enthält, dazu Version (Größe), Fehlerkorrekturstufe und Maske, und die Datei wird von einem unabhängigen Decoder zurückgelesen, bevor Sie sie bekommen. Verdeckt ein Logo zu viel, sagt Ihnen die Seite das, statt einen Code zu liefern, der vielleicht nicht scannt.
