# Las Cruces Minimum Wage 2026: $13.01

The Las Cruces minimum wage is $13.01 an hour from January 1, 2026 (tipped employees: $5.20 cash wage); it applies to work performed inside Las Cruces city limits, and the New Mexico rate is $12.00. Next: changes on January 1, 2027; the new rate was not published when we read the page.

## Where it applies

Inside Las Cruces city limits. A ZIP code can cross the boundary, so check the street address. Where the New Mexico rate is higher on a date, the higher rate applies.
