# Compared with a QuickBooks Online recurring journal

A QuickBooks Online recurring journal entry repeats the same amounts, which fits a policy that posts $100.00 every month; a policy starting November 17 by actual days posts $460.27 in its first month and $526.02 in its last, and a loan's interest falls every month, so those need computed entries.

## The three template types

- Scheduled: "Scheduled transactions other than invoices can be sent automatically without any changes."
- Reminder: "Reminders are created at regular times, but you need to edit and send them yourself."
- Unscheduled: "Unscheduled transactions need to be created and sent each time."
- Where: All apps, then Accounting, then Recurring transactions.

## Side by side

QuickBooks Online's side from Intuit's help, read November 8, 2026

|  | Recurring journal | This tool |
| --- | --- | --- |
| Same amount each month | Yes: Scheduled posts it | Yes |
| First and last partial months | Edit those two by hand (Reminder) | Computed |
| Loan interest that falls monthly | Edit each month | Computed, payment by payment |
| Many schedules | One template each | One import file |
| Cost | Included | $0.50 per schedule |

## When the recurring journal is better

- A few schedules with identical monthly amounts.
- Intuit itself suggests it when the amounts are going to always be the same.
