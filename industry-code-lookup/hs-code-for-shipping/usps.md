# HS codes on a USPS customs form

On a USPS customs form, the HS tariff code is a 6-to-10-digit number, and USPS says its tools (Click-N-Ship, Customs Forms Online) assign the HS code from a good item description; if you enter one yourself, its first 6 digits must be a real HS code, such as 6109.10 for cotton T-shirts, which has 14 US 10-digit lines.

- Digits: 6-to-10
- Example: 6109.10

## What USPS says

- HS tariff codes are 6-to-10-digit identifiers linked to specific goods descriptions.
- With USPS tools and acceptable descriptions, USPS assigns the HS code on your customs declaration.
- Item descriptions need detail: customs authorities use HS codes to screen incoming goods.

## If you enter the code yourself

- Make sure the first 6 digits are a valid HS code; the checker above says so and names the description.
- For a US export over $2,500 under one number, the EEI filing needs a 10-digit Schedule B or HTS number.
- Describe the item in plain words as well: material, use and what it is.

> Reference, not a customs ruling or tax advice: a code that exists may still be the wrong one for your goods or business. Only U.S. Customs and Border Protection (by a binding ruling) decides an import classification, and the IRS decides what goes on a return. Each answer names the official table it came from and that table's date; check the official source before you file.

## Questions

### Do I have to look up an HS code for USPS?

Not with USPS tools: USPS says that if you give acceptable descriptions in Click-N-Ship, Customs Forms Online or its other tools, it will assign the HS code.

### How many digits does USPS want?

USPS describes HS tariff codes as 6-to-10-digit identifiers. Six digits are the international part; 10 is the full US number.
