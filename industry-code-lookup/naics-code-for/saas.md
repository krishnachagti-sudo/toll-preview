## How to choose

- Use the code for the activity that brings in most of your receipts; SBA judges the primary industry by receipts, employees and costs (13 CFR 121.107).
- Read the Census definition on the code's page: the cross-references say what belongs elsewhere.
- For Schedule C, use the IRS list, which groups some NAICS codes; see the Schedule C business codes.

> Reference, not a customs ruling or tax advice: a code that exists may still be the wrong one for your goods or business. Only U.S. Customs and Border Protection (by a binding ruling) decides an import classification, and the IRS decides what goes on a return. Each answer names the official table it came from and that table's date; check the official source before you file.

## Questions

### What NAICS code do I use for SaaS (software as a service)?

513210 Software Publishers is the first the Census index gives for "software publisher". Use the code that matches the activity that brings in most of your receipts.

### Can I pick more than one NAICS code?

Many forms, such as SAM.gov, let you list several, with one primary. For SBA size, the primary industry is the one with the largest share of receipts, employees and costs (13 CFR 121.107).
