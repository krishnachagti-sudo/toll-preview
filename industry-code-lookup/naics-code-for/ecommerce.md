# NAICS code for an online store (e-commerce)

NAICS 2022 has no single code for an online store (e-commerce): the old 454110 (Electronic Shopping and Mail-Order Houses) was split across 42 retail codes by product, so an online store takes the retail code of what it mainly sells, such as 449210 Electronics and Appliance Retailers (SBA size standard $40 million in average annual receipts).

- First code: 449210
- Codes found: 25
- SBA size standard: $40 million in receipts

## Why there is no e-commerce code

454110 is not in NAICS 2022: it is a NAICS 2017 code (Electronic Shopping and Mail-Order Houses), now split across 42 NAICS 2022 codes, such as 441227 Motorcycle, ATV, and All Other Motor Vehicle Dealers, 441330 Automotive Parts and Accessories Retailers, 441340 Tire Dealers.

The IRS Schedule C instructions say the same: nonstore retailers select the code for the main product they sell.

## How to choose

- Use the code for the activity that brings in most of your receipts; SBA judges the primary industry by receipts, employees and costs (13 CFR 121.107).
- Read the Census definition on the code's page: the cross-references say what belongs elsewhere.
- For Schedule C, use the IRS list, which groups some NAICS codes; see the Schedule C business codes.

> Reference, not a customs ruling or tax advice: a code that exists may still be the wrong one for your goods or business. Only U.S. Customs and Border Protection (by a binding ruling) decides an import classification, and the IRS decides what goes on a return. Each answer names the official table it came from and that table's date; check the official source before you file.

## Questions

### What NAICS code do I use for an online store (e-commerce)?

The retail code for what you mainly sell; the Census index lists 449210 Electronics and Appliance Retailers first for "retailer".

### Can I pick more than one NAICS code?

Many forms, such as SAM.gov, let you list several, with one primary. For SBA size, the primary industry is the one with the largest share of receipts, employees and costs (13 CFR 121.107).
