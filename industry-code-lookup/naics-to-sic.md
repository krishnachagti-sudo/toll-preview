# NAICS to SIC

Chaining the Census concordances from NAICS 2022 back to 2002 and then to SIC 1987 links 1,009 of the 1,012 NAICS 2022 codes to 1,004 SIC industries; 547 map to exactly one SIC code, such as 541511 to 7371 Computer Programming Services.

- NAICS codes linked: 1,009
- SIC industries reached: 1,004
- Exactly one SIC code: 547

## How the chain works

1. NAICS 2022 to NAICS 2017 (Census 2022 to 2017 concordance)
2. 2017 to 2012, 2012 to 2007, 2007 to 2002 (Census concordances)
3. 2002 NAICS to 1987 SIC (Census table)

## Questions

### Is there an official NAICS 2022 to SIC table?

No: the Census Bureau's SIC table is for 2002 NAICS. This conversion follows its concordances from 2022 back to 2002, then the 2002 NAICS to 1987 SIC table.

### Why does one NAICS code give several SIC codes?

Industries were split and joined between editions, so a NAICS code can hold pieces of several SIC industries. The SIC code that fits depends on what the business does.

### Is SIC still used?

SIC 1987 is no longer revised: NAICS replaced it in 1997. Some forms, lenders and the SEC still ask for a SIC code.
