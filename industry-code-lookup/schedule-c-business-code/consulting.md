# Schedule C business code for consulting

For management, scientific or technical consulting, the IRS's 2025 Schedule C list gives 541600, "Management, scientific, & technical consulting services", under Professional, Scientific, & Technical Services. The IRS list has no code named for any app: the code describes the work, not the platform.

- Code: 541600
- IRS title: Management, scientific, & technical consulting services

## How to choose

- Pick the code for the work that brings in most of your receipts.
- If you do two kinds of work, such as rides and deliveries, use the main one; separate businesses file separate Schedules C.
- Codes come from the IRS list only: a NAICS code that is not on the list does not belong on line B.

The full list is on [Schedule C business codes](https://krishnachagti-sudo.github.io/toll-preview/industry-code-lookup/schedule-c-business-codes/).

> Reference, not a customs ruling or tax advice: a code that exists may still be the wrong one for your goods or business. Only U.S. Customs and Border Protection (by a binding ruling) decides an import classification, and the IRS decides what goes on a return. Each answer names the official table it came from and that table's date; check the official source before you file.

## Questions

### What business code do I put on Schedule C for consulting?

541600, Management, scientific, & technical consulting services, on the IRS list in the 2025 Schedule C instructions.

### Does the wrong business code change my tax?

The code classifies your business for the IRS; your tax comes from your income and expenses. Pick the code for the activity that brings in most of your receipts.
