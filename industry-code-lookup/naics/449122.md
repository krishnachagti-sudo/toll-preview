# NAICS 449122: Window Treatment Retailers

449122 is a valid NAICS 2022 code (national industry): Window Treatment Retailers; SBA size standard $11.5 million in average annual receipts; no change is proposed for NAICS 2027.

- Code: 449122
- SBA size standard: $11.5 million in receipts
- Census index entries: 2
- NAICS 2027 (proposed): no change

## The Census definition

This U.S. industry comprises establishments primarily engaged in retailing new window treatments, such as curtains, drapes, blinds, and shades.

## Census index entries (2)

- Curtain and drapery stores, packaged
- Window treatment stores
