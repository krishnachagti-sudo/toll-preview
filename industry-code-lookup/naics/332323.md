# NAICS 332323: Ornamental and Architectural Metal Work Manufacturing

332323 is a valid NAICS 2022 code (national industry): Ornamental and Architectural Metal Work Manufacturing; SBA size standard 500 employees; no change is proposed for NAICS 2027.

- Code: 332323
- SBA size standard: 500 employees
- Census index entries: 42
- NAICS 2027 (proposed): no change

## The Census definition

This U.S. industry comprises establishments primarily engaged in manufacturing ornamental and architectural metal work, such as staircases, metal open steel flooring, fire escapes, railings, and scaffolding.
