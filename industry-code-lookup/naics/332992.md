# NAICS 332992: Small Arms Ammunition Manufacturing

332992 is a valid NAICS 2022 code (national industry): Small Arms Ammunition Manufacturing; SBA size standard 1,300 employees; NAICS 2027 proposes combining it into 332995 Small Arms, Ammunition, Ordnance, and Ordnance Accessories Manufacturing.

- Code: 332992
- SBA size standard: 1,300 employees
- Census index entries: 19
- NAICS 2027 (proposed): combined

## The Census definition

This U.S. industry comprises establishments primarily engaged in manufacturing small arms ammunition.
