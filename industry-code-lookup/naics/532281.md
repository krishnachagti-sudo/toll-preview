# NAICS 532281: Formal Wear and Costume Rental

532281 is a valid NAICS 2022 code (national industry): Formal Wear and Costume Rental; SBA size standard $25 million in average annual receipts; no change is proposed for NAICS 2027.

## The Census definition

This U.S. industry comprises establishments primarily engaged in renting clothing, such as formal wear, costumes (e.g., theatrical), or other clothing (except laundered uniforms and work apparel).
