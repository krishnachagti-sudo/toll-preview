# NAICS 611610: Fine Arts Schools

611610 is a valid NAICS 2022 code (national industry): Fine Arts Schools; SBA size standard $9 million in average annual receipts; no change is proposed for NAICS 2027.

- Code: 611610
- SBA size standard: $9 million in receipts

## The Census definition

This industry comprises establishments primarily engaged in offering instruction in the arts, including dance, art, drama, and music.
