# NAICS 327390: Other Concrete Product Manufacturing

327390 is a valid NAICS 2022 code (national industry): Other Concrete Product Manufacturing; SBA size standard 500 employees; no change is proposed for NAICS 2027.

- Code: 327390
- SBA size standard: 500 employees
- Census index entries: 25
- NAICS 2027 (proposed): no change

## The Census definition

This industry comprises establishments primarily engaged in manufacturing concrete products (except block, brick, and pipe).
