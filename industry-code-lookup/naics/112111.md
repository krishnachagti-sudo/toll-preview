# NAICS 112111: Beef Cattle Ranching and Farming

112111 is a valid NAICS 2022 code (national industry): Beef Cattle Ranching and Farming; SBA size standard $2.5 million in average annual receipts; no change is proposed for NAICS 2027.

- Code: 112111
- SBA size standard: $2.5 million in receipts
- Census index entries: 9
- NAICS 2027 (proposed): no change

## The Census definition

This U.S. industry comprises establishments primarily engaged in raising cattle (including cattle for dairy herd replacements).

## Census index entries (9)

- Backgrounding, cattle
- Beef cattle ranching or farming
- Calf (e.g., feeder, stocker, veal) production
- Cattle conditioning operations
- Cattle farming or ranching
- Dairy heifer replacement production
- Feeder calf production
- Stocker calf production
- Veal calf production
