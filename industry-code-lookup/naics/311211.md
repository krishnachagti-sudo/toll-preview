# NAICS 311211: Flour Milling

311211 is a valid NAICS 2022 code (national industry): Flour Milling; SBA size standard 1,050 employees; no change is proposed for NAICS 2027.

- Code: 311211
- SBA size standard: 1,050 employees
- Census index entries: 34
- NAICS 2027 (proposed): no change

## The Census definition

This U.S. industry comprises establishments primarily engaged in (1) milling flour or meal from grains (except rice) or vegetables and/or (2) milling flour and preparing flour mixes or doughs.
