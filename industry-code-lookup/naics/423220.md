# NAICS 423220: Home Furnishing Merchant Wholesalers

423220 is a valid NAICS 2022 code (national industry): Home Furnishing Merchant Wholesalers; SBA size standard 100 employees; no change is proposed for NAICS 2027.

- Code: 423220
- SBA size standard: 100 employees
- Census index entries: 37
- NAICS 2027 (proposed): no change

## The Census definition

This industry comprises establishments primarily engaged in the merchant wholesale distribution of home furnishings and/or housewares.
