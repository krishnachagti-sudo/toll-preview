# NAICS 112340: Poultry Hatcheries

112340 is a valid NAICS 2022 code (national industry): Poultry Hatcheries; SBA size standard $4 million in average annual receipts; no change is proposed for NAICS 2027.

- Code: 112340
- SBA size standard: $4 million in receipts
- Census index entries: 5
- NAICS 2027 (proposed): no change

## The Census definition

This industry comprises establishments primarily engaged in hatching poultry of any kind.

## Census index entries (5)

- Chicken hatcheries
- Egg hatcheries, poultry
- Hatcheries, poultry
- Poultry hatcheries
