# NAICS 561520: Tour Operators

561520 is a valid NAICS 2022 code (national industry): Tour Operators; SBA size standard $25 million in average annual receipts; no change is proposed for NAICS 2027.

- Code: 561520
- SBA size standard: $25 million in receipts
- Census index entries: 3
- NAICS 2027 (proposed): no change

## The Census definition

This industry comprises establishments primarily engaged in arranging and assembling tours. The tours are sold through travel agencies or tour operators. Travel or wholesale tour operators are included in this industry.

## Census index entries (3)

- Tour operators (i.e., arranging and assembling tours)
- Travel tour operators
- Wholesale tour operators
