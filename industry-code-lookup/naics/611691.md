# NAICS 611691: Exam Preparation and Tutoring

611691 is a valid NAICS 2022 code (national industry): Exam Preparation and Tutoring; SBA size standard $12.5 million in average annual receipts; no change is proposed for NAICS 2027.

## The Census definition

This U.S. industry comprises establishments primarily engaged in offering preparation for standardized examinations and/or academic tutoring services.
