# NAICS 424430: Dairy Product (except Dried or Canned) Merchant Wholesalers

424430 is a valid NAICS 2022 code (national industry): Dairy Product (except Dried or Canned) Merchant Wholesalers; SBA size standard 200 employees; no change is proposed for NAICS 2027.

- Code: 424430
- SBA size standard: 200 employees
- Census index entries: 18
- NAICS 2027 (proposed): no change

## The Census definition

This industry comprises establishments primarily engaged in the merchant wholesale distribution of dairy products (except dried or canned).
