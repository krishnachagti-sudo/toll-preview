# NAICS 334290: Other Communications Equipment Manufacturing

334290 is a valid NAICS 2022 code (national industry): Other Communications Equipment Manufacturing; SBA size standard 800 employees; NAICS 2027 proposes combining it into 334230 Communications Equipment Manufacturing.

- Code: 334290
- SBA size standard: 800 employees
- Census index entries: 22
- NAICS 2027 (proposed): combined

## The Census definition

This industry comprises establishments primarily engaged in manufacturing communications equipment (except telephone apparatus, radio and television broadcast equipment, and wireless communications equipment).
