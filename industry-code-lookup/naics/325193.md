# NAICS 325193: Ethyl Alcohol Manufacturing

325193 is a valid NAICS 2022 code (national industry): Ethyl Alcohol Manufacturing; SBA size standard 1,000 employees; no change is proposed for NAICS 2027.

- Code: 325193
- SBA size standard: 1,000 employees
- Census index entries: 4
- NAICS 2027 (proposed): no change

## The Census definition

This U.S. industry comprises establishments primarily engaged in manufacturing nonpotable ethyl alcohol.

## Census index entries (4)

- Denatured alcohol manufacturing
- Ethanol, nonpotable, manufacturing
- Ethyl alcohol, nonpotable, manufacturing
- Grain alcohol, nonpotable, manufacturing
