332420 is a valid NAICS 2022 code (national industry): Metal Tank (Heavy Gauge) Manufacturing; SBA size standard 750 employees; no change is proposed for NAICS 2027.

- Code: 332420

## The Census definition

This industry comprises establishments primarily engaged in cutting, forming, and joining heavy gauge metal to manufacture tanks, vessels, and other containers.
