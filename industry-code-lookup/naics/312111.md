# NAICS 312111: Soft Drink Manufacturing

312111 is a valid NAICS 2022 code (national industry): Soft Drink Manufacturing; SBA size standard 1,400 employees; no change is proposed for NAICS 2027.

- Code: 312111
- SBA size standard: 1,400 employees
- Census index entries: 18
- NAICS 2027 (proposed): no change

## The Census definition

This U.S. industry comprises establishments primarily engaged in manufacturing soft drinks and artificially carbonated waters.
