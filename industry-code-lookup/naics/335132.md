# NAICS 335132: Commercial, Industrial, and Institutional Electric Lighting Fixture Manufacturing

335132 is a valid NAICS 2022 code (national industry): Commercial, Industrial, and Institutional Electric Lighting Fixture Manufacturing; SBA size standard 600 employees; no change is proposed for NAICS 2027.

- Code: 335132

## The Census definition

This U.S. industry comprises establishments primarily engaged in manufacturing commercial, industrial, and institutional electric lighting fixtures.
