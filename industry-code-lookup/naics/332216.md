# NAICS 332216: Saw Blade and Handtool Manufacturing

332216 is a valid NAICS 2022 code (national industry): Saw Blade and Handtool Manufacturing; SBA size standard 750 employees; no change is proposed for NAICS 2027.

## The Census definition

This U.S. industry comprises establishments primarily engaged in (1) manufacturing saw blades, all types (including those for power sawing machines) and/or (2) manufacturing nonpowered handtools and edge tools.
