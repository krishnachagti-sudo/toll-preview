# NAICS 441340: Tire Dealers

441340 is a valid NAICS 2022 code (national industry): Tire Dealers; SBA size standard $25.5 million in average annual receipts; no change is proposed for NAICS 2027.

- Code: 441340
- SBA size standard: $25.5 million in receipts
- Census index entries: 5
- NAICS 2027 (proposed): no change

## The Census definition

This industry comprises establishments primarily engaged in retailing new and/or used tires and tubes or retailing new tires in combination with automotive repair services.

## Census index entries (5)

- Automotive tire dealers
- Tire dealers, automotive
- Truck tires and tubes dealers (except heavy truck)
- Used automotive tire dealers
- Used tire dealers
