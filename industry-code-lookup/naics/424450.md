# NAICS 424450: Confectionery Merchant Wholesalers

424450 is a valid NAICS 2022 code (national industry): Confectionery Merchant Wholesalers; SBA size standard 225 employees; no change is proposed for NAICS 2027.

- Code: 424450
- SBA size standard: 225 employees

## The Census definition

This industry comprises establishments primarily engaged in the merchant wholesale distribution of confectioneries; salted or roasted nuts; popcorn; potato, corn, and similar chips; and/or fountain fruits and syrups.
