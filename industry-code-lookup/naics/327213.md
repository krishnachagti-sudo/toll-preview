# NAICS 327213: Glass Container Manufacturing

327213 is a valid NAICS 2022 code (national industry): Glass Container Manufacturing; SBA size standard 1,250 employees; no change is proposed for NAICS 2027.

- Code: 327213
- SBA size standard: 1,250 employees
- Census index entries: 8
- NAICS 2027 (proposed): no change

## The Census definition

This U.S. industry comprises establishments primarily engaged in manufacturing glass packaging, bottling, and canning containers.

## Census index entries (8)

- Beer bottles, glass, manufacturing
- Beverage containers, glass, manufacturing
- Bottles (i.e., bottling, canning, packaging), glass, manufacturing
- Containers for packaging, bottling, and canning, glass, manufacturing
- Food packaging, glass, manufacturing
- Glass packaging containers manufacturing
- Jars for packaging, bottling, and canning, glass, manufacturing
- Soda bottles, glass, manufacturing
