# NAICS 311119: Other Animal Food Manufacturing

311119 is a valid NAICS 2022 code (national industry): Other Animal Food Manufacturing; SBA size standard 650 employees; no change is proposed for NAICS 2027.

- Code: 311119
- SBA size standard: 650 employees
- Census index entries: 42
- NAICS 2027 (proposed): no change

## The Census definition

This U.S. industry comprises establishments primarily engaged in manufacturing animal food (except dog and cat) from ingredients, such as grains, oilseed mill products, and meat products.
