# NAICS 111332: Grape Vineyards

111332 is a valid NAICS 2022 code (national industry): Grape Vineyards; SBA size standard $4 million in average annual receipts; no change is proposed for NAICS 2027.

- Code: 111332
- SBA size standard: $4 million in receipts
- Census index entries: 2
- NAICS 2027 (proposed): no change

## The Census definition

This U.S. industry comprises establishments primarily engaged in growing grapes and/or growing grapes to sun dry into raisins.

## Census index entries (2)

- Grape farming without making wine
- Raisin farming
