# NAICS 325320: Pesticide and Other Agricultural Chemical Manufacturing

325320 is a valid NAICS 2022 code (national industry): Pesticide and Other Agricultural Chemical Manufacturing; SBA size standard 1,150 employees; no change is proposed for NAICS 2027.

- Code: 325320
- SBA size standard: 1,150 employees
- Census index entries: 43
- NAICS 2027 (proposed): no change

## The Census definition

This industry comprises establishments primarily engaged in the formulation and preparation of agricultural and household pest control chemicals (except fertilizers).
