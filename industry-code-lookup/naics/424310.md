# NAICS 424310: Piece Goods, Notions, and Other Dry Goods Merchant Wholesalers

424310 is a valid NAICS 2022 code (national industry): Piece Goods, Notions, and Other Dry Goods Merchant Wholesalers; SBA size standard 100 employees; no change is proposed for NAICS 2027.

- Code: 424310
- SBA size standard: 100 employees

## The Census definition

This industry comprises establishments primarily engaged in the merchant wholesale distribution of piece goods, fabrics, knitting yarns (except industrial), thread and other notions, and/or hair accessories.
