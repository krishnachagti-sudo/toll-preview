# NAICS 922150: Parole Offices and Probation Offices

922150 is a valid NAICS 2022 code (national industry): Parole Offices and Probation Offices; no change is proposed for NAICS 2027.

- Code: 922150
- SBA size standard: none listed
- Census index entries: 6
- NAICS 2027 (proposed): no change

## The Census definition

This industry comprises government establishments primarily engaged in judicially administering probation offices, parole offices and boards, and pardon boards.

## Census index entries (6)

- Pardon boards and offices
- Parole offices, publicly administered
- Probation offices, publicly administered
- Public parole offices
