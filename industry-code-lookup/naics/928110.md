# NAICS 928110: National Security

928110 is a valid NAICS 2022 code (national industry): National Security; no change is proposed for NAICS 2027.

- Code: 928110
- SBA size standard: none listed
- Census index entries: 13
- NAICS 2027 (proposed): no change

## The Census definition

This industry comprises government establishments of the Armed Forces, including the National Guard, primarily engaged in national security and related activities.
