# NAICS 112410: Sheep Farming

112410 is a valid NAICS 2022 code (national industry): Sheep Farming; SBA size standard $3.5 million in average annual receipts; no change is proposed for NAICS 2027.

- Code: 112410
- SBA size standard: $3.5 million in receipts
- Census index entries: 5
- NAICS 2027 (proposed): no change

## The Census definition

This industry comprises establishments primarily engaged in raising sheep and lambs, or feeding lambs for fattening. The sheep or lambs may be raised for sale or wool production.

## Census index entries (5)

- Dairy sheep farming
- Feedlots (except stockyards for transportation), lamb
- Lamb feedlots (except stockyards for transportation)
- Milking dairy sheep
- Sheep farming (e.g., meat, milk, wool production)
