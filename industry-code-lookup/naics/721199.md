# NAICS 721199: All Other Traveler Accommodation

721199 is a valid NAICS 2022 code (national industry): All Other Traveler Accommodation; SBA size standard $9 million in average annual receipts; no change is proposed for NAICS 2027.

- Code: 721199
- SBA size standard: $9 million in receipts
- Census index entries: 9
- NAICS 2027 (proposed): no change

## The Census definition

This U.S. industry comprises establishments primarily engaged in providing short-term lodging (except hotels, motels, casino hotels, and bed-and-breakfast inns).
