# NAICS 238350: Finish Carpentry Contractors

238350 is a valid NAICS 2022 code (national industry): Finish Carpentry Contractors; SBA size standard $19 million in average annual receipts; no change is proposed for NAICS 2027.

- Code: 238350
- SBA size standard: $19 million in receipts
- Census index entries: 30

## The Census definition

This industry comprises establishments primarily engaged in finish carpentry work. The work performed may include new work, additions, alterations, maintenance, and repairs.
