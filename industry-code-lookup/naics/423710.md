# NAICS 423710: Hardware Merchant Wholesalers

423710 is a valid NAICS 2022 code (national industry): Hardware Merchant Wholesalers; SBA size standard 150 employees; no change is proposed for NAICS 2027.

- Code: 423710
- SBA size standard: 150 employees
- Census index entries: 21
- NAICS 2027 (proposed): no change

## The Census definition

This industry comprises establishments primarily engaged in the merchant wholesale distribution of hardware, knives, or handtools.
