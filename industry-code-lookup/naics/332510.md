# NAICS 332510: Hardware Manufacturing

332510 is a valid NAICS 2022 code (national industry): Hardware Manufacturing; SBA size standard 750 employees; no change is proposed for NAICS 2027.

## The Census definition

This industry comprises establishments primarily engaged in manufacturing metal hardware, such as metal hinges, metal handles, keys, and locks (except coin- or card-operated, time locks).
