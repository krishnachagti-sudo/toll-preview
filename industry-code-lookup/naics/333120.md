# NAICS 333120: Construction Machinery Manufacturing

333120 is a valid NAICS 2022 code (national industry): Construction Machinery Manufacturing; SBA size standard 1,250 employees; no change is proposed for NAICS 2027.

- Code: 333120
- SBA size standard: 1,250 employees
- Census index entries: 60
- NAICS 2027 (proposed): no change

## The Census definition

This industry comprises establishments primarily engaged in manufacturing construction machinery, surface mining machinery, and logging equipment.
