# NAICS 212290: Other Metal Ore Mining

212290 is a valid NAICS 2022 code (national industry): Other Metal Ore Mining; SBA size standard 1,250 employees; no change is proposed for NAICS 2027.

- Code: 212290
- SBA size standard: 1,250 employees
- Census index entries: 74
- NAICS 2027 (proposed): no change

## The Census definition

This industry comprises establishments primarily engaged in developing the mine site, mining, and/or beneficiating (i.e., preparing) metal ores (except iron and manganiferous ores valued for their iron content, gold ore, silver ore, copper, nickel, lead, and zinc ore).
