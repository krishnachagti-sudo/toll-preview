# NAICS 531320: Offices of Real Estate Appraisers

531320 is a valid NAICS 2022 code (national industry): Offices of Real Estate Appraisers; SBA size standard $9.5 million in average annual receipts; no change is proposed for NAICS 2027.

- Code: 531320
- SBA size standard: $9.5 million in receipts
- Census index entries: 4
- NAICS 2027 (proposed): no change

## The Census definition

This industry comprises establishments primarily engaged in estimating the fair market value of real estate.
