# NAICS 112930: Fur-Bearing Animal and Rabbit Production

112930 is a valid NAICS 2022 code (national industry): Fur-Bearing Animal and Rabbit Production; SBA size standard $3.75 million in average annual receipts; no change is proposed for NAICS 2027.

- Code: 112930
- SBA size standard: $3.75 million in receipts
- Census index entries: 5
- NAICS 2027 (proposed): no change

## The Census definition

This industry comprises establishments primarily engaged in raising fur-bearing animals including rabbits. These animals may be raised for sale or for their pelt production.

## Census index entries (5)

- Chinchilla production
- Fox production
- Fur-bearing animal production
- Mink production
- Rabbit production
