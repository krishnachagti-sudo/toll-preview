# NAICS 541511: Custom Computer Programming Services

541511 is a valid NAICS 2022 code (national industry): Custom Computer Programming Services; SBA size standard $34 million in average annual receipts; no change is proposed for NAICS 2027.

- Code: 541511
- SBA size standard: $34 million in receipts
- Census index entries: 18
- NAICS 2027 (proposed): no change

## The Census definition

This U.S. industry comprises establishments primarily engaged in writing, modifying, testing, and supporting software to meet the needs of a particular customer.
