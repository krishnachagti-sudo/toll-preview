# NAICS 331410: Nonferrous Metal (except Aluminum) Smelting and Refining

331410 is a valid NAICS 2022 code (national industry): Nonferrous Metal (except Aluminum) Smelting and Refining; SBA size standard 1,000 employees; no change is proposed for NAICS 2027.

## The Census definition

This industry comprises establishments primarily engaged in (1) smelting ores into nonferrous metals and/or (2) the primary refining of nonferrous metals (except aluminum) by electrolytic methods or other processes.
