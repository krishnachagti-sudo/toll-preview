# NAICS 339992: Musical Instrument Manufacturing

339992 is a valid NAICS 2022 code (national industry): Musical Instrument Manufacturing; SBA size standard 1,000 employees; no change is proposed for NAICS 2027.

- Code: 339992
- SBA size standard: 1,000 employees
- Census index entries: 48
- NAICS 2027 (proposed): no change

## The Census definition

This U.S. industry comprises establishments primarily engaged in manufacturing musical instruments (except toys).
