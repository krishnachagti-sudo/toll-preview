# NAICS 111411: Mushroom Production

111411 is a valid NAICS 2022 code (national industry): Mushroom Production; SBA size standard $4.5 million in average annual receipts; no change is proposed for NAICS 2027.

- Code: 111411
- SBA size standard: $4.5 million in receipts
- Census index entries: 3
- NAICS 2027 (proposed): no change

## The Census definition

This U.S. industry comprises establishments primarily engaged in growing mushrooms under cover in mines underground, or in other controlled environments.

## Census index entries (3)

- Mushroom farming
- Mushroom spawn farming
- Shitake mushroom farming
