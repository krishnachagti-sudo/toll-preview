# NAICS 423330: Roofing, Siding, and Insulation Material Merchant Wholesalers

423330 is a valid NAICS 2022 code (national industry): Roofing, Siding, and Insulation Material Merchant Wholesalers; SBA size standard 225 employees; no change is proposed for NAICS 2027.

- Code: 423330
- SBA size standard: 225 employees

## The Census definition

This industry comprises establishments primarily engaged in the merchant wholesale distribution of nonwood roofing and nonwood siding and insulation materials.
