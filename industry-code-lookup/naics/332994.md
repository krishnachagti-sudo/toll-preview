# NAICS 332994: Small Arms, Ordnance, and Ordnance Accessories Manufacturing

332994 is a valid NAICS 2022 code (national industry): Small Arms, Ordnance, and Ordnance Accessories Manufacturing; SBA size standard 1,000 employees; NAICS 2027 proposes combining it into 332995 Small Arms, Ammunition, Ordnance, and Ordnance Accessories Manufacturing.

- Code: 332994
- SBA size standard: 1,000 employees
- Census index entries: 56
- NAICS 2027 (proposed): combined

## The Census definition

This U.S. industry comprises establishments primarily engaged in manufacturing small arms, other ordnance, and/or ordnance accessories.
