# NAICS 325120: Industrial Gas Manufacturing

325120 is a valid NAICS 2022 code (national industry): Industrial Gas Manufacturing; SBA size standard 1,200 employees; NAICS 2027 proposes moving biogas manufacturing to 325199 All Other Basic Organic Chemical Manufacturing.

- Code: 325120
- SBA size standard: 1,200 employees
- Census index entries: 25
- NAICS 2027 (proposed): part moves

## The Census definition

This industry comprises establishments primarily engaged in manufacturing industrial organic and inorganic gases in compressed, liquid, and solid forms.
