# NAICS 113110: Timber Tract Operations

113110 is a valid NAICS 2022 code (national industry): Timber Tract Operations; SBA size standard $19 million in average annual receipts; no change is proposed for NAICS 2027.

- Code: 113110
- SBA size standard: $19 million in receipts
- Census index entries: 1
- NAICS 2027 (proposed): no change

## The Census definition

This industry comprises establishments primarily engaged in the operation of timber tracts for the purpose of selling standing timber.
