# NAICS 333618: Other Engine Equipment Manufacturing

333618 is a valid NAICS 2022 code (national industry): Other Engine Equipment Manufacturing; SBA size standard 1,500 employees; NAICS 2027 proposes combining it into 333619 Other Engine and Power Transmission Equipment Manufacturing.

- Code: 333618
- SBA size standard: 1,500 employees
- Census index entries: 17
- NAICS 2027 (proposed): combined

## The Census definition

This U.S. industry comprises establishments primarily engaged in manufacturing internal combustion engines (except automotive gasoline and aircraft).
