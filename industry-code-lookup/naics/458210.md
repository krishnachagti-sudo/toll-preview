# NAICS 458210: Shoe Retailers

458210 is a valid NAICS 2022 code (national industry): Shoe Retailers; SBA size standard $34 million in average annual receipts; no change is proposed for NAICS 2027.

## The Census definition

This industry comprises establishments primarily engaged in retailing all types of new footwear (except hosiery and specialty sports footwear, such as golf shoes, bowling shoes, and cleated shoes). Establishments primarily engaged in retailing new tennis shoes or sneakers are included in this industry.

## Census index entries (5)

- Athletic shoe (except bowling, golf, cleated) stores
- Children's shoe stores
- Orthopedic shoes stores
- Shoe (except bowling, golf, cleated) stores
- Shoe stores, orthopedic
