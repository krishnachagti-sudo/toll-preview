# NAICS 332613: Spring Manufacturing

332613 is a valid NAICS 2022 code (national industry): Spring Manufacturing; SBA size standard 600 employees; no change is proposed for NAICS 2027.

- Code: 332613
- SBA size standard: 600 employees
- Census index entries: 21
- NAICS 2027 (proposed): no change

## The Census definition

This U.S. industry comprises establishments primarily engaged in manufacturing springs from purchased wire, strip, or rod.
