# NAICS 325414: Biological Product (except Diagnostic) Manufacturing

325414 is a valid NAICS 2022 code (national industry): Biological Product (except Diagnostic) Manufacturing; SBA size standard 1,250 employees; no change is proposed for NAICS 2027.

- Code: 325414
- SBA size standard: 1,250 employees
- Census index entries: 22
- NAICS 2027 (proposed): no change

## The Census definition

This U.S. industry comprises establishments primarily engaged in manufacturing vaccines, toxoids, blood fractions, and culture media of plant or animal origin (except diagnostic).
