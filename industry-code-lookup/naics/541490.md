# NAICS 541490: Other Specialized Design Services

541490 is a valid NAICS 2022 code (national industry): Other Specialized Design Services; SBA size standard $13.5 million in average annual receipts; no change is proposed for NAICS 2027.

- Code: 541490
- SBA size standard: $13.5 million in receipts
- Census index entries: 10
- NAICS 2027 (proposed): no change

## The Census definition

This industry comprises establishments primarily engaged in providing professional design services (except architectural, landscape architecture, engineering, interior, industrial, graphic, and computer systems design).
