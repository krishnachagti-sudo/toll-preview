# NAICS 332911: Industrial Valve Manufacturing

332911 is a valid NAICS 2022 code (national industry): Industrial Valve Manufacturing; SBA size standard 750 employees; NAICS 2027 proposes combining it into 332910 Metal Valve Manufacturing.

- Code: 332911
- SBA size standard: 750 employees
- Census index entries: 29
- NAICS 2027 (proposed): combined

## The Census definition

This U.S. industry comprises establishments primarily engaged in manufacturing industrial valves and valves for water works and municipal water systems.
