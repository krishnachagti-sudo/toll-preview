# NAICS 424720: Petroleum and Petroleum Products Merchant Wholesalers (except Bulk Stations and Terminals)

424720 is a valid NAICS 2022 code (national industry): Petroleum and Petroleum Products Merchant Wholesalers (except Bulk Stations and Terminals); SBA size standard 200 employees; no change is proposed for NAICS 2027.

- Code: 424720
- SBA size standard: 200 employees
- Census index entries: 22
- NAICS 2027 (proposed): no change

## The Census definition

This industry comprises establishments primarily engaged in the merchant wholesale distribution of petroleum and petroleum products (except from bulk liquid storage facilities).
