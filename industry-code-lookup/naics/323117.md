# NAICS 323117: Books Printing

323117 is a valid NAICS 2022 code (national industry): Books Printing; SBA size standard 1,250 employees; no change is proposed for NAICS 2027.

## The Census definition

This U.S. industry comprises establishments primarily engaged in printing or printing and binding books and pamphlets without publishing.
