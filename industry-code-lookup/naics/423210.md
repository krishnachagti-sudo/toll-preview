# NAICS 423210: Furniture Merchant Wholesalers

423210 is a valid NAICS 2022 code (national industry): Furniture Merchant Wholesalers; SBA size standard 100 employees; no change is proposed for NAICS 2027.

- Code: 423210
- SBA size standard: 100 employees
- Census index entries: 18
- NAICS 2027 (proposed): no change

## The Census definition

This industry comprises establishments primarily engaged in the merchant wholesale distribution of furniture (except hospital beds, medical furniture, and drafting tables).
