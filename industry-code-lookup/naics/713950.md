# NAICS 713950: Bowling Centers

713950 is a valid NAICS 2022 code (national industry): Bowling Centers; SBA size standard $12.5 million in average annual receipts; no change is proposed for NAICS 2027.

- Code: 713950

## The Census definition

This industry comprises establishments engaged in operating bowling centers. These establishments often provide food and beverage services.
