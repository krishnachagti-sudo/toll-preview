# NAICS 112390: Other Poultry Production

112390 is a valid NAICS 2022 code (national industry): Other Poultry Production; SBA size standard $3.75 million in average annual receipts; no change is proposed for NAICS 2027.

- Code: 112390
- SBA size standard: $3.75 million in receipts
- Census index entries: 10
- NAICS 2027 (proposed): no change

## The Census definition

This industry comprises establishments primarily engaged in raising poultry (except chickens for meat or egg production and turkeys).
