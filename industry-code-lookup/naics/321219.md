# NAICS 321219: Reconstituted Wood Product Manufacturing

321219 is a valid NAICS 2022 code (national industry): Reconstituted Wood Product Manufacturing; SBA size standard 750 employees; no change is proposed for NAICS 2027.

- Code: 321219
- SBA size standard: 750 employees
- Census index entries: 19
- NAICS 2027 (proposed): no change

## The Census definition

This U.S. industry comprises establishments primarily engaged in manufacturing reconstituted wood sheets and boards.
