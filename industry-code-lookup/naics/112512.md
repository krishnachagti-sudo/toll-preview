# NAICS 112512: Shellfish Farming

112512 is a valid NAICS 2022 code (national industry): Shellfish Farming; SBA size standard $3.75 million in average annual receipts; no change is proposed for NAICS 2027.

- Code: 112512
- SBA size standard: $3.75 million in receipts
- Census index entries: 11
- NAICS 2027 (proposed): no change

## The Census definition

This U.S. industry comprises establishments primarily engaged in farm raising shellfish (e.g., crayfish, shrimp, oysters, clams, mollusks).
