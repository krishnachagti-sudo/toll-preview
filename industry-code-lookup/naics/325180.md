# NAICS 325180: Other Basic Inorganic Chemical Manufacturing

325180 is a valid NAICS 2022 code (national industry): Other Basic Inorganic Chemical Manufacturing; SBA size standard 1,000 employees; no change is proposed for NAICS 2027.

- Code: 325180
- SBA size standard: 1,000 employees
- Census index entries: 198
- NAICS 2027 (proposed): no change

## The Census definition

This industry comprises establishments primarily engaged in manufacturing basic inorganic chemicals (except industrial gases and synthetic dyes and pigments).
