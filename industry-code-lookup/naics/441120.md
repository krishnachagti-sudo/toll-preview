# NAICS 441120: Used Car Dealers

441120 is a valid NAICS 2022 code (national industry): Used Car Dealers; SBA size standard $30.5 million in average annual receipts; no change is proposed for NAICS 2027.

- Code: 441120
- SBA size standard: $30.5 million in receipts
- Census index entries: 4
- NAICS 2027 (proposed): no change

## The Census definition

This industry comprises establishments primarily engaged in retailing used automobiles and light trucks, such as sport utility vehicles, and passenger and cargo vans.

## Census index entries (4)

- Antique auto dealers
- Automobile dealers, used only
- Light utility truck dealers, used only
- Used car dealers
