# NAICS 312112: Bottled Water Manufacturing

312112 is a valid NAICS 2022 code (national industry): Bottled Water Manufacturing; SBA size standard 1,100 employees; no change is proposed for NAICS 2027.

- Code: 312112
- SBA size standard: 1,100 employees
- Census index entries: 4
- NAICS 2027 (proposed): no change

## The Census definition

This U.S. industry comprises establishments primarily engaged in purifying and bottling water (including naturally carbonated).

## Census index entries (4)

- Beverages, naturally carbonated bottled water, manufacturing
- Naturally carbonated water, purifying and bottling
- Spring waters, purifying and bottling
- Water, naturally carbonated, purifying and bottling
