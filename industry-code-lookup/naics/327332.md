# NAICS 327332: Concrete Pipe Manufacturing

327332 is a valid NAICS 2022 code (national industry): Concrete Pipe Manufacturing; SBA size standard 750 employees; NAICS 2027 proposes combining it into 327330 Concrete Pipe, Brick, and Block Manufacturing.

- Code: 327332
- SBA size standard: 750 employees
- Census index entries: 9
- NAICS 2027 (proposed): combined

## The Census definition

This U.S. industry comprises establishments primarily engaged in manufacturing concrete pipe.
