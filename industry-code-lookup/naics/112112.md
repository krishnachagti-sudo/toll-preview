# NAICS 112112: Cattle Feedlots

112112 is a valid NAICS 2022 code (national industry): Cattle Feedlots; SBA size standard $22 million in average annual receipts; no change is proposed for NAICS 2027.

- Code: 112112
- SBA size standard: $22 million in receipts
- Census index entries: 5
- NAICS 2027 (proposed): no change

## The Census definition

This U.S. industry comprises establishments primarily engaged in feeding cattle for fattening.

## Census index entries (5)

- Beef cattle feedlots (except stockyards for transportation)
- Cattle feedlots (except stockyards for transportation)
- Fattening cattle
- Feed yards (except stockyards for transportation), cattle
- Feedlots (except stockyards for transportation), cattle
