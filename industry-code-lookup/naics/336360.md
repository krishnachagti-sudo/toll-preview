336360 is a valid NAICS 2022 code (national industry): Motor Vehicle Seating and Interior Trim Manufacturing; SBA size standard 1,500 employees; no change is proposed for NAICS 2027.

## The Census definition

This industry comprises establishments primarily engaged in manufacturing motor vehicle seating, seats, seat frames, seat belts, and interior trimmings.
