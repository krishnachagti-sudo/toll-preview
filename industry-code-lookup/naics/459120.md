# NAICS 459120: Hobby, Toy, and Game Retailers

459120 is a valid NAICS 2022 code (national industry): Hobby, Toy, and Game Retailers; SBA size standard $35 million in average annual receipts; no change is proposed for NAICS 2027.

- Code: 459120
- SBA size standard: $35 million in receipts
- Census index entries: 6
- NAICS 2027 (proposed): no change

## The Census definition

This industry comprises establishments primarily engaged in retailing new toys, games, and hobby and craft supplies (except needlecraft).

## Census index entries (6)

- Craft supply stores (except needlecraft)
- Hobby shops
- Magic supply stores
- Pottery (unfinished pottery to be painted by customer on premises) stores
- Toy stores
- Toy stores, electronic
