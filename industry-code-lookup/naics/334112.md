# NAICS 334112: Computer Storage Device Manufacturing

334112 is a valid NAICS 2022 code (national industry): Computer Storage Device Manufacturing; SBA size standard 1,250 employees; NAICS 2027 proposes combining it into 334110 Computer and Peripheral Equipment Manufacturing.

- Code: 334112
- SBA size standard: 1,250 employees
- Census index entries: 12
- NAICS 2027 (proposed): combined

## The Census definition

This U.S. industry comprises establishments primarily engaged in manufacturing computer storage devices that allow the storage and retrieval of data from a phase change, magnetic, optical, or magnetic/optical media. Examples of products made by these establishments are computer disk drives, USB flash drives, and tape storage and backup units.

- Tape storage units (e.g., drive backups), computer peripheral equipment, manufacturing
