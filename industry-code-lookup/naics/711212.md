# NAICS 711212: Racetracks

711212 is a valid NAICS 2022 code (national industry): Racetracks; SBA size standard $47 million in average annual receipts; no change is proposed for NAICS 2027.

- Code: 711212
- SBA size standard: $47 million in receipts
- Census index entries: 12

## The Census definition

This U.S. industry comprises establishments primarily engaged in operating racetracks without casinos. These establishments may also present and/or promote the events, such as auto, dog, and horse races, held in these facilities.
