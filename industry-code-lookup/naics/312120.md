# NAICS 312120: Breweries

312120 is a valid NAICS 2022 code (national industry): Breweries; SBA size standard 1,250 employees; no change is proposed for NAICS 2027.

- Code: 312120
- SBA size standard: 1,250 employees
- Census index entries: 12
- NAICS 2027 (proposed): no change

## The Census definition

This industry comprises establishments primarily engaged in brewing beer, ale, lager, malt liquors, and nonalcoholic beer.

## Census index entries (12)

- Ale brewing
- Beer brewing
- Beverages, beer, ale, and malt liquors, manufacturing
- Breweries
- Grain, brewers' spent, manufacturing
- Lager brewing
- Malt liquor brewing
- Microbreweries without restaurant or bar
- Near beer brewing
- Nonalcoholic beer brewing
- Porter brewing
- Stout brewing
