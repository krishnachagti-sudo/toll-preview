# NAICS 333514: Special Die and Tool, Die Set, Jig, and Fixture Manufacturing

333514 is a valid NAICS 2022 code (national industry): Special Die and Tool, Die Set, Jig, and Fixture Manufacturing; SBA size standard 500 employees; no change is proposed for NAICS 2027.

- Code: 333514
- SBA size standard: 500 employees
- Census index entries: 14
- NAICS 2027 (proposed): no change

## The Census definition

This U.S. industry comprises establishments, known as tool and die shops, primarily engaged in manufacturing special tools and fixtures, such as cutting dies and jigs.

- Dies and die holders for metal cutting and forming (except threading) manufacturing
- Dies, metalworking (except threading), manufacturing

- Jigs and fixtures for use with machine tools manufacturing
- Punches for use with machine tools manufacturing

- Welding positioners (i.e., jigs) manufacturing
- Wire drawing and straightening dies manufacturing
