# NAICS 561740: Carpet and Upholstery Cleaning Services

561740 is a valid NAICS 2022 code (national industry): Carpet and Upholstery Cleaning Services; SBA size standard $8.5 million in average annual receipts; no change is proposed for NAICS 2027.

- Code: 561740
- SBA size standard: $8.5 million in receipts
- Census index entries: 13
- NAICS 2027 (proposed): no change

## The Census definition

This industry comprises establishments primarily engaged in cleaning and dyeing used rugs, carpets, and upholstery.
