# NAICS 334419: Other Electronic Component Manufacturing

334419 is a valid NAICS 2022 code (national industry): Other Electronic Component Manufacturing; SBA size standard 750 employees; no change is proposed for NAICS 2027.

- Code: 334419
- SBA size standard: 750 employees
- Census index entries: 33
- NAICS 2027 (proposed): no change

## The Census definition

This U.S. industry comprises establishments primarily engaged in manufacturing electronic components (except bare printed circuit boards; semiconductors and related devices; electronic capacitors; electronic resistors; coils, transformers, and other inductors; connectors; and loaded printed circuit boards).
