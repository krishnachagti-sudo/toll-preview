# NAICS 316210: Footwear Manufacturing

316210 is a valid NAICS 2022 code (national industry): Footwear Manufacturing; SBA size standard 1,000 employees; no change is proposed for NAICS 2027.

- Code: 316210
- SBA size standard: 1,000 employees
- Census index entries: 89
- NAICS 2027 (proposed): no change

## The Census definition

This industry comprises establishments primarily engaged in manufacturing footwear (except orthopedic extension footwear).
