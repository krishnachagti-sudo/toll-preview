# NAICS 445291: Baked Goods Retailers

445291 is a valid NAICS 2022 code (national industry): Baked Goods Retailers; SBA size standard $16 million in average annual receipts; no change is proposed for NAICS 2027.

- Code: 445291
- SBA size standard: $16 million in receipts
- Census index entries: 1
- NAICS 2027 (proposed): no change

## The Census definition

This U.S. industry comprises establishments primarily engaged in retailing baked goods not for immediate consumption and not made on the premises.

## Census index entries (1)

- Baked goods (not made on premises) stores
