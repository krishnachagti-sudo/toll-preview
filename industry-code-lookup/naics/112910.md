# NAICS 112910: Apiculture

112910 is a valid NAICS 2022 code (national industry): Apiculture; SBA size standard $3.25 million in average annual receipts; no change is proposed for NAICS 2027.

## The Census definition

This industry comprises establishments primarily engaged in raising bees. These establishments may collect and gather honey; and/or sell queen bees, packages of bees, royal jelly, bees' wax, propolis, venom, pollen, and/or other bee products.

## Census index entries (7)

- Bee pollen collection
- Bee production (i.e., apiculture)
- Beeswax production
- Honey bee production
- Propolis production, bees
- Queen bee production
- Royal jelly production, bees
