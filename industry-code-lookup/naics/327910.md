# NAICS 327910: Abrasive Product Manufacturing

327910 is a valid NAICS 2022 code (national industry): Abrasive Product Manufacturing; SBA size standard 900 employees; no change is proposed for NAICS 2027.

## The Census definition

This industry comprises establishments primarily engaged in manufacturing abrasive grinding wheels of natural or synthetic materials, abrasive-coated products, and other abrasive products.
