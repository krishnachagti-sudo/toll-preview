# NAICS 321920: Wood Container and Pallet Manufacturing

321920 is a valid NAICS 2022 code (national industry): Wood Container and Pallet Manufacturing; SBA size standard 500 employees; no change is proposed for NAICS 2027.

- Code: 321920
- SBA size standard: 500 employees
- Census index entries: 62
- NAICS 2027 (proposed): no change

## The Census definition

This industry comprises establishments primarily engaged in manufacturing wood pallets, wood box shook, wood boxes, other wood containers, and wood parts for pallets and containers.
