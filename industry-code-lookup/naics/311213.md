# NAICS 311213: Malt Manufacturing

311213 is a valid NAICS 2022 code (national industry): Malt Manufacturing; SBA size standard 500 employees; NAICS 2027 proposes combining it into 311214 Rice Milling and Malt Manufacturing.

- Code: 311213
- SBA size standard: 500 employees
- Census index entries: 12
- NAICS 2027 (proposed): combined

## The Census definition

This U.S. industry comprises establishments primarily engaged in manufacturing malt from barley, rye, or other grains.
