# NAICS 424410: General Line Grocery Merchant Wholesalers

424410 is a valid NAICS 2022 code (national industry): General Line Grocery Merchant Wholesalers; SBA size standard 250 employees; no change is proposed for NAICS 2027.

- Code: 424410
- SBA size standard: 250 employees
- Census index entries: 3

## The Census definition

This industry comprises establishments primarily engaged in the merchant wholesale distribution of a general line (wide range) of groceries.

## Census index entries (3)

- Food, general-line, merchant wholesalers
- General-line groceries merchant wholesalers
- Groceries, general-line, merchant wholesalers
