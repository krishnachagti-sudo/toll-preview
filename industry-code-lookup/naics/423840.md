# NAICS 423840: Industrial Supplies Merchant Wholesalers

423840 is a valid NAICS 2022 code (national industry): Industrial Supplies Merchant Wholesalers; SBA size standard 125 employees; no change is proposed for NAICS 2027.

- Code: 423840
- SBA size standard: 125 employees
- Census index entries: 60
- NAICS 2027 (proposed): no change

## The Census definition

This industry comprises establishments primarily engaged in the merchant wholesale distribution of supplies for machinery and equipment generally used in manufacturing, oil well, and warehousing activities.
