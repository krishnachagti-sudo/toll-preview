333515 is a valid NAICS 2022 code (national industry): Cutting Tool and Machine Tool Accessory Manufacturing; SBA size standard 500 employees; no change is proposed for NAICS 2027.

## The Census definition

This U.S. industry comprises establishments primarily engaged in manufacturing accessories and attachments for metal cutting and metal forming machine tools.
