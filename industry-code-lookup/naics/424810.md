# NAICS 424810: Beer and Ale Merchant Wholesalers

424810 is a valid NAICS 2022 code (national industry): Beer and Ale Merchant Wholesalers; SBA size standard 200 employees; no change is proposed for NAICS 2027.

- Code: 424810
- SBA size standard: 200 employees

## The Census definition

This industry comprises establishments primarily engaged in the merchant wholesale distribution of beer, ale, porter, and other fermented malt beverages.

## Census index entries (7)

- Alcoholic beverages (except distilled spirits, wine) merchant wholesalers
- Ale merchant wholesalers
- Beer merchant wholesalers
- Beverages, alcoholic (except distilled spirits, wine), merchant wholesalers
- Fermented malt beverages merchant wholesalers
- Malt liquor merchant wholesalers
- Porter merchant wholesalers
