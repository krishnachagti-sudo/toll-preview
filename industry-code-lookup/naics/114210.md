# NAICS 114210: Hunting and Trapping

114210 is a valid NAICS 2022 code (national industry): Hunting and Trapping; SBA size standard $8.5 million in average annual receipts; no change is proposed for NAICS 2027.

## The Census definition

This industry comprises establishments primarily engaged in one or more of the following: (1) commercial hunting and trapping; (2) operating commercial game preserves, such as game retreats; and (3) operating hunting preserves.

## Census index entries (6)

- Animal trapping, commercial
- Fishing preserves
- Game preserves, commercial
- Game propagation
- Game retreats
- Hunting preserves
