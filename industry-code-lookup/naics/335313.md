# NAICS 335313: Switchgear and Switchboard Apparatus Manufacturing

335313 is a valid NAICS 2022 code (national industry): Switchgear and Switchboard Apparatus Manufacturing; SBA size standard 1,250 employees; no change is proposed for NAICS 2027.

- Code: 335313
- SBA size standard: 1,250 employees
- Census index entries: 29
- NAICS 2027 (proposed): no change

## The Census definition

This U.S. industry comprises establishments primarily engaged in manufacturing switchgear and switchboard apparatus.
