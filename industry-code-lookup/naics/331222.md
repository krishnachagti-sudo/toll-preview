# NAICS 331222: Steel Wire Drawing

331222 is a valid NAICS 2022 code (national industry): Steel Wire Drawing; SBA size standard 1,000 employees; no change is proposed for NAICS 2027.

- Code: 331222
- SBA size standard: 1,000 employees
- Census index entries: 24
- NAICS 2027 (proposed): no change

## The Census definition

This U.S. industry comprises establishments primarily engaged in drawing wire from purchased steel.
