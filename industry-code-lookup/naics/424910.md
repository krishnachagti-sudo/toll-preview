# NAICS 424910: Farm Supplies Merchant Wholesalers

424910 is a valid NAICS 2022 code (national industry): Farm Supplies Merchant Wholesalers; SBA size standard 200 employees; no change is proposed for NAICS 2027.

- Code: 424910

## The Census definition

This industry comprises establishments primarily engaged in the merchant wholesale distribution of farm supplies, such as animal feeds, fertilizers, agricultural chemicals, pesticides, plant seeds, and plant bulbs.
