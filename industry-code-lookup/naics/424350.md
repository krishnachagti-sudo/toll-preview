# NAICS 424350: Clothing and Clothing Accessories Merchant Wholesalers

424350 is a valid NAICS 2022 code (national industry): Clothing and Clothing Accessories Merchant Wholesalers; SBA size standard 150 employees; no change is proposed for NAICS 2027.

- Code: 424350
- SBA size standard: 150 employees
- Census index entries: 59
- NAICS 2027 (proposed): no change

## The Census definition

This industry comprises establishments primarily engaged in the merchant wholesale distribution of clothing and clothing accessories.
