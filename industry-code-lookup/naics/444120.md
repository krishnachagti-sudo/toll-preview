# NAICS 444120: Paint and Wallpaper Retailers

444120 is a valid NAICS 2022 code (national industry): Paint and Wallpaper Retailers; SBA size standard $34 million in average annual receipts; no change is proposed for NAICS 2027.

- Code: 444120
- SBA size standard: $34 million in receipts
- Census index entries: 2
- NAICS 2027 (proposed): no change

## The Census definition

This industry comprises establishments primarily engaged in retailing paint, wallpaper, and related supplies.

## Census index entries (2)

- Paint stores
- Wallpaper and wall coverings stores
