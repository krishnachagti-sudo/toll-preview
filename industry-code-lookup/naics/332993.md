# NAICS 332993: Ammunition (except Small Arms) Manufacturing

332993 is a valid NAICS 2022 code (national industry): Ammunition (except Small Arms) Manufacturing; SBA size standard 1,500 employees; NAICS 2027 proposes combining it into 332995 Small Arms, Ammunition, Ordnance, and Ordnance Accessories Manufacturing.

- Code: 332993
- SBA size standard: 1,500 employees
- Census index entries: 31
- NAICS 2027 (proposed): combined

## The Census definition

This U.S. industry comprises establishments primarily engaged in manufacturing ammunition (except small arms). Examples of products made by these establishments are bombs, depth charges, rockets (except guided missiles), grenades, mines, and torpedoes.
