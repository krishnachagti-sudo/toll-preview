# NAICS 424520: Livestock Merchant Wholesalers

424520 is a valid NAICS 2022 code (national industry): Livestock Merchant Wholesalers; SBA size standard 125 employees; no change is proposed for NAICS 2027.

- Code: 424520
- SBA size standard: 125 employees
- Census index entries: 7
- NAICS 2027 (proposed): no change

## The Census definition

This industry comprises establishments primarily engaged in the merchant wholesale distribution of livestock (except horses and mules).

## Census index entries (7)

- Auction markets, livestock (except horses, mules), merchant wholesalers
- Cattle merchant wholesalers
- Goats merchant wholesalers
- Hogs merchant wholesalers
- Livestock (except horses, mules, and feedlots) merchant wholesalers
- Sheep merchant wholesalers
- Swine merchant wholesalers
