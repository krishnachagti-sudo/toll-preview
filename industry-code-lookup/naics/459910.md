# NAICS 459910: Pet and Pet Supplies Retailers

459910 is a valid NAICS 2022 code (national industry): Pet and Pet Supplies Retailers; SBA size standard $32 million in average annual receipts; no change is proposed for NAICS 2027.

- Code: 459910
- SBA size standard: $32 million in receipts
- Census index entries: 3
- NAICS 2027 (proposed): no change

## The Census definition

This industry comprises establishments primarily engaged in retailing pets, pet foods, and pet supplies.

## Census index entries (3)

- Feed stores, pet
- Pet shops
- Pet supply stores
