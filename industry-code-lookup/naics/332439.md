# NAICS 332439: Other Metal Container Manufacturing

332439 is a valid NAICS 2022 code (national industry): Other Metal Container Manufacturing; SBA size standard 600 employees; no change is proposed for NAICS 2027.

- Code: 332439
- SBA size standard: 600 employees
- Census index entries: 24
- NAICS 2027 (proposed): no change

## The Census definition

This U.S. industry comprises establishments primarily engaged in manufacturing metal (light gauge) containers (except cans).
