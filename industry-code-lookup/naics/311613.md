# NAICS 311613: Rendering and Meat Byproduct Processing

311613 is a valid NAICS 2022 code (national industry): Rendering and Meat Byproduct Processing; SBA size standard 750 employees; no change is proposed for NAICS 2027.

- Code: 311613
- SBA size standard: 750 employees
- Census index entries: 14
- NAICS 2027 (proposed): no change

## The Census definition

This U.S. industry comprises establishments primarily engaged in rendering animal fat, bones, and meat scraps.
