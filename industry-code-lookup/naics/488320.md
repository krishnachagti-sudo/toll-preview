# NAICS 488320: Marine Cargo Handling

488320 is a valid NAICS 2022 code (national industry): Marine Cargo Handling; SBA size standard $47 million in average annual receipts; no change is proposed for NAICS 2027.

- Code: 488320
- SBA size standard: $47 million in receipts
- Census index entries: 5
- NAICS 2027 (proposed): no change

## The Census definition

This industry comprises establishments primarily engaged in providing stevedoring and other marine cargo handling services (except warehousing).

## Census index entries (5)

- Loading and unloading services at ports and harbors
- Longshoremen services
- Marine cargo handling services
- Ship hold cleaning services
- Stevedoring services
