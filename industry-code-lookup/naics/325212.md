# NAICS 325212: Synthetic Rubber Manufacturing

325212 is a valid NAICS 2022 code (national industry): Synthetic Rubber Manufacturing; SBA size standard 1,000 employees; no change is proposed for NAICS 2027.

- Code: 325212
- SBA size standard: 1,000 employees
- Census index entries: 41
- NAICS 2027 (proposed): no change

## The Census definition

This U.S. industry comprises establishments primarily engaged in manufacturing synthetic rubber.
