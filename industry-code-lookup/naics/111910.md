# NAICS 111910: Tobacco Farming

111910 is a valid NAICS 2022 code (national industry): Tobacco Farming; SBA size standard $2.5 million in average annual receipts; no change is proposed for NAICS 2027.

- Code: 111910
- SBA size standard: $2.5 million in receipts
- Census index entries: 1
- NAICS 2027 (proposed): no change
