# NAICS 212311: Dimension Stone Mining and Quarrying

212311 is a valid NAICS 2022 code (national industry): Dimension Stone Mining and Quarrying; SBA size standard 500 employees; no change is proposed for NAICS 2027.

- Code: 212311
- SBA size standard: 500 employees
- Census index entries: 30
- NAICS 2027 (proposed): no change

## The Census definition

This U.S. industry comprises establishments primarily engaged in developing the mine site and/or mining or quarrying dimension stone (i.e., rough blocks and/or slabs of stone).
