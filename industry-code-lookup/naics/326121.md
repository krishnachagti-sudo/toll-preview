# NAICS 326121: Unlaminated Plastics Profile Shape Manufacturing

326121 is a valid NAICS 2022 code (national industry): Unlaminated Plastics Profile Shape Manufacturing; SBA size standard 600 employees; no change is proposed for NAICS 2027.

## The Census definition

This U.S. industry comprises establishments primarily engaged in converting plastics resins into nonrigid plastics profile shapes (except film, sheet, bags, and hoses), such as rod, tube, and sausage casings.

## Census index entries (5)

- Casings, sausage, nonrigid plastics, manufacturing
- Profile shapes (e.g., rod, tube), nonrigid plastics, manufacturing
- Rod, nonrigid plastics, manufacturing
- Sausage casings, plastics, manufacturing
- Tube, nonrigid plastics, manufacturing
