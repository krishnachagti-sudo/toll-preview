# NAICS 332912: Fluid Power Valve and Hose Fitting Manufacturing

332912 is a valid NAICS 2022 code (national industry): Fluid Power Valve and Hose Fitting Manufacturing; SBA size standard 1,000 employees; NAICS 2027 proposes combining it into 332910 Metal Valve Manufacturing.

- Code: 332912
- SBA size standard: 1,000 employees
- Census index entries: 17
- NAICS 2027 (proposed): combined

## The Census definition

This U.S. industry comprises establishments primarily engaged in manufacturing fluid power valves and hose fittings.
