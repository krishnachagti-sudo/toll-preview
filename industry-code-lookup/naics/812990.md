# NAICS 812990: All Other Personal Services

812990 is a valid NAICS 2022 code (national industry): All Other Personal Services; SBA size standard $15 million in average annual receipts; no change is proposed for NAICS 2027.

- Code: 812990
- SBA size standard: $15 million in receipts
- Census index entries: 45
- NAICS 2027 (proposed): no change

## The Census definition

This industry comprises establishments primarily engaged in providing personal services (except personal care services, death care services, drycleaning and laundry services, pet care services, photofinishing services, or parking space and/or valet parking services).
