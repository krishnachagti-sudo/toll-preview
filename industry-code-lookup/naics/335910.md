# NAICS 335910: Battery Manufacturing

335910 is a valid NAICS 2022 code (national industry): Battery Manufacturing; SBA size standard 1,250 employees; no change is proposed for NAICS 2027.

- Code: 335910
- SBA size standard: 1,250 employees
- Census index entries: 24
- NAICS 2027 (proposed): no change

## The Census definition

This industry comprises establishments primarily engaged in manufacturing primary and storage batteries.
