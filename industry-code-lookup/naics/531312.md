# NAICS 531312: Nonresidential Property Managers

531312 is a valid NAICS 2022 code (national industry): Nonresidential Property Managers; SBA size standard $19.5 million in average annual receipts; no change is proposed for NAICS 2027.

- Code: 531312
- SBA size standard: $19.5 million in receipts
- Census index entries: 14
- NAICS 2027 (proposed): no change

## The Census definition

This U.S. industry comprises establishments primarily engaged in managing nonresidential real estate for others.
