# NAICS 112511: Finfish Farming and Fish Hatcheries

112511 is a valid NAICS 2022 code (national industry): Finfish Farming and Fish Hatcheries; SBA size standard $3.75 million in average annual receipts; no change is proposed for NAICS 2027.

- Code: 112511
- SBA size standard: $3.75 million in receipts
- Census index entries: 13
- NAICS 2027 (proposed): no change

## The Census definition

This U.S. industry comprises establishments primarily engaged in (1) farm raising finfish (e.g., catfish, trout, goldfish, tropical fish, minnows) and/or (2) hatching fish of any kind.
