# NAICS 311313: Beet Sugar Manufacturing

311313 is a valid NAICS 2022 code (national industry): Beet Sugar Manufacturing; SBA size standard 1,150 employees; no change is proposed for NAICS 2027.

## The Census definition

This U.S. industry comprises establishments primarily engaged in manufacturing refined beet sugar from sugar beets.
