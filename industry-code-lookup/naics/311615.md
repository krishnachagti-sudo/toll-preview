# NAICS 311615: Poultry Processing

311615 is a valid NAICS 2022 code (national industry): Poultry Processing; SBA size standard 1,250 employees; no change is proposed for NAICS 2027.

- Code: 311615
- SBA size standard: 1,250 employees
- Census index entries: 24

## The Census definition

This U.S. industry comprises establishments primarily engaged in (1) slaughtering poultry and small game and/or (2) preparing processed poultry and small game meat and meat byproducts.
