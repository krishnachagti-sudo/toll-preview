# NAICS 713290: Other Gambling Industries

713290 is a valid NAICS 2022 code (national industry): Other Gambling Industries; SBA size standard $40 million in average annual receipts; no change is proposed for NAICS 2027.

- Code: 713290
- SBA size standard: $40 million in receipts
- Census index entries: 21
- NAICS 2027 (proposed): no change

## The Census definition

This industry comprises establishments primarily engaged in operating gambling facilities (except casinos or casino hotels) or providing gambling services.
