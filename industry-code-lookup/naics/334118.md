# NAICS 334118: Computer Terminal and Other Computer Peripheral Equipment Manufacturing

334118 is a valid NAICS 2022 code (national industry): Computer Terminal and Other Computer Peripheral Equipment Manufacturing; SBA size standard 1,000 employees; NAICS 2027 proposes combining it into 334110 Computer and Peripheral Equipment Manufacturing.

- Code: 334118
- SBA size standard: 1,000 employees
- Census index entries: 24
- NAICS 2027 (proposed): combined

## The Census definition

This U.S. industry comprises establishments primarily engaged in manufacturing computer terminals and other computer peripheral equipment (except storage devices).
