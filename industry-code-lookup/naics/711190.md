# NAICS 711190: Other Performing Arts Companies

711190 is a valid NAICS 2022 code (national industry): Other Performing Arts Companies; SBA size standard $34 million in average annual receipts; no change is proposed for NAICS 2027.

- Code: 711190

- Census index entries: 8
- NAICS 2027 (proposed): no change

## The Census definition

This industry comprises companies or groups (except theater companies, dance companies, and musical groups and artists) primarily engaged in producing live theatrical presentations.
