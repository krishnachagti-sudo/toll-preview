# NAICS 512132: Drive-In Motion Picture Theaters

512132 is a valid NAICS 2022 code (national industry): Drive-In Motion Picture Theaters; SBA size standard $12.5 million in average annual receipts; no change is proposed for NAICS 2027.

- Code: 512132
- SBA size standard: $12.5 million in receipts
- Census index entries: 6
- NAICS 2027 (proposed): no change

## The Census definition

This U.S. industry comprises establishments primarily engaged in operating drive-in motion picture theaters.

- Movie theaters, drive-in
