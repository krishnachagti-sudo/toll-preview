# NAICS 311611: Animal (except Poultry) Slaughtering

311611 is a valid NAICS 2022 code (national industry): Animal (except Poultry) Slaughtering; SBA size standard 1,150 employees; no change is proposed for NAICS 2027.

- Code: 311611
- SBA size standard: 1,150 employees
- Census index entries: 28
- NAICS 2027 (proposed): no change

## The Census definition

This U.S. industry comprises establishments primarily engaged in slaughtering animals (except poultry and small game). Establishments that slaughter and prepare meats are included in this industry.
