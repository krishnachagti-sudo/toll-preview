# NAICS 112120: Dairy Cattle and Milk Production

112120 is a valid NAICS 2022 code (national industry): Dairy Cattle and Milk Production; SBA size standard $3.75 million in average annual receipts; no change is proposed for NAICS 2027.

- Code: 112120
- SBA size standard: $3.75 million in receipts
- Census index entries: 3
- NAICS 2027 (proposed): no change

## The Census definition

This industry comprises establishments primarily engaged in milking dairy cattle.

## Census index entries (3)

- Dairy cattle farming
- Milk production, dairy cattle
- Milking dairy cattle
