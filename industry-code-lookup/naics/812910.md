# NAICS 812910: Pet Care (except Veterinary) Services

812910 is a valid NAICS 2022 code (national industry): Pet Care (except Veterinary) Services; SBA size standard $9 million in average annual receipts; no change is proposed for NAICS 2027.

- Code: 812910
- SBA size standard: $9 million in receipts
- Census index entries: 17
- NAICS 2027 (proposed): no change

## The Census definition

This industry comprises establishments primarily engaged in providing pet care services (except veterinary), such as boarding, grooming, sitting, walking, and training pets.
