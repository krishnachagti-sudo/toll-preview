# NAICS 524130: Reinsurance Carriers

524130 is a valid NAICS 2022 code (national industry): Reinsurance Carriers; SBA size standard $47 million in average annual receipts; no change is proposed for NAICS 2027.

- Code: 524130
- SBA size standard: $47 million in receipts
- Census index entries: 6
- NAICS 2027 (proposed): no change

## The Census definition

This industry comprises establishments primarily engaged in assuming all or part of the risk associated with existing insurance policies originally underwritten by other insurance carriers.
