# NAICS 423430: Computer and Computer Peripheral Equipment and Software Merchant Wholesalers

423430 is a valid NAICS 2022 code (national industry): Computer and Computer Peripheral Equipment and Software Merchant Wholesalers; SBA size standard 250 employees; no change is proposed for NAICS 2027.

- Code: 423430

- Census index entries: 30

## The Census definition

This industry comprises establishments primarily engaged in the merchant wholesale distribution of computers, computer peripheral equipment, loaded computer boards, and/or computer software.
