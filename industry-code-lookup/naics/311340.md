# NAICS 311340: Nonchocolate Confectionery Manufacturing

311340 is a valid NAICS 2022 code (national industry): Nonchocolate Confectionery Manufacturing; SBA size standard 1,000 employees; no change is proposed for NAICS 2027.

- Code: 311340
- SBA size standard: 1,000 employees
- Census index entries: 30
- NAICS 2027 (proposed): no change

## The Census definition

This industry comprises establishments primarily engaged in manufacturing nonchocolate confectioneries. Included in this industry are establishments primarily engaged in retailing nonchocolate confectionery products not for immediate consumption made on the premises.
