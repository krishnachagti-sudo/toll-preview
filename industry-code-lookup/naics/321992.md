# NAICS 321992: Prefabricated Wood Building Manufacturing

321992 is a valid NAICS 2022 code (national industry): Prefabricated Wood Building Manufacturing; SBA size standard 500 employees; no change is proposed for NAICS 2027.

- Code: 321992
- SBA size standard: 500 employees
- Census index entries: 14
- NAICS 2027 (proposed): no change

## The Census definition

This U.S. industry comprises establishments primarily engaged in manufacturing prefabricated wood buildings and wood sections and panels for prefabricated wood buildings.
