# NAICS 333993: Packaging Machinery Manufacturing

333993 is a valid NAICS 2022 code (national industry): Packaging Machinery Manufacturing; SBA size standard 600 employees; no change is proposed for NAICS 2027.

- Code: 333993
- SBA size standard: 600 employees
- Census index entries: 14
- NAICS 2027 (proposed): no change

## The Census definition

This U.S. industry comprises establishments primarily engaged in manufacturing packaging machinery, such as wrapping, bottling, canning, and labeling machinery.

- Bread wrapping machines manufacturing

- Packaging machinery manufacturing
- Testing, weighing, inspecting, packaging machinery manufacturing

- Wrapping (i.e., packaging) machinery manufacturing
