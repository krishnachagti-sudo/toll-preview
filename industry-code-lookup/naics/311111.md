# NAICS 311111: Dog and Cat Food Manufacturing

311111 is a valid NAICS 2022 code (national industry): Dog and Cat Food Manufacturing; SBA size standard 1,250 employees; no change is proposed for NAICS 2027.

- Code: 311111
- SBA size standard: 1,250 employees
- Census index entries: 11
- NAICS 2027 (proposed): no change

## The Census definition

This U.S. industry comprises establishments primarily engaged in manufacturing dog and cat food from ingredients, such as grains, oilseed mill products, and meat products.
