# NAICS 335921: Fiber Optic Cable Manufacturing

335921 is a valid NAICS 2022 code (national industry): Fiber Optic Cable Manufacturing; SBA size standard 1,000 employees; NAICS 2027 proposes combining it into 335920 Communication and Energy Wire and Cable Manufacturing.

- Code: 335921
- SBA size standard: 1,000 employees
- Census index entries: 1
- NAICS 2027 (proposed): combined

## The Census definition

This U.S. industry comprises establishments primarily engaged in manufacturing insulated fiber optic cable from purchased fiber optic strand.

## Census index entries (1)

- Fiber optic cable made from purchased fiber optic strand
