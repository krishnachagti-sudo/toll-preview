# NAICS 326122: Plastics Pipe and Pipe Fitting Manufacturing

326122 is a valid NAICS 2022 code (national industry): Plastics Pipe and Pipe Fitting Manufacturing; SBA size standard 750 employees; no change is proposed for NAICS 2027.

- Code: 326122
- SBA size standard: 750 employees
- Census index entries: 5
- NAICS 2027 (proposed): no change

## The Census definition

This U.S. industry comprises establishments primarily engaged in converting plastics resins into plastics pipes and pipe fittings.

## Census index entries (5)

- Fittings and unions, rigid plastics pipe, manufacturing
- Fittings, rigid plastics pipe, manufacturing
- Pipe fittings, rigid plastics, manufacturing
- Pipe, rigid plastics, manufacturing
- PVC pipe manufacturing
