# NAICS 445320: Beer, Wine, and Liquor Retailers

445320 is a valid NAICS 2022 code (national industry): Beer, Wine, and Liquor Retailers; SBA size standard $10 million in average annual receipts; no change is proposed for NAICS 2027.

- Code: 445320
- SBA size standard: $10 million in receipts
- Census index entries: 5
- NAICS 2027 (proposed): no change

## The Census definition

This industry comprises establishments primarily engaged in retailing packaged alcoholic beverages, such as ale, beer, wine, and liquor.

## Census index entries (5)

- Beer stores, packaged
- Duty free liquor shops
- Liquor stores, package
- Package stores (i.e., liquor)
- Wine shops, packaged
