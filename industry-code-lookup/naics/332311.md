# NAICS 332311: Prefabricated Metal Building and Component Manufacturing

332311 is a valid NAICS 2022 code (national industry): Prefabricated Metal Building and Component Manufacturing; SBA size standard 750 employees; no change is proposed for NAICS 2027.

- Code: 332311

## The Census definition

This U.S. industry comprises establishments primarily engaged in manufacturing prefabricated metal buildings, panels, and sections.
