# NAICS 325130: Synthetic Dye and Pigment Manufacturing

325130 is a valid NAICS 2022 code (national industry): Synthetic Dye and Pigment Manufacturing; SBA size standard 1,050 employees; no change is proposed for NAICS 2027.

- Code: 325130
- SBA size standard: 1,050 employees
- Census index entries: 62
- NAICS 2027 (proposed): no change

## The Census definition

This industry comprises establishments primarily engaged in manufacturing synthetic organic and inorganic dyes and pigments, such as lakes and toners (except electrostatic and photographic).
