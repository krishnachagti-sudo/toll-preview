# NAICS 325920: Explosives Manufacturing

325920 is a valid NAICS 2022 code (national industry): Explosives Manufacturing; SBA size standard 750 employees; no change is proposed for NAICS 2027.

- Code: 325920
- SBA size standard: 750 employees
- Census index entries: 23
- NAICS 2027 (proposed): no change

## The Census definition

This industry comprises establishments primarily engaged in manufacturing explosives.
