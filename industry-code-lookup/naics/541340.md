# NAICS 541340: Drafting Services

541340 is a valid NAICS 2022 code (national industry): Drafting Services; SBA size standard $9 million in average annual receipts; no change is proposed for NAICS 2027.

- Code: 541340
- SBA size standard: $9 million in receipts
- Census index entries: 4

## The Census definition

This industry comprises establishments primarily engaged in drawing detailed layouts, plans, and illustrations of buildings, structures, systems, or components from engineering and architectural specifications.

## Census index entries (4)

- Blueprint drafting services
- Computer-aided design drafting (CADD) services
- Drafting services
- Draftsmen's offices
