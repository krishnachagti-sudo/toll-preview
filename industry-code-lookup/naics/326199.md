# NAICS 326199: All Other Plastics Product Manufacturing

326199 is a valid NAICS 2022 code (national industry): All Other Plastics Product Manufacturing; SBA size standard 750 employees; no change is proposed for NAICS 2027.

- Code: 326199
- SBA size standard: 750 employees

## The Census definition

This U.S. industry comprises establishments primarily engaged in manufacturing plastics products (except film, sheet, bags, profile shapes, pipes, pipe fittings, laminates, foam products, bottles, plumbing fixtures, and hoses).
