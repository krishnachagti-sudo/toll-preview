# NAICS 112310: Chicken Egg Production

112310 is a valid NAICS 2022 code (national industry): Chicken Egg Production; SBA size standard $19 million in average annual receipts; no change is proposed for NAICS 2027.

- Code: 112310
- SBA size standard: $19 million in receipts
- Census index entries: 7
- NAICS 2027 (proposed): no change

## The Census definition

This industry comprises establishments primarily engaged in raising chickens for egg production. The eggs produced may be for use as table eggs or hatching eggs.

## Census index entries (7)

- Chicken egg production
- Chicken eggs (table, hatching) production
- Cull hen production
- Egg production, chicken
- Eggs, chicken (table, hatching) production
- Layer-type chicken production
- Started pullet production
