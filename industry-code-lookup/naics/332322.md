# NAICS 332322: Sheet Metal Work Manufacturing

332322 is a valid NAICS 2022 code (national industry): Sheet Metal Work Manufacturing; SBA size standard 500 employees; no change is proposed for NAICS 2027.

- Code: 332322
- SBA size standard: 500 employees
- Census index entries: 45
- NAICS 2027 (proposed): no change

## The Census definition

This U.S. industry comprises establishments primarily engaged in manufacturing sheet metal work (except stampings).
