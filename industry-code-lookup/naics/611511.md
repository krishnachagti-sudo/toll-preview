# NAICS 611511: Cosmetology and Barber Schools

611511 is a valid NAICS 2022 code (national industry): Cosmetology and Barber Schools; SBA size standard $13 million in average annual receipts; no change is proposed for NAICS 2027.

- Code: 611511
- SBA size standard: $13 million in receipts
- Census index entries: 9

## The Census definition

This U.S. industry comprises establishments primarily engaged in offering training in barbering, hair styling, or the cosmetic arts, such as makeup or skin care. These schools provide job-specific certification.
