# NAICS 335931: Current-Carrying Wiring Device Manufacturing

335931 is a valid NAICS 2022 code (national industry): Current-Carrying Wiring Device Manufacturing; SBA size standard 600 employees; NAICS 2027 proposes combining it into 335930 Wiring Device Manufacturing.

- Code: 335931
- SBA size standard: 600 employees
- Census index entries: 39
- NAICS 2027 (proposed): combined

## The Census definition

This U.S. industry comprises establishments primarily engaged in manufacturing current-carrying wiring devices.
