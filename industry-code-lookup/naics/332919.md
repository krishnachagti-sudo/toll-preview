# NAICS 332919: Other Metal Valve and Pipe Fitting Manufacturing

332919 is a valid NAICS 2022 code (national industry): Other Metal Valve and Pipe Fitting Manufacturing; SBA size standard 750 employees; NAICS 2027 proposes combining it into 332910 Metal Valve Manufacturing.

- Code: 332919
- SBA size standard: 750 employees
- Census index entries: 17
- NAICS 2027 (proposed): combined

## The Census definition

This U.S. industry comprises establishments primarily engaged in manufacturing metal valves (except industrial valves, fluid power valves, fluid power hose fittings, and plumbing fixture fittings and trim).
