# NAICS 332618: Other Fabricated Wire Product Manufacturing

332618 is a valid NAICS 2022 code (national industry): Other Fabricated Wire Product Manufacturing; SBA size standard 500 employees; no change is proposed for NAICS 2027.

- Code: 332618
- SBA size standard: 500 employees
- Census index entries: 53
- NAICS 2027 (proposed): no change

## The Census definition

This U.S. industry comprises establishments primarily engaged in manufacturing fabricated wire products (except springs) made from purchased wire.
