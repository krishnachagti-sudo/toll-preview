# NAICS 111339: Other Noncitrus Fruit Farming

111339 is a valid NAICS 2022 code (national industry): Other Noncitrus Fruit Farming; SBA size standard $3.5 million in average annual receipts; no change is proposed for NAICS 2027.

- Code: 111339
- SBA size standard: $3.5 million in receipts
- Census index entries: 28
- NAICS 2027 (proposed): no change

## The Census definition

This U.S. industry comprises establishments primarily engaged in growing noncitrus fruits (except apples, grapes, berries, and fruit(s) and tree nut(s) combinations).
