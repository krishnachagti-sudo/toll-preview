# NAICS 459930: Manufactured (Mobile) Home Dealers

459930 is a valid NAICS 2022 code (national industry): Manufactured (Mobile) Home Dealers; SBA size standard $19 million in average annual receipts; no change is proposed for NAICS 2027.

- Code: 459930
- SBA size standard: $19 million in receipts
- Census index entries: 3
- NAICS 2027 (proposed): no change

## The Census definition

This industry comprises establishments primarily engaged in retailing new and/or used manufactured homes (i.e., mobile homes), parts, and equipment.

## Census index entries (3)

- Manufactured (mobile) home dealers
- Mobile home dealers, manufactured
- Used manufactured (mobile) home dealers
