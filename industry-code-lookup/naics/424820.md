# NAICS 424820: Wine and Distilled Alcoholic Beverage Merchant Wholesalers

424820 is a valid NAICS 2022 code (national industry): Wine and Distilled Alcoholic Beverage Merchant Wholesalers; SBA size standard 250 employees; no change is proposed for NAICS 2027.

## The Census definition

This industry comprises establishments primarily engaged in the merchant wholesale distribution of wine, distilled alcoholic beverages, and/or neutral spirits and ethyl alcohol used in blended wines and distilled liquors.
