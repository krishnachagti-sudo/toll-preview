# NAICS 541310: Architectural Services

541310 is a valid NAICS 2022 code (national industry): Architectural Services; SBA size standard $12.5 million in average annual receipts; no change is proposed for NAICS 2027.

- Code: 541310
- SBA size standard: $12.5 million in receipts
- Census index entries: 7
- NAICS 2027 (proposed): no change

## The Census definition

This industry comprises establishments primarily engaged in planning and designing residential, institutional, leisure, commercial, and industrial buildings and structures by applying knowledge of design, construction procedures, zoning regulations, building codes, and building materials.

## Census index entries (7)

- Architects' (except landscape) offices
- Architects' (except landscape) private practices
- Architectural (except landscape) consultants' offices
- Architectural (except landscape) design services
- Architectural (except landscape) services
- Architectural construction specifications consulting services
- Building architectural design services
