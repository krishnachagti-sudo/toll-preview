# NAICS 321215: Engineered Wood Member Manufacturing

321215 is a valid NAICS 2022 code (national industry): Engineered Wood Member Manufacturing; SBA size standard 500 employees; no change is proposed for NAICS 2027.

- Code: 321215
- SBA size standard: 500 employees
- Census index entries: 18
- NAICS 2027 (proposed): no change

## The Census definition

This U.S. industry comprises establishments primarily engaged in manufacturing fabricated or laminated wood arches, wood roof and floor trusses, and/or other fabricated or laminated wood structural members.
