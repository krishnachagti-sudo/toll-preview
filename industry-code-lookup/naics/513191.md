# NAICS 513191: Greeting Card Publishers

513191 is a valid NAICS 2022 code (national industry): Greeting Card Publishers; SBA size standard 1,000 employees; no change is proposed for NAICS 2027.

- Code: 513191
- SBA size standard: 1,000 employees
- Census index entries: 8

## The Census definition

This U.S. industry comprises establishments primarily engaged in publishing greeting cards. These establishments may publish works in print or electronic form, including exclusively on the Internet.
