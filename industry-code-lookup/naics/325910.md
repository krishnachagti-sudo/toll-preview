# NAICS 325910: Printing Ink Manufacturing

325910 is a valid NAICS 2022 code (national industry): Printing Ink Manufacturing; SBA size standard 750 employees; no change is proposed for NAICS 2027.

- Code: 325910

## The Census definition

This industry comprises establishments primarily engaged in manufacturing printing and inkjet inks and inkjet cartridges.
