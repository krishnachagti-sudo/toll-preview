# NAICS 456120: Cosmetics, Beauty Supplies, and Perfume Retailers

456120 is a valid NAICS 2022 code (national industry): Cosmetics, Beauty Supplies, and Perfume Retailers; SBA size standard $34 million in average annual receipts; no change is proposed for NAICS 2027.

- Code: 456120
- SBA size standard: $34 million in receipts
- Census index entries: 3
- NAICS 2027 (proposed): no change

## The Census definition

This industry comprises establishments primarily engaged in retailing cosmetics, perfumes, toiletries, and personal grooming products.

## Census index entries (3)

- Beauty supply stores
- Cosmetics stores
- Perfume stores
