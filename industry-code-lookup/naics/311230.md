# NAICS 311230: Breakfast Cereal Manufacturing

311230 is a valid NAICS 2022 code (national industry): Breakfast Cereal Manufacturing; SBA size standard 1,300 employees; no change is proposed for NAICS 2027.

- Code: 311230
- SBA size standard: 1,300 employees
- Census index entries: 16
- NAICS 2027 (proposed): no change

## The Census definition

This industry comprises establishments primarily engaged in manufacturing breakfast cereal foods.
