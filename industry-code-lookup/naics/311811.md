# NAICS 311811: Retail Bakeries

311811 is a valid NAICS 2022 code (national industry): Retail Bakeries; SBA size standard 500 employees; no change is proposed for NAICS 2027.

- Code: 311811
- SBA size standard: 500 employees
- Census index entries: 1
- NAICS 2027 (proposed): no change

## The Census definition

This U.S. industry comprises establishments primarily engaged in retailing bread and other bakery products not for immediate consumption made on the premises from flour, not from prepared dough.

## Census index entries (1)

- Bakeries with baking from flour on the premises, retailing not for immediate consumption
