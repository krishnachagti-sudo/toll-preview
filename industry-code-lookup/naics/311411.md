# NAICS 311411: Frozen Fruit, Juice, and Vegetable Manufacturing

311411 is a valid NAICS 2022 code (national industry): Frozen Fruit, Juice, and Vegetable Manufacturing; SBA size standard 1,100 employees; no change is proposed for NAICS 2027.

- Code: 311411
- SBA size standard: 1,100 employees

## The Census definition

This U.S. industry comprises establishments primarily engaged in manufacturing frozen fruits; frozen vegetables; and frozen fruit juices, ades, drinks, cocktail mixes and concentrates.
