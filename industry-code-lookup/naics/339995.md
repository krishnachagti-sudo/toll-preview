# NAICS 339995: Burial Casket Manufacturing

339995 is a valid NAICS 2022 code (national industry): Burial Casket Manufacturing; SBA size standard 1,000 employees; no change is proposed for NAICS 2027.

- Code: 339995
- SBA size standard: 1,000 employees
- Census index entries: 4
- NAICS 2027 (proposed): no change

## The Census definition

This U.S. industry comprises establishments primarily engaged in manufacturing burial caskets, cases, and vaults (except concrete).

## Census index entries (4)

- Burial caskets and cases manufacturing
- Burial vaults (except concrete, stone) manufacturing
- Caskets, burial, manufacturing
- Vaults (except concrete) manufacturing
