# NAICS 2027: what changes

OMB's July 13, 2026 notice proposes NAICS 2027 changes to 53 of the 1,012 NAICS 2022 six-digit codes, for data periods beginning on or after January 1, 2027: 47 combined into fewer codes, 2 split, 2 with part moving and 2 retitled, using 22 new code numbers. No final notice was in the Federal Register on November 8, 2026.

- Codes affected: 53
- New code numbers: 22
- Effective (proposed): January 1, 2027

## What to do now

- Keep using NAICS 2022 codes on forms until the agency that asks says otherwise; a proposal changes nothing on its own.
- If one of your codes is above, note its 2027 code so your records can map old to new.
- SBA size standards are set by NAICS code in 13 CFR 121.201; watch for SBA rulemaking that adopts NAICS 2027.

> Reference, not a customs ruling or tax advice: a code that exists may still be the wrong one for your goods or business. Only U.S. Customs and Border Protection (by a binding ruling) decides an import classification, and the IRS decides what goes on a return. Each answer names the official table it came from and that table's date; check the official source before you file.

## Questions

### When does NAICS 2027 take effect?

OMB proposed it for publication of US establishment data for periods beginning on or after January 1, 2027. It is a proposal until OMB publishes a final notice.

### Does my NAICS code change in 2027?

Only if it is in the table on this page: 53 of the 1,012 six-digit codes are. Every other code keeps its number and title in the proposal.

### How often is NAICS revised?

Every five years; the 2027 revision would be the sixth since OMB adopted NAICS in 1997.
