The columns

  • naics_2022 and title: the Census 2-6 digit 2022 file.
  • sba_receipts_million_usd or sba_employees, and sba_footnote: SBA's table effective March 17, 2023 (13 CFR 121.201).
  • naics_2027_proposed: the change OMB proposed on July 13, 2026 (combined, split, part moves or title), with the 2027 code.
  • naics_2017 and sic_1987: from the Census concordances.

Questions

Is there a NAICS code list I can open in Excel?

Yes: the CSV on this page opens in Excel or Google Sheets. Format the code column as text before you sort it.

How many NAICS codes have an SBA size standard?

974 of the 1,012 six-digit codes, in SBA's table effective March 17, 2023.
