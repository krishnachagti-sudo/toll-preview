# Endwise vs the Census NAICS search

The Census Bureau publishes NAICS 2022 itself, with 1,012 six-digit codes, definitions, 20,373 index entries and concordances, free; this checker uses those same files and adds lists of codes in one call, the SBA size standard, the SIC 1987 chain and OMB's proposed 2027 change for each code.

## Side by side

|  | Census NAICS | This checker |
| --- | --- | --- |
| Definitions, index and cross-references | Yes, the source | Definitions and index entries from the Census files |
| Many codes at once | Download the files | Paste up to 5,000 codes |
| SBA size standard | No | Yes, table effective March 17, 2023 |
| NAICS 2017 and SIC | Concordance files | In each answer |
| 2027 proposal | Census posts the materials | Per code, from OMB's July 13, 2026 notice |
| Price | Free | One code free on the page; lists and API per code |

## When Census is better

The Census definitions, index and concordances are the reference of record; read them there for the cross-references and when a statistical survey asks you to classify.

> Reference, not a customs ruling or tax advice: a code that exists may still be the wrong one for your goods or business. Only U.S. Customs and Border Protection (by a binding ruling) decides an import classification, and the IRS decides what goes on a return. Each answer names the official table it came from and that table's date; check the official source before you file.
