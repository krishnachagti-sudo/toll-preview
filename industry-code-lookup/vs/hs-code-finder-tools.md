# HS code finders vs a validator

A classification tool such as Zonos Classify suggests a code from a product description (its page offers up to 3 tries and asks you to contact sales for pricing); this checker does the other half, a yes or no on whether a code exists in the official table, with its title and edition, for up to 5,000 codes a call.

## Side by side

|  | Classification tool (Zonos Classify) | This checker |
| --- | --- | --- |
| Input | A product description | A code, or words to search the official text |
| Output | A suggested code | Valid or not, official title, edition and date |
| Method | Model and rules; Zonos says it also checks each code for validity and fit with the description | Exact table match; no model |
| Price | Not published: contact sales; up to 3 tries on the page | One code or one search is free on the checker's page. A list, or any call over the API or MCP, is $0.002 per code checked for the first 50,000 codes in a month and $0.0005 per code after that; a search over the API or MCP is $0.002. |

## When a classification tool is better

When you have products and no codes, and want guided classification from a description with expert support behind it.

## When a validator is better

When codes already exist, in a product list, a supplier file or an agent's output, and you need to know which ones are not real, are out of date or are short of digits.
