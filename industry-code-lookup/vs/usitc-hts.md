# Endwise vs the USITC HTS search

The USITC's HTS search is the legal source for the 2026 HTS Revision 22 (effective 10/30/2026), free, with duty rates, notes and every revision; this checker reads the same 19,949 statistical numbers and adds bulk checks of up to 5,000 codes, the matching Schedule B numbers and NAICS, US SIC, UK SIC and Schedule C in the same call.

## Side by side

|  | USITC HTS search | This checker |
| --- | --- | --- |
| Source | The HTS itself, the legal text | The USITC JSON export of 2026 HTS Revision 22 |
| Price | Free | One code or search free on the page; lists and API per code |
| Duty rates | All columns: general, special, column 2, footnotes | The general rate |
| Chapter and section notes | Yes | No |
| Many codes at once | Search and export by range | Paste up to 5,000 codes; valid or not for each |
| Other systems | HTS only | Schedule B, HS, NAICS, US and UK SIC, Schedule C |

## When USITC is better

USITC is the legal source for duty rates and the only authority on the text; use it for binding detail, notes, special program rates and revision history. Rulings come from CBP.

## When this checker helps

When you have a list to clean before a shipment or a product listing upload, when you need export and import numbers side by side, or when an agent needs a yes or no with the edition and date.
