A NAICS code for your small business

Use the NAICS code of the activity that brings in most of your receipts: SBA decides a firm's primary industry from how its receipts, employees and costs split across industries (13 CFR 121.107), and that code sets your size standard, such as $34 million in average annual receipts for 541511 Custom Computer Programming Services.

Where the code is asked

  • SBA loans and certifications, and SAM.gov registration: the code decides which size standard applies.
  • Schedule C (sole proprietors): line B takes a code from the IRS list, which groups some NAICS codes; see the Schedule C business codes.
  • Insurance applications, state registrations and bank forms often ask too; the code is the same.

Changing it later is allowed: update it wherever you registered. The full IRS list is on Schedule C business codes.

Reference, not a customs ruling or tax advice: a code that exists may still be the wrong one for your goods or business. Only U.S. Customs and Border Protection (by a binding ruling) decides an import classification, and the IRS decides what goes on a return. Each answer names the official table it came from and that table's date; check the official source before you file.

Questions

How do I know my primary NAICS code?

SBA looks at how your receipts, employees and costs of doing business split across industries in your last completed fiscal year, and may also look at patents, contract awards and assets (13 CFR 121.107).

Does my NAICS code decide if I am a small business?

For SBA programs, yes: each code has a size standard in receipts or employees, such as $34 million in average annual receipts for 541511.
