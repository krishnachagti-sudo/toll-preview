# HTS code for clothing

The USITC HTS (2026 HTS Revision 22) has 211 lines whose text contains "apparel" for clothing, under 34 six-digit HS codes; the first is 4303.90.00.00, Articles of apparel, clothing accessories and other articles of furskin: Other, general duty Free. The right line depends on the material, use and value of your goods.

- HTS lines: 211
- HS codes: 34

## How to pick the line

- Start from the heading whose words describe your goods (General Rule of Interpretation 1), then the subheading at each level.
- Material, use and value decide many lines: check each "Of cotton", "Valued over" or "Other" step.
- Use the 10-digit statistical number on an entry, and a Schedule B number for an export.

> Reference, not a customs ruling or tax advice: a code that exists may still be the wrong one for your goods or business. Only U.S. Customs and Border Protection (by a binding ruling) decides an import classification, and the IRS decides what goes on a return. Each answer names the official table it came from and that table's date; check the official source before you file.
