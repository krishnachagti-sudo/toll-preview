# The AIA G702 and G703, or a G702/G703-style pay application

AIA sells the G702 (Payment Application and Certificate for Payment) and the G703 (Continuation Sheet) at $59.99 each for one-time use, and they are copyrighted; Endwise makes a G702/G703-style application with the same columns in its own layout for $2.50 per pay application, with corrections of the same application free for 60 days and at most $29.00 a month. If your contract names the AIA forms, use them.

From AIA G702 and G703's own pages, read November 8, 2026.

|  | AIA G702 and G703 | Endwise pay application |
| --- | --- | --- |
| What it is | The official, copyrighted AIA documents G702-1992 and G703-1992. | This tool's own layout using the column logic in AIA's published instructions. |
| Price | $59.99 each, one-time use (AIA store). | $2.50 per pay application, with corrections of the same application free for 60 days and at most $29.00 a month; totals and checks free. |
| Certification | The G702 has the architect's certificate; AIA's instructions say the contractor signs and has it notarized. | A signature line for the contractor and a space for the approved amount; no notary block. |
| Checks | Instructions for each column. | Tie-out checks before the PDF: lines total the contract sum, no line over 100%, unsigned change orders, previous certificates, state retainage limits. |
| From code | Not offered on the pages read. | REST and MCP, with the same price (Endwise developers page). |

## When AIA G702 and G703 is better

- Your contract or the owner requires the AIA G702 and G703 themselves: a lookalike can be rejected.
- An architect certifies payment on the AIA certificate as part of the AIA contract set.

## When Endwise is better

- Your GC asks for "AIA-style" or G702/G703 billing but accepts any form with the same columns.
- You want the numbers checked before you send them, and the state retainage limit applied.
- You bill many months: each application is priced once, and corrections are free.

## Questions

### How much do the AIA G702 and G703 cost?

AIA's store lists each at $59.99 for a one-time use licence (read November 8, 2026), so a pay application on both forms is $119.98.

### Can I copy the AIA G702 form?

No: AIA's instructions say the document is copyrighted and may not be reproduced or excerpted without AIA's written permission.
