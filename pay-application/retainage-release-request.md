# Retainage release request

At closeout of a $248,500.00 subcontract held at 10%, $24,850.00 of retainage is outstanding; a 50% partial release bills $12,425.00, and the final release then bills the remaining $12,425.00.

- Held at closeout: $24,850.00
- Partial release (50%): $12,425.00
- Final release: $12,425.00

## The request letter

Fill in the bracketed parts and send it with the final pay application:

```
[Date]

[GC or owner name and address]

Re: Release of retainage, [project name], [your contract or PO number]

Our work under the contract was [substantially complete / complete and accepted] on [date].
Retainage held to date: $24,850.00. Released before: $0.00. Requested now: $24,850.00.

Attached: final pay application no. [n], [lien waiver for the release amount], [closeout documents].
Please confirm the payment date.

[Name, title, company]
```

## Deadlines some states set

- Minnesota, private projects: "The owner or the owner's agent must release all retainage no later than 60 days after substantial completion subject to the terms of this subdivision." ([Minn. Stat. 337.10, subd. 4](https://www.revisor.mn.gov/statutes/cite/337.10)).
- Kansas, public projects: retainage on undisputed payments is released within 30 days after substantial completion, with 18% a year interest if late ([K.S.A. 16-1904](https://www.ksrevisor.gov/statutes/chapters/ch16/016_019_0004.html)).
- Other covered states are on the [state table](https://krishnachagti-sudo.github.io/toll-preview/pay-application/retainage-caps-by-state/).

A release usually goes with a lien waiver for the same amount: make it with the [lien waiver generator](https://krishnachagti-sudo.github.io/toll-preview/lien-waiver/). If the retainage is not paid, the [lien deadline calculator](https://krishnachagti-sudo.github.io/toll-preview/lien-deadline/) works out the dates that protect it.

> Not legal advice. State rules are quoted from the statute on the state's own site as read on November 8, 2026; your contract, the project's funding and later changes in the law can change the answer.

## Steps

1. **Work out what is still held.** Retainage held to date less anything already released: $24,850.00 on a fully billed $248,500.00 contract at 10%.
2. **Check the release condition.** The subcontract (and, where it applies, the state statute) says when retainage is due: substantial completion, final acceptance, or a set number of days after.
3. **Bill it on a pay application.** A final application with every line at 100% and the retainage released shows the release as the amount due; a partial release lowers the retainage held.
4. **Attach what the contract asks for.** Usually a final or conditional lien waiver for the release amount, closeout documents and warranties.
5. **Send the request letter.** Name the project, the amount, the date the release became due and the documents attached.
